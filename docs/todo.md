## Missing tokens / foundations (from gap analysis)

- [ ] **[P2] Typography utilities (`.t-*`) + fixed global classes — expose `--ds-*` token hooks so consumers can retune them locally (requested 2026-07-24, Stas — mm-broker auth dogfooding).** Today `.t-h3`/`.t-h4`/`.t-s`/… hard-code `font: var(--font-weight-*) var(--font-size-*)/…` with NO per-class override hook. A consumer wanting e.g. a **bold** (not extrabold) h3 heading has to either re-declare the raw `font`/`font-weight` (defeats the utility) or hand-roll a custom class — the mm-broker auth `.title`/`.subtitle` did exactly the latter. Give the utilities read-with-fallback `--ds-*` hooks — e.g. `.t-h3 { font-weight: var(--ds-t-h3-weight, var(--font-weight-extrabold)); font-size: var(--ds-t-h3-size, var(--font-size-h3)); … }` — so a scoped override (`[data-brand] .t-h3 { --ds-t-h3-weight: var(--font-weight-bold) }`) retunes weight/size/color without forking or overriding raw declarations. Same consumer-first `--ds-*` contract the components use, extended to the global utility/class layer (`.link` already exposes `--ds-link-*`; `.t-*` and the other fixed classes don't). **Pairs with the token-architecture pass** (same consumer-first `--ds-*` layer principle).
- [ ] **[P2] Semantic radius + elevation role layer (requested Stas 2026-07-08).** Today radius/shadow are read RAW from foundation, so a consumer can't re-round "panels" without hitting every control sharing `--radius-md`. Add a thin role layer: **radius** → `--ds-radius-{field, control, panel, pill}` (natural grouping already exists in raw usage: `--radius-sm` ~17 field files, `--radius-md` ~33 controls, `--radius-lg` ~13 panels, `--radius-pill` ~20 round); **elevation** → `--ds-elevation-{raised, overlay, modal}`. Roles default to current raw values → **non-breaking**; component tokens fall back to the role not the raw token (3-tier). **Verified 2026-07-24:** neither role family exists; radius refactor is genuinely library-wide (~60+ hits) but the **elevation half is partly pre-solved** — `--shadow-popover/modal/toast/card` aliases already exist (just differently named), so scope-reduce elevation to a rename/normalize and keep radius as the real work. **Pairs with the token-architecture pass** — sequence together. (Density/pad NOT in scope; `--space-stack/-inline` already shipped.)
- [ ] **[P2] Global `focus type` config — switch the focus-indicator style theme-wide (idea 2026-06-18).** Two fixed families today: `--focus-field` (soft 3px halo) and `--focus-ring` (crisp 2px ring + gap) — **verified `_semantic.scss:214-229`; no `[data-focus]`/`focus-mode` switch exists, 2026-07-24**. - [ ] **[P3] Primary-button CTA token layer (brand-safety).** Add opt-in `--primary-cta`/`-hover`/`-active`/`-on`, defaulting to the `--primary*` family; the default solid button (the `--c-base`/`--accent` slot — **note: no `.primary` class; verified `button.component.scss:23,35`, 2026-07-24**) reads them.
