# Dropzone - single-file mode

multiple is off by default: a pick or drop delivers one file through (filesAdded). Replacing the existing entry is up to the handler; this one does. accept limits the file picker to the listed types; a drop is not filtered. An element with the hint attribute shows under the default text while the list is empty. --ds-dropzone-max-width caps the width.

Full API: `Dropzone.d.ts`. How to use the component anywhere: `Dropzone.prompt.md`.
