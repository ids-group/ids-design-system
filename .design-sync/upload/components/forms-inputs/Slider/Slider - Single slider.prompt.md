# Slider - single slider

Binds a number signal, updated as the thumb moves. Arrows move one step, PageUp/PageDown ten, Home/End to the ends (in range mode, bounded by the other thumb).

No visible label input: ariaLabel names the thumb(s), suffixed "minimum"/"maximum" in range mode.

Full API: `Slider.d.ts`. How to use the component anywhere: `Slider.prompt.md`.
