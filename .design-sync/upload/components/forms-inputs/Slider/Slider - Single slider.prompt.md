# Slider - single slider

Bind to a number signal; the current value updates as the thumb moves. Arrows move one step, PageUp/PageDown ten, Home/End to the ends (in range mode, bounded by the other thumb).

There is no visible label input; ariaLabel names the thumb(s), suffixed "minimum"/"maximum" in range mode.

Full API: `Slider.d.ts`. How to use the component anywhere: `Slider.prompt.md`.
