Number stepper - sizes

Spinbox for small bounded whole numbers: -/+ buttons around a numeric input. Bind with <ds-number-stepper [(value)]="qty"> ; not a form control (no formControlName, no hint / error). No label, so always set ariaLabel .

Heights match input / select. Unset size falls back to DS_CONFIG.control.size, then md . Focus ring: --ds-number-stepper-focus-shadow .
