Number stepper - sizes

<NumberStepper />

Spinbox for small bounded quantities — increment / decrement buttons around a numeric value. Respects min / max / step . Render via <ds-number-stepper [(value)]="qty"> .

Three sizes aligned with input / select field heights.

size="sm"
size="md" · default
size="lg"
Inputs 7
Name Type Default Description
value two-way number 0 Current numeric value, two-way bound.
min number 0 Lower bound — the decrement button and typed input clamp to it.
max number | null null Upper bound — the increment button and typed input clamp to it; unbounded when null.
step number 1 Amount added or subtracted per increment/decrement.
size sm md lg null Control height — sm/md/lg. Unset falls back to `DS_CONFIG.control.size`, then `'md'`.
disabled boolean false Disables the stepper and blocks all interaction.
ariaLabel string | null null Accessible name for the number input (the stepper has no visible label).
