Number stepper - sizes

Spinbox for small bounded whole-number quantities: increment / decrement buttons around a numeric input. Bind it with <ds-number-stepper [(value)]="qty"> ; it is not a form control (no formControlName, no hint / error). It renders no label, so always set ariaLabel.

Three sizes aligned with input / select field heights. Unset size falls back to DS_CONFIG.control.size, then md. The focus ring reads --ds-number-stepper-focus-shadow.
