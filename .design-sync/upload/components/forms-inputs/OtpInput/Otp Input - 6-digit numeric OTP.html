OTP input - 6-digit numeric OTP

One-time password and PIN entry.

  • length - default 6.
  • mode - numeric (default; digits, numeric keypad) or alphanumeric.
  • (completed) - fires with the code when it goes from partial to complete, not on edits of a full code.
  • Paste spreads across cells; focus snaps to the first empty cell.
  • Backspace on an empty cell clears the previous one; ArrowLeft / ArrowRight move.
  • The first cell has autocomplete="one-time-code" for SMS autofill.
  • The row is a role="group" named by ariaLabel (fallback DS_INTL.otpInput.label); cells read "digit N" or "character N" from DS_INTL.otpInput.
