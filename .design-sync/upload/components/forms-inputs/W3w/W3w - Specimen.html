w3w - specimen

<W3w />

Pill for what3words-style location identifiers (///daring.lion.race). Monospace body in brand colour so the identifier reads as a distinct, code-like token; the leading prefix mark is danger red. Click to copy the full identifier to clipboard. Sits with badges and tags as a pill-family component.

/// daring.lion.race
Inputs 3
Name Type Default Description
prefix string '///' Marker rendered before the address (e.g. the "///" glyph).
address * string — The three-word address, rendered after `prefix`.
copyable boolean true Makes the address clickable/focusable and copies `prefix` + `address` to the clipboard.
Outputs 1
Name Type Emits Description
copied string event Fires with `address` after a successful copy.
