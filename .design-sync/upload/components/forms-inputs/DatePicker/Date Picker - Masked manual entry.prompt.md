# Date picker - masked manual entry

The trigger is a text field by default ([allowInput]="true"). Typing is masked to the active locale format — non-numeric characters are rejected as typed, and an impossible or out-of-range date flags an error on blur. Range mode uses one combined field (start and end in a single input). Clicking the field or the calendar icon opens the panel.

Full API: `DatePicker.d.ts`. How to use the component anywhere: `DatePicker.prompt.md`.
