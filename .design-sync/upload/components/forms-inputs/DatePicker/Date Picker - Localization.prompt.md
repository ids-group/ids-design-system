# Date picker - localization

[locale] drives month names, weekday headers and the value format together via Intl — no OS-locale mixing. [firstDayOfWeek] (0–6, default Monday) shifts the week. Set app-wide via provideDsConfig(datePicker: locale).

Full API: `DatePicker.d.ts`. How to use the component anywhere: `DatePicker.prompt.md`.
