# Date picker - single date

The field accepts masked typing (the locale mask, e.g. MM/DD/YYYY); the calendar icon or ↓ opens a one-month panel. In the grid, arrows move by day or week, Home / End jump to the week start or end, PageUp / PageDown move by month, Enter or Space selects and Esc closes.

Full API: `DatePicker.d.ts`. How to use the component anywhere: `DatePicker.prompt.md`.
