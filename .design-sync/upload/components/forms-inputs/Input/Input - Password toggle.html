Input - password toggle
Truncation
  • Label Single line, no clip — labels are short by spec. Wraps if forced.
  • Input value No clip while focused (caret needs reach). Single-line ellipsis when blurred and overflowing; full value in title attr.
  • Hint Wrap to 2 lines, then ellipsis. No tooltip — hint is itself the tooltip.
  • Error message Wrap, no clip. Always fully visible — error must never hide.

<Input />

On type="password", [passwordToggle]="true" adds an eye button that flips the field between masked and plain text. Two-way [(passwordVisible)] exposes the state.
