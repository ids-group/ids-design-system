Field group - trailing action, and a unit after the value

<FieldGroup />

Several controls, one bordered box — scope + search, amount + unit, input + action.

Any supported control can be a segment, in any order — a ds-button at the end is the same mechanism as a ds-select at the start.

kg
Inputs 4
Name Type Default Description
size sm md lg null Segment height — the field family's scale, so a group lines up with a plain field beside it. Unset falls back to `DS_CONFIG.control.size`, then `'md'`.
invalid boolean false Draws the error border on the whole group. A single segment cannot be invalid on its own: the border belongs to the group.
disabled boolean false Dims the group. Disable the CONTROLS too — this is the chrome, not their interactivity.
fullWidth boolean false Fills the container instead of hugging its segments.
