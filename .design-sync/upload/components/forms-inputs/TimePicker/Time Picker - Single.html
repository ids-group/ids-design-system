Time picker - single

<TimePicker />

A time field (HH:MM) that opens column wheels — Hours / Minutes (and AM·PM in 12-hour mode). Value is a canonical 24-hour "HH:MM" string; 24h vs 12h display is chosen app-wide via provideDsConfig({ timePicker: { format } }) .

Click the trigger, pick an hour and a minute; the value updates live. label renders the same label row a ds-date-picker uses, so date + time in one form row line up without a hand-rolled label above the trigger.
