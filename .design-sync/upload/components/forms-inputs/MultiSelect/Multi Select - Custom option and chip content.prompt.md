# Multi-select - custom option and chip content

dsOptionTemplate fills an option row's label, dsChipTemplate the chip, so a visual survives selection. Both work in ds-select (rows only), ds-multi-select and ds-autocomplete.

Not projected, library-owned: role="option", aria-selected, the checkbox, the check glyph and the chip's close button.

Full API: `MultiSelect.d.ts`. How to use the component anywhere: `MultiSelect.prompt.md`.
