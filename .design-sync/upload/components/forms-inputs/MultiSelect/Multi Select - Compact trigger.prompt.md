# Multi-select - compact trigger

triggerDisplay="count" swaps the chip field for a caption and a selected-count badge at intrinsic width — a fixed footprint for a filter toolbar, where a field that grows with the selection does not fit. A projected dsPickerTrigger WINS over it, and triggerDisplay is then not read at all.

Full API: `MultiSelect.d.ts`. How to use the component anywhere: `MultiSelect.prompt.md`.
