# Multi-select - labels in the trigger, and per-group select-all

triggerDisplay="labels" keeps the compact footprint but names what is selected instead of counting it, cut to the width with the rest behind &laquo;+N&raquo; — the same measurement the chips use. selectAll takes 'group' or 'both' to head each group with its own row.

Full API: `MultiSelect.d.ts`. How to use the component anywhere: `MultiSelect.prompt.md`.
