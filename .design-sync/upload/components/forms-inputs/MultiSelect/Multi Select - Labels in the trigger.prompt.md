# Multi-select - labels in the trigger, and per-group select-all

triggerDisplay="labels" names the selection in the compact footprint, cut to width with the rest behind &laquo;+N&raquo;. selectAll takes 'group' or 'both' for a row per group.

Full API: `MultiSelect.d.ts`. How to use the component anywhere: `MultiSelect.prompt.md`.
