# Multi-select - overflow collapse

maxVisibleChips defaults to "fit": as many chips as fit, the rest behind "+N more", re-split on resize. A number is a ceiling - fewer when the trigger is too narrow. "all" shows every chip and grows the trigger. Same input and default on ds-autocomplete.

Full API: `MultiSelect.d.ts`. How to use the component anywhere: `MultiSelect.prompt.md`.
