# Autocomplete - width

Default width="fill" stretches to the container. width="content" hugs the chips/value plus a minimum typing area — for filter toolbars where a full-width trigger looks broken next to one short chip. --ds-autocomplete-input-min-width tunes the typing area (default 80px), --ds-autocomplete-max-width caps the trigger in either mode. An option label too long for the panel, the create row's included, is cut with an ellipsis and shows in full in a tooltip on hover; one that fits shows none.

Full API: `Autocomplete.d.ts`. How to use the component anywhere: `Autocomplete.prompt.md`.
