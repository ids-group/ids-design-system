Autocomplete - single
Truncation
  • Token chip in the input Single line, ellipsis at ~16 ch. Tooltip on hover when clipped.
  • Option label in dropdown Single line, ellipsis. Tooltip on hover always (the popover is narrow).
  • Secondary metadata Single line, ellipsis. Drop before the primary label clips.

<Autocomplete />

Text input that filters a token-tagged list. Single-select for picking a record (a Member, a venue); multi-select for picking a set (allowed products, audience tags). Distinct from <ds-select> (fixed-list dropdown) and Command palette (global search).

A NUMBER is a CEILING, not a promise: the row still measures, so you get at most that many and fewer when the trigger is narrow. `"all"` shows every chip and lets the trigger grow a line per selection. Unset (`null`) means "not deciding", as it does on every other input in the library — it resolves to `"fit"`. It does NOT mean "show all": that is `"all"`, which is the loudest of the three modes and has to be asked for.
