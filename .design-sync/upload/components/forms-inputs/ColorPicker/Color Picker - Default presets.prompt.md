# Color picker - default presets

Click the swatch to open the picker: drag on the plane to set saturation/brightness, drag the hue bar, or type a hex. Omit [presets] to use the built-in palette. The plane and hue bar take arrow keys (Shift for steps of 10).

Full API: `ColorPicker.d.ts`. How to use the component anywhere: `ColorPicker.prompt.md`.
