# Select - long labels

A label too long for its space is cut with an ellipsis, and hovering it shows the whole text in a tooltip; a label that fits shows none. That covers the trigger value and every option, so a [title] that repeats the label is not needed; keep one only where it says more than the label.

Full API: `Select.d.ts`. How to use the component anywhere: `Select.prompt.md`.
