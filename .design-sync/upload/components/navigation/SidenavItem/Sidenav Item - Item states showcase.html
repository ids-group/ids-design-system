Truncation
  • Item label (expanded) Single line, ellipsis at panel width. Tooltip on hover when clipped.
  • Item label (collapsed) Hidden — the full label moves to a tooltip on hover or keyboard focus.
  • Count badge No clip — numeric, fixed surface area. Caps at 99+ if needed.
  • Group label Uppercase, single line, no clip. Wraps if forced (unlikely at panel widths).
  • Brand name Single line, ellipsis at panel width. Tooltip on hover. Hidden entirely when collapsed.
  • User name (footer) Single line, ellipsis. Tooltip on hover. Role row truncates the same way.

Inputs 9
Name Type Default Description
icon IconName | null null Icon shown before the label; omit to project a custom icon via the `[icon]` slot instead.
label * string — Visible link text; also used as the tooltip/aria-label when the rail is collapsed.
href string '' Plain `href` target, used when `routerLink` is not set.
routerLink string | readonly unknown[] | null null Angular `RouterLink` target — string or array form for dynamic segments.
active boolean false Applies the active style; also drives `aria-current` when not using `routerLink`.
badge number | null null Numeric count shown at the end of the item.
hasAlert boolean false Shows an alert dot alongside the badge.
disabled boolean false Disables the item — non-navigable and styled as inactive.
rail boolean | null null Whether THIS item draws its edge marker when active. Unset follows the parent `ds-sidenav`, then on — the same "null means not deciding" reading as the rest of the library, so a sidenav-wide `[rail]="false"` is not fought per item.
Outputs 1
Name Type Emits Description
activate MouseEvent event Emitted on click, carrying the `MouseEvent`. On an `href` item, `preventDefault()` intercepts navigation (e.g. a docs sidebar driving scroll-spy); a `routerLink` item navigates regardless — Angular's RouterLink ignores `defaultPrevented` — so treat it as a click hook there.
