Menu Item

<MenuItem />

Default

Four items with icons — the typical user-account menu shape.

Disabled item

A row blocked from interaction — still keyboard-focusable (aria-disabled), so a dsTooltip can explain why on hover/focus. Activation stays blocked.

Error

Destructive action — colour pulled from --error-text.

Text only

Icons are optional — omit for a compact text-only list.

Inputs 6
Name Type Default Description
icon IconName | null null Leading icon shown before the projected label.
disabled boolean false Blocks activation and styles the item as inactive. It stays keyboard-focusable (`aria-disabled`, ARIA menu practice) and in `ds-menu`'s roving order, so a `[dsTooltip]` explaining why can be reached and shown.
error boolean false Renders the item in an error/destructive style.
quiet boolean false Renders the item muted — a secondary row like "Sign out" under a divider, still actionable but not competing with the items above it.
description string '' A standing second line under the label — a limitation the action carries ("will not be saved", "read-only in this workspace"). Visible without hover or focus, which is what separates it from a `[dsTooltip]`. Reaches assistive tech as `aria-describedby`, NOT as part of the item's name: the projected label names the action, and a caveat is a description of it. That is why the line is `aria-hidden` in the DOM and referenced by id — inside the button and visible, it would otherwise be concatenated into the name.
submenu TemplateRef<unknown> | null null Optional submenu template — renders a nested `ds-menu` on hover / ArrowRight.
Outputs 1
Name Type Emits Description
pressed MouseEvent event Fires on click, unless the item is disabled or opens a submenu.
