# Menu Item

Four items with icons — the typical user-account menu shape.

A row blocked from interaction — still keyboard-focusable (aria-disabled), so a dsTooltip can explain why on hover/focus. Activation stays blocked.

Destructive action — colour pulled from --error-text.

Icons are optional — omit for a compact text-only list.

Full API: `MenuItem.d.ts`. How to use the component anywhere: `MenuItem.prompt.md`.
