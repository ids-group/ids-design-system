  • Item label (expanded) Single line, ellipsis at panel width. Tooltip on hover when clipped.
  • Item label (collapsed) Hidden — the full label moves to a tooltip on hover or keyboard focus.
  • Count badge No clip — numeric, fixed surface area. Caps at 99+ if needed.
  • Group label Uppercase, single line, no clip. Wraps if forced (unlikely at panel widths).
  • Brand name Single line, ellipsis at panel width. Tooltip on hover. Hidden entirely when collapsed.
  • User name (footer) Single line, ellipsis. Tooltip on hover. Role row truncates the same way.

<Sidenav />

App-level vertical navigation. Items carry an icon, a label, an optional count badge or alert dot. Collapsed mode keeps the icon and pushes the label into a tooltip.

Three groups, brand mark at the top, one item active. Each item exposes an (activate) output (the click MouseEvent ) — preventDefault() intercepts navigation on an href item (a routerLink navigates regardless), e.g. to drive scroll-spy.

Inputs 6
Name Type Default Description
collapsed boolean false Collapses the rail to icon-only width; read by nested `ds-sidenav-item`/`ds-sidenav-group`.
rail boolean true Whether the ACTIVE item draws its edge marker, for the whole sidenav. Off leaves the active state on the fill and the label alone — check that is still distinguishable before turning it off. An individual `ds-sidenav-item` can override this with its own `rail`.
brand string | null null Brand text at the top of the rail (auto letter-mark + name). For a custom logo image/SVG, project it into the `[brand]` slot instead. Unset falls back to `DS_CONFIG.brand.name`. Each field resolves on its own, so `brand=""` drops the wordmark while a `logoLetter` in the config still paints its tile.
logoLetter string | null null Letter-mark glyph when it differs from the brand's first letter (e.g. an "A" tile beside the "MyAdmin" wordmark). Empty = first letter of `brand`; unset falls back to `DS_CONFIG.brand.logoLetter`.
brandRoute string | readonly unknown[] | null null Route the brand row links to — typically the app's home. Unset leaves the row a plain, non-interactive block. Router targets only, and `RouterLink` is instantiated only once this is set, so an app with no router still renders.
brandLinkLabel string | null null Accessible name for the brand link; unset names it "<brand>, home". Ignored while `brandRoute` is unset.
