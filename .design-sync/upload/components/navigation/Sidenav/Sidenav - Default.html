Sidenav - default

App-level vertical navigation.

Each item emits (activate) with the click MouseEvent ; preventDefault() stops navigation on an href item, e.g. for scroll-spy; a routerLink navigates regardless.

Slots: an item takes [icon] (when the icon input is unset) and [trailing] (before the badge); a group takes [ds-group-icon].
