Stepper - default

<Stepper />

Visual indicator of multi-step progress. Pass an array of step labels and a zero-indexed current. Nodes before current render as done (with check icon); the current node fills with brand; later nodes stay as outlined numerals. Each label shows beneath its node, with the current step emphasised — or set labelPosition="inline" for a compact row with the caption beside each node (e.g. a header progress bar). Set orientation="vertical" to stack steps top-to-bottom, [clickable]="true" to make nodes interactive, and [errorSteps]="[...]" to mark steps in error.

Brief Step 1: Brief (completed) Plan Step 2: Plan (completed) 3 Build Step 3: Build (current) 4 Review Step 4: Review (upcoming) 5 Ship Step 5: Ship (upcoming)
Inputs 6
Name Type Default Description
steps readonly string[] [] Step labels, in order — one node is rendered per entry.
current number 0 Zero-based index of the active step; earlier steps render as completed.
labelPosition bottom inline 'bottom' Where the step caption sits relative to its node.
orientation horizontal vertical 'horizontal' Layout axis of the stepper.
clickable boolean false When true, each step node renders as a button and emits its index on activation.
errorSteps readonly number[] [] Zero-based indices of steps in an error state. Error wins over completed/current/upcoming.
Outputs 1
Name Type Emits Description
stepClicked number event Fires with a step's index when it's activated (only when `clickable`).
