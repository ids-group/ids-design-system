Inputs 6
Name Type Default Description
total * number — Total item count, used to compute the page count.
pageSize two-way number 10 Items per page, two-way bound.
currentPage two-way number 1 1-based active page, two-way bound; a page change (incl. the reset to 1 after a size change) emits via the implicit `currentPageChange`.
pageSizeOptions number[] [10, 25, 50, 100] Preset choices offered in the page-size dropdown.
showLabel boolean true Shows the "Showing X–Y of Z" range label.
showPageSize boolean true Shows the rows-per-page dropdown. Turn it off for a screen with a fixed page size — otherwise the control offers a choice the host won't honour.
