Breadcrumbs - service-driven (route-aware apps)

Omit [items] and the component reads from BreadcrumbsService.items — apps push crumbs from route data or an effect when the page model resolves. 

// in a page component or route effect
import { BreadcrumbsService } from 'ds';
private readonly crumbs = inject(BreadcrumbsService);
this.crumbs.set([
  { label: 'Workspace', href: '/' },
  { label: 'Records', href: '/records' },
  { label: 'P-12894' },
]);

// template — items input omitted, reads from service
<ds-breadcrumbs />

Library-level breadcrumb state. Apps push items either programmatically (page constructor / effect) or via a router-data driver (see app docs). `<ds-breadcrumbs>` reads from here when no `[items]` input is provided.

BreadcrumbsService methods 5
Signature Returns Description
set(items: BreadcrumbItem[]) void Replace the whole trail.
push(item: BreadcrumbItem) void Append one item to the end of the trail.
pop() void Drop the last item. A no-op on an empty trail.
replaceLast(item: BreadcrumbItem) void Swap the last item, or set the trail to this one item if it is empty — for a page whose leaf name arrives after its data loads.
clear() void Empty the trail.
BreadcrumbsService properties 1
Name Type Description
items Signal<BreadcrumbItem[]> The current trail. `<ds-breadcrumbs>` reads this whenever no `[items]` input is bound.
