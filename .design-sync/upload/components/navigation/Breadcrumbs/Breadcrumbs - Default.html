<Breadcrumbs />

Trail to root. The last item is the current page (no href). Middle segments collapse to … before the leaf clips.

Four levels — leaf is the current page, bold and non-interactive.

Workspace Clients Acme Co. P-12894
Inputs 4
Name Type Default Description
items BreadcrumbItem[] | null null When omitted, the component reads from `BreadcrumbsService.items`. Pass an explicit array to opt out of the service (per-page override).
separator IconName | null null Icon between crumbs; falls back to `DS_CONFIG.breadcrumbs.separator`, then `chevronRight`.
clickable boolean | null null Whether crumbs render as links; falls back to `DS_CONFIG.breadcrumbs.clickable`, then `true`.
maxItems number | null null Caps how many crumbs render, collapsing the middle into an ellipsis — the first and the LAST always survive. Null (default) renders every crumb. Worth setting on any trail that can get deep: the row is `nowrap` with `overflow: hidden`, so without a cap an overlong trail is clipped from the END, which is the current page — the one crumb the reader needs most.
Outputs 1
Name Type Emits Description
navigate BreadcrumbItem event Fires when a clickable crumb with `href` is activated; default navigation is always prevented.
