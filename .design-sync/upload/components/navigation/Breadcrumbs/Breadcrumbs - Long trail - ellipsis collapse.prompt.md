# Breadcrumbs - long trail · ellipsis collapse

[maxItems]="4" keeps first and last crumbs and collapses the middle to … N more. Set it on any deep trail: the row is nowrap + overflow: hidden; uncapped, the current page clips off the end.

Full API: `Breadcrumbs.d.ts`. How to use the component anywhere: `Breadcrumbs.prompt.md`.
