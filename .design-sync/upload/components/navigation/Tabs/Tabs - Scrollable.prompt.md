# Tabs - scrollable

When scrollable is set the tab strip clips to its bounds and scrolls horizontally. While tabs lie beyond an edge, an arrow on that side turns the strip by a page; a strip that fits shows no arrows. The active tab is always scrolled into view. Works for both variants.
