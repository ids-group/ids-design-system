Shimmer placeholder while data is loading. Render via <ds-skeleton width="…" height="…"> ; the [circle] input applies full border-radius for circular shapes (avatars, dot placeholders).

Name Type Default Description
width string | undefined undefined CSS width of the placeholder (e.g. `'120px'`, `'50%'`).
height string | undefined undefined CSS height of the placeholder.
circle boolean false Pill radius, for avatar/dot-shaped placeholders.
inline boolean false `display: inline-block` instead of `block`, to sit inline with text.
