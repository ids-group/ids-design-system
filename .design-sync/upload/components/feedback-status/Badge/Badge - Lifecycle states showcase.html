Inputs 6
Name Type Default Description
status DsStatusKey — Consumer-defined status key; colours are wired via styles/status. Unset → neutral.
withDot boolean | null null Leading status dot, rendered only while `count` is unset — a count replaces the badge's whole content. Unset falls back to `DS_CONFIG.badge.withDot`, then `false`.
solid boolean false Solid accent fill instead of the default subtle background.
count number | null null Numeric count to display; overrides projected content when set.
max number 99 Count is capped at this value, shown as `"max+"` beyond it.
countLabel string 'notifications' Noun used in the count's accessible label — set for non-notification counts (cart, results, …).
