# Badge - lifecycle states showcase

The app declares keys with @include status.define((key: (bg:, text?, dot?))); these are this site's. status.semantic-preset adds info, success, warning, error and neutral (next section).

withDot adds a leading dot (unset follows DS_CONFIG.badge.withDot, then false); a count replaces the dot and all content.

Full API: `Badge.d.ts`. How to use the component anywhere: `Badge.prompt.md`.
