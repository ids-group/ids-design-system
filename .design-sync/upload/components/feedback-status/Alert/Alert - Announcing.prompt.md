# Alert - announcing

announce follows DS_CONFIG.alert.announce, then false, for the reason under ds-banner, and dev mode raises the same two warnings, prefixed [ds-alert]: an error or warning alert left unbound while the key is unset, and an info, success or neutral one announcing only because the key is true.

Full API: `Alert.d.ts`. How to use the component anywhere: `Alert.prompt.md`.
