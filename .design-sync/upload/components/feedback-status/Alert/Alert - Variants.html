Alert - variants

<Alert />

Lightweight inline status message. Five variants — info, success, warning, error, neutral — each with a default icon, optional title, optional dismiss control, and an [actions] slot for follow-up CTAs.

All five severity variants as permanent specimens.

Neutral
Inputs 5
Name Type Default Description
variant info success warning error neutral 'info' Severity — drives colour, the default icon and the ARIA role/live.
title string '' Optional bold heading above the message.
dismissible boolean false Show a close button that emits `closed`.
icon IconName | null null Override the variant's default icon.
announce boolean false Announce this alert to a screen reader when it appears. Off by default — see `ds-banner`'s `announce` for why, and prefer `ToastService` for anything transient.
Outputs 1
Name Type Emits Description
closed void event Fires when the user dismisses the alert.
