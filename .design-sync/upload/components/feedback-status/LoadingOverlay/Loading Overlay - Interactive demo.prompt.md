# Loading overlay - interactive demo

The overlay is positioned relative to its host; toggle it without unmounting the content. [blur]="false" drops the backdrop blur; spinnerSize takes sm · md (default) · lg. Tokens: --ds-loading-overlay-scrim-color, -label-color and -enter-keyframes/-duration/-easing/-scale.

Full API: `LoadingOverlay.d.ts`. How to use the component anywhere: `LoadingOverlay.prompt.md`.
