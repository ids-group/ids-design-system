# Banner - announcing

announce is off unless bound on the element or set app-wide with provideDsConfig({ banner: { announce: true } }): an alert region fires on insertion, so page furniture would interrupt the reader on every route. Dev mode warns in two cases. An error, warning or severe banner left unbound while the key is unset is one a screen reader will not hear; that warning ends the moment the app sets the key, true or false. An info, success or neutral banner that announces only because the key is true is nearly always furniture written after the key was adopted; that warning ends at an [announce] binding. Neither reaches a production build.

Full API: `Banner.d.ts`. How to use the component anywhere: `Banner.prompt.md`.
