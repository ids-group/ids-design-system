# Bar - in a table cell

A chart is a block with a caption, a legend and an annex table; in a 60px cell that chrome is the whole cell. This is the mark on its own. max is the ceiling the column is read against — usually the column's own largest value, so the longest bar fills its track and the rest are its share. The figure is printed beside it, so the bars are semantics="none".

Full API: `Bar.d.ts`. How to use the component anywhere: `Bar.prompt.md`.
