# Heat map - default

One reading per cell. Magnitude reads from the STEP between colours, so the heat scale spans the full lightness range (unlike the funnel's mid-range ramp). Cells: --ds-heatmap-chart-cell-size (34px), --ds-heatmap-chart-cell-gap (2px), --ds-heatmap-chart-cell-radius; labels: --ds-heatmap-chart-label-color, --ds-heatmap-chart-label-font-size.

Full API: `HeatmapChart.d.ts`. How to use the component anywhere: `HeatmapChart.prompt.md`.
