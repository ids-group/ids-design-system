Heat map - default

A matrix of readings coloured by magnitude - depot by weekday, hour by date, queue by region.

One reading per cell. Magnitude reads from the step between colours, so the heat scale spans the full lightness range.

Token Default

--ds-heatmap-chart-label-font-size --ds-chart-axis-font-size
  • inline-size: fit-content (default) - as wide as the grid, capped at the container; a wider grid scrolls.
  • inline-size: auto - fills the container. Set it from a component stylesheet, or as :root ds-heatmap-chart globally.
