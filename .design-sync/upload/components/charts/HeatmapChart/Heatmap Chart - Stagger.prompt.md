# Heat map - stagger

Cells fade in column by column, left to right. staggerMs sets the step between two columns, 40 by default, and the whole spread fits inside 260ms, so a wide grid narrows the step instead of crawling in. 0 has the grid arrive at once.

Full API: `HeatmapChart.d.ts`. How to use the component anywhere: `HeatmapChart.prompt.md`.
