# Scatter chart - default

Always set xLabel and yLabel. Marks are semi-transparent (--ds-scatter-chart-dot-opacity, 0.72; radius --ds-scatter-chart-dot-radius) so pile-ups read darker, and enter together with no stagger.

tickCount hints both axes; ticks snap to a round step. dimOthers fades all marks but the hovered one; tooltip="none" drops the panel.

Full API: `ScatterChart.d.ts`. How to use the component anywhere: `ScatterChart.prompt.md`.
