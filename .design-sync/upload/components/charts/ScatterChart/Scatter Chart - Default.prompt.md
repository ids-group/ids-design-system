# Scatter chart - default

Both scales are continuous, so a point carries its own position on each rather than an index into a list of categories. xLabel and yLabel are not decoration: without them the reader has two numbers and no idea which is which, and on a scatter that is the whole reading. Marks are drawn semi-transparent, because the interesting thing is where they pile up and at full opacity a cluster of forty and a cluster of four are the same solid disc.

Full API: `ScatterChart.d.ts`. How to use the component anywhere: `ScatterChart.prompt.md`.
