Sparkline - default

A word-sized trend line for a table cell or stat.

  • One svg, no container to measure: cheap in a thousand-row table.
  • A tooltip shows on hover.
  • Decorative unless it gets a label.
  • With a label and tooltip on (default) it is a tab stop: focus opens the tooltip on the last reading; ← → Home End move it.
