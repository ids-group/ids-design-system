# Chat - a notice from the app

role="system" is a line from the app rather than either speaker, centred, and it splits a run of replies. Pick tone by what the note means: leave it neutral for a routine note (saved, switched, started), a quiet one-line plaque that takes an icon if you give one. Set info, success, warning or error when the reader should not miss it: a card in that status colour with its icon. Add a title when the note carries a detail under it.

Full API: `ChatMessage.d.ts`. How to use the component anywhere: `ChatMessage.prompt.md`.
