Inline - inline

<Inline />

Lays children out in a horizontal row with wrapping and gap control. Ideal for tag clouds, button groups, and filter chips.

Angular TypeScript SCSS Design tokens Accessibility
Inputs 4
Name Type Default Description
gap none xs sm md lg xl null Space between children. `null` inherits whatever the enclosing layout set.
align start center end stretch null Cross-axis alignment — vertical, for a row.
justify start center end between null Main-axis distribution — horizontal, for a row. `between` pushes the ends apart.
wrap boolean true Let the row wrap onto more lines (default). `false` keeps one line and lets it overflow.
