# List - list with leading and trailing icons

Use the [leading] and [trailing] slots for icons or avatars. Tokens: --ds-list-divider-color and --ds-list-item-* (padding-y/x, gap, hover-bg-color, selected-bg/label/icon-color, label/subtitle-color).

Full API: `List.d.ts`. How to use the component anywhere: `List.prompt.md`.
