# Stats - stat tiles

Label · value · optional delta with directional arrow. Direction is shown only by arrow and colour; put it in words in deltaLabel or the [delta] slot (e.g. "down 5 vs last week"). deltaTone replaces the up/down colour where direction is not good or bad.

Full API: `Stat.d.ts`. How to use the component anywhere: `Stat.prompt.md`.
