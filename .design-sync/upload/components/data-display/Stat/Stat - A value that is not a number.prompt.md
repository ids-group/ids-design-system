# Stats - a value that is not a number

Project into [dsStatValue] when the headline is a badge, a status dot or other non-text content; the tile keeps its geometry and the value input is the fallback. Like the [delta] slot, the projection replaces the input's text - but [delta] still needs a numeric [delta] input to show the row. unit applies only to the input value - put a suffix inside the projected content.

Full API: `Stat.d.ts`. How to use the component anywhere: `Stat.prompt.md`.
