# Stats - a value that is not a number

Project a badge, status dot or other non-text headline into [dsStatValue]; the tile keeps its geometry, value is the fallback. Projection replaces the input's text, as in the [delta] slot, which still needs a numeric [delta] input to show the row. unit applies only to the input value; put a suffix in the projection.

Full API: `Stat.d.ts`. How to use the component anywhere: `Stat.prompt.md`.
