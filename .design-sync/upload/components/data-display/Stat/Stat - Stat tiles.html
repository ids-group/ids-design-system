Name Type Default Description
label * string — Metric name shown above the value.
value string | number | null '' Headline metric; `unit` is appended directly after it. Optional because the value can be PROJECTED instead — `[dsStatValue]` takes a badge, a status dot, anything a tile needs where a number would go. The input is the fallback, the same shape `[delta]` already has. Namespaced, unlike `[delta]`: twenty components in this library have a `value` input, so a bare `value` attribute used to slot one of them in would also set that input to the empty string. Takes `null` so `[value]="count | number"` typechecks: Angular's own `number`/`date`/`percent` pipes are typed `string | null`, and without the null the idiomatic form fails `strictTemplates` and pushes consumers to `toLocaleString()` in the template — which hardcodes a locale instead of reading LOCALE_ID. Renders as nothing, like the empty default.
delta number | null null Change amount; sign drives the up/down arrow and color.
deltaLabel string '' Suffix appended after the delta's magnitude, e.g. "vs last month".
deltaTone neutral secondary null Overrides the automatic up/down coloring of the delta.
caption string '' Secondary text shown below the value when there's no `delta`.
unit string '' Suffix appended directly after `value`, e.g. "%".
variant default error 'default' `error` applies the error color treatment.
size sm md lg 'md' Controls the stat's overall type scale.
