List Item - a row with its own control

<ListItem />

[leading] and [trailing] sit OUTSIDE the row's button, so a row can carry its own controls and still be the thing that selects. That is the master–detail shape: a checkbox per row for a bulk action, the row itself choosing what the detail pane shows. Two independent targets, never one.

This is why the row is not a single <button> : a checkbox nested in one is invalid HTML, its click would bubble into activated , and a screen reader would fold it into the button's name and never announce its checked state. Note it is a role="list" and NOT a listbox — the ARIA spec says a listbox option cannot hold interactive content at all.

Viewing: Halden Logistics · included: 1 of 3

Inputs 5
Name Type Default Description
title string '' Convenience text; richer middle content can be projected as default content.
subtitle string '' Secondary line below `title`.
clickable boolean false Makes the row's text a button that emits `activated`. `[leading]` and `[trailing]` stay outside it, so a row can hold its own controls as well.
selected boolean false Marks the row current — `aria-current` and the selected tint.
disabled boolean false Disables the row's own button. Controls projected into `[leading]` or `[trailing]` keep their own disabled state.
Outputs 1
Name Type Emits Description
activated void event Fires when the clickable row's button is activated.
