# Description list - narrow containers

Once a value would get less than --ds-description-list-value-min-width (14rem) beside the label, every item puts its label above its value at once. The switch follows the list's own width and its label width. Drag the handles: the second list has a 180px label, so it switches wider.

Full API: `DescriptionList.d.ts`. How to use the component anywhere: `DescriptionList.prompt.md`.
