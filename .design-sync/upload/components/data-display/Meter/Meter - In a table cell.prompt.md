# Meter - in a table cell

A chart is a block with a caption, a legend and an annex table; in a 60px cell that chrome is the whole cell. This is the mark on its own — the bar below sits in a 64px track beside its figure. max is the ceiling the column is read against — usually the column's own largest value, so the longest bar fills its track and the rest are its share.

Full API: `Meter.d.ts`. How to use the component anywhere: `Meter.prompt.md`.
