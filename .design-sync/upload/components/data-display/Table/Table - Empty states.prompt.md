# Table - empty states

Headers always stay.

One line in the [empty] slot, for transient or obvious cases.

A paged table announces it when a filter empties it. Try an unknown project.

First run: the CTA invites creation.

Data exists; the filter or search excluded every row.

Load failure: danger icon, retry first.

loading (either mode) withholds the empty state.
