# Table - loading · skeleton

[loading]="'skeleton'" replaces rows with shimmer rows that pulse in step with every other <ds-skeleton>. Use it while there are no rows yet.

[skeletonRows] sets how many stand in (default 5). Match it to the coming page size so the body does not resize when rows land.

The same table with [skeletonRows]="3".

Full API: `Table.d.ts`. How to use the component anywhere: `Table.prompt.md`.
