# Table - pagination · sticky column

[pageSize]: client paging, select-all per page. [stickyFirstColumn] pins column one. [animateHeight] tweens page changes. Server paging: bind [total], pass one page. [scrollToTopOnPageChange] scrolls the table into view.

sortMode: server (default) only emits (sortChange), client sorts the rows in hand, none removes the affordance.
