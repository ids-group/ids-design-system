# Table - row actions · kebab menu

[rowActions] adds a trailing kebab column; (rowActionSelected) reports action, row. Menu clicks never fire (rowClicked).

Per row: disabled greys an item, disabledReason explains it, hidden omits it; all hidden, no kebab. A hand-built action column with no visible header needs screenReaderLabel.
