# Table - column filters

A column marked filter: 'set' gets a funnel button in its header — a searchable checkbox list of the column's distinct values (here Venue and Status). Unchecking narrows the rows; the funnel highlights while a filter is active. State is two-way bindable via [(columnFilters)] and combines with [filterQuery].

Full API: `Table.d.ts`. How to use the component anywhere: `Table.prompt.md`.
