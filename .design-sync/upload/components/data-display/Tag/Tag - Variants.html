<Tag />

Pill-shaped chip for short labels. Solid (brand-fill) for selected tokens in multi-select inputs; neutral (grey, bordered) for filter chips and metadata. Add [closable] to render a close affordance.

Solid · default Ghost
Inputs 5
Name Type Default Description
variant solid neutral 'solid' Fill style — `solid` for high-emphasis, `neutral` for low-emphasis chips.
closable boolean false Shows a close button that emits `closed`.
interactive boolean false Makes the tag clickable, emitting `toggled` on click.
selected boolean false Applies the active/selected visual state.
closeLabel string 'Remove' Accessible label for the close button (e.g. "Remove Source filter").
Outputs 2
Name Type Emits Description
closed void event Fires when the close button is clicked.
toggled void event Fires on click when `interactive` is true.
