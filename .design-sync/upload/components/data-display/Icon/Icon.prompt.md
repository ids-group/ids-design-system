# Icon

Inline stroke icon from the built-in 85-name set (24×24 viewBox, `stroke: currentColor`, weight 1.75). Decorative by default (`aria-hidden`); pass `ariaLabel` to expose it as an image. `size` in px (default 16), `stroke` overrides weight.

Common names: search plus minus check x chevronDown chevronRight chevronLeft chevronUp menu arrowRight info warn error success bell settings user users home calendar truck box map folder edit trash copy download upload eye filter sort star clock refresh lock mail phone globe file image.

```tsx
<Icon name="truck" size={20} />
```
