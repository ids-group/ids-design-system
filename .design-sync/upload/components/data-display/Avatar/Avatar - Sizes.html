Inputs 11
Name Type Default Description
size xs sm md lg 'md' Diameter — xs/sm/lg apply a size class; md is the default.
initials string '' Fallback text shown when there's no `imageUrl`. Wins over anything derived from `name`, so a caller that already has the letters keeps passing them.
name string '' The person or thing this avatar stands for — one binding drives both the initials and the seed the tint hashes. The tint keys on the NAME, never on the initials — two letters collide wholesale, so every Alice Brown and Adam Bell would share one colour.
initialsRule ((name: string) => string) | null null Replaces the built-in rule for turning `name` into initials, for one avatar or one table of them. Falls back to `DS_CONFIG.avatar.initials`, then to `initialsFrom` — first two words, a Latin-script guess the library does not pretend is universal.
imageUrl string | null null Image source; shown before `initials` or `fallbackIcon` when set.
ariaLabel string | null null Accessible name. When omitted, the avatar is treated as decorative (hidden from AT) — correct when a visible name sits beside it.
tint { bg: string; fg: string } | 'neutral' | null null Off-token color tint. Accepts a `{ bg, fg }` pair for arbitrary palettes, the literal `'neutral'` for the neutral overflow-chip treatment, or null for the default brand-subtle tones from avatar.scss.
status online offline away busy null Presence indicator shown as a colored dot in the bottom-right corner.
fallbackIcon IconName | null null Icon rendered when there is no imageUrl and no initials.
seed string | null null Seed for a deterministic tint (e.g. an email) used when no explicit `tint` is set — the same seed always yields the same colour. Defaults to `name`; set it explicitly when identity is an id or an email rather than the display name.
avoidHues readonly (readonly [number, number])[] [] Hue arcs `[start, end]` (0–360°) the seeded tint must avoid, e.g. a brand hue: `[[310, 360], [0, 20]]`. Only applies when `seed` drives the tint.
