# Avatars - status dots

Pass status to show a presence indicator in the bottom-right corner of the avatar. Set ariaLabel to name the person and their status (e.g. "Alice Brown, Online"): the labelled avatar is role="img", so the dot's own label is not read. Without ariaLabel the avatar is decorative.

Full API: `Avatar.d.ts`. How to use the component anywhere: `Avatar.prompt.md`.
