Buttons - link-styled action
Truncation
  • Label Single line, ellipsis on overflow. Buttons must fit — rephrase if you need multi-line. No tooltip.
  • Icon-only No visible label; full label MUST live in aria-label and tooltip-on-hover.
  • Split-button menu items Single line, ellipsis. Tooltip on hover when clipped.

<Button />

A link-styled action is the global .link class on a <button> (replaces the old variant="text" ). It is an action, not navigation — navigation is what the Link section covers.
