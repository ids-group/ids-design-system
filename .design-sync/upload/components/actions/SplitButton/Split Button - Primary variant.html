Split button - primary variant

<SplitButton />

Combines a primary action button with a dropdown of secondary actions in a single cohesive control.

The main action fires immediately; the chevron reveals alternative actions. Last triggered action is shown below.

Inputs 6
Name Type Default Description
label string '' Label text on the main button.
variant primary outline 'primary' Visual style — primary (solid) or outline.
icon IconName | null null Icon shown on the main button, before the label.
disabled boolean false Disables both the main button and the dropdown trigger.
menuItems readonly SplitButtonItem[] [] Items listed in the dropdown menu.
menuLabel string 'More actions' Accessible name for the dropdown trigger.
Outputs 2
Name Type Emits Description
pressed MouseEvent event Fires when the main button (not the dropdown trigger) is clicked.
