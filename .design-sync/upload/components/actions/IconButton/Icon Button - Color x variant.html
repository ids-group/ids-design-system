Icon button - color × variant

<IconButton />

Icon-only action with its own variant taxonomy — distinct from <ds-button> . Use for toolbars, table-row actions, close / back / overflow affordances. [ariaLabel] is required (an icon has no text label). This replaces the former ds-button iconOnly flag.

variant = fill taxonomy (standard chromeless · filled · tonal · outlined); color = the shared brand/status hue family (same axis as ds-button ). All combinations are valid. secondary/tertiary ship distinct default hues (orange / violet), independent of --primary, so the brand rows read as independent roles out of the box.

Inputs 11
Name Type Default Description
icon * IconName — Icon to render — the button's only visible content.
ariaLabel * string — Accessible name — required since the button has no visible text.
ariaDescribedBy string | null null ARIA `aria-describedby` — the id of text the app renders beside the button, such as why the action is refused. Icon-only leaves no room for a second line, so unlike `ds-button` there is no `disabledReason` here: the text has to exist on screen already for this to point at it.
variant standard filled tonal outlined 'standard' Fill style — standard (chromeless), filled, tonal, or outlined.
color primary secondary tertiary neutral error success warning 'primary' Brand/status hue family (shared with ds-button). `variant` is the fill axis; `color` recolours the accent the fill consumes. Default primary.
size sm md lg null Button size — sm/md/lg, matches the field/button height scale. Unset falls back to `DS_CONFIG.control.size`, then `'md'`.
type button submit reset 'button' Native `<button>` `type`; defaults to `'button'` (not `'submit'`) so it never submits an ancestor form by accident.
disabled boolean false Disables the button and blocks `pressed`.
selected boolean false Toggle state — renders the pressed/active look and sets aria-pressed.
ariaExpanded boolean | null null ARIA `aria-expanded`, forwarded to the inner `<button>` — bind to the open state when this button opens a panel. On the host element it would land on a non-focusable wrapper, which no screen reader reads.
ariaControls string | null null ARIA `aria-controls`, forwarded to the inner `<button>` — the id of the panel this button opens, e.g. `ds-app-layout`'s `railId`.
