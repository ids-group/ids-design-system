# Modal Card - title badge · subtitle

A header richer than one string, without leaving the component: project a status chip into [title-badge] beside the title, and set subtitle for the line under it. The accessible name stays the title string either way — projected markup never enters aria-labelledby. Same shape as ds-page-header.

Full API: `ModalCard.d.ts`. How to use the component anywhere: `ModalCard.prompt.md`.
