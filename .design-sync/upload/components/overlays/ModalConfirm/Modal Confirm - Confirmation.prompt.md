# Modal Confirm - confirmation

Inject ModalService and call modal.confirm() for a destructive or irreversible action — it resolves true on confirm, false on cancel or dismiss. typeToConfirm requires the user to type a phrase before the confirm button enables.

Full API: `ModalConfirm.d.ts`. How to use the component anywhere: `ModalConfirm.prompt.md`. This component is not exported by the package, so it has neither.
