# Tooltip Panel - states showcase (static specimens)

A value with no place to break, a file name or an ID, breaks inside --ds-tooltip-max-width (240px) rather than running past the panel.

On the light theme the panel is light, with a border. To keep the dark, inverted panel, set the three hooks on :root:
