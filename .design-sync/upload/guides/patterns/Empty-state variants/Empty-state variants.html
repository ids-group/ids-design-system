Empty-state variants

Four canonical variants. Each has a distinct icon background, a clear message, and at most one primary action.

No data

The default — section is empty because nothing exists yet.

No asset allocated yet Pick from the equipment list to start building this Line item.

Loading overlay

Data exists but is being refetched. The previous content stays visible behind a dimming layer.

Error with retry

Network or server failure. Retry is the only sensible primary action.

Permission denied

The user is authenticated but their role doesn't grant access to this resource. Don't suggest "log in again" — give them an escape route.

You don't have access to this Delivery schedule Delivery schedules are restricted to Deliveries and Planner roles. Ask Alex Park or your team lead.

Usage

  • One primary action per empty state — never more. Pair with a ghost secondary only when retry needs an escape hatch.
  • Concrete subject ("asset"), concrete next step ("pick from the asset register"). Skip generic copy and cheer.
  • Loading overlay reuses the previous content silhouette behind a dim scrim — don't drop to a full skeleton when data was previously visible.
  • Permission denied never suggests "log in again" — the user is already authenticated; give them a real escape route.
