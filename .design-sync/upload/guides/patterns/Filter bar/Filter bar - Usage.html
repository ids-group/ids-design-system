Filter bar - usage

  • Sits above the list it filters, never below — search is read top-down.
  • Don't mix free-text search with non-text facets inside the same input. Expose facets as siblings.
  • Each applied tag is individually removable; the right-side link is the escape hatch for everything at once.
  • On narrow widths, collapse the facets that do not fit into an overflow panel — that is what ds-filter-bar does — rather than wrapping a single facet onto a second line.
