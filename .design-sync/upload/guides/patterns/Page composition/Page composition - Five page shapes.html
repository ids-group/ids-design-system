Page composition - five page shapes

Naming which one you are building settles most placement questions before they come up.

Pattern
Made of
Easy to miss
List + filters
page header · filter bar · table (or a card list) · pagination
Filters above the data, pagination below it, both full width
Record detail
page header with [meta] · 8+4 grid — main left, meta sidebar right
The sidebar is metadata, never navigation
Form
page header · one card per section · actions in the last card
One primary; submit gates on presence, never on validity
Dashboard
page header · a row of stat tiles · charts or tables below
Tiles are one row that wraps, not a grid you hand-place
Empty / error
an empty state centred in the region that would have held the data
It replaces the region, not the page — header and filters stay
