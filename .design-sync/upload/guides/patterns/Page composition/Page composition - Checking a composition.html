Page composition - checking a composition, instead of eyeballing it

Most effective first.

  1. Every gap is a token. A literal px will not follow [data-density]. Grep the diff for px outside a token declaration.
  2. Every span is a column. col-span-* on .page-grid, and the split is 8+4, 6+6 or 9+3. If a region needs 7+5, the content is wrong, not the grid.
  3. One grid per page. A sub-region aligns to the page tracks. A local display:grid with its own columns is how alignment drifts one screen at a time.
  4. Nested radii decrease. inner < control < panel. Two nested surfaces with the same radius is a defect you can see once you look for it.
  5. One primary per region. One solid button per header, card and modal footer.
  6. Prose is capped. --col-cap-text (720px) regardless of grid width.
