# Form layout - multi-column form

Two-column section pattern: title and description on the left, fields on the right. Fields stack vertically; naturally-paired controls (Start / End, City / Country) sit side-by-side. A footer anchors every form with a secondary Discard and a primary Save.

The display name and ID used across the operations stack.

Three discrete date blocks — Build, Live, and Strike. Editing any of them triggers an impact preview on save.

Six / twelve split — city plus country on a single 12-col row.
