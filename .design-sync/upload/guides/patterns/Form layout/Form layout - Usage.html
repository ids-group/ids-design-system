Form layout - usage

  • Section description fits on one line — if you need two, the section is doing too much.
  • Pair natural counterparts (Start/End, City/Country) horizontally; everything else stacks.
  • Footer stays visible without scroll on common viewports; sticky-footer is acceptable on tall forms.
  • Inline edit is for single-field changes. Promote to a full form once two or more fields move together.
