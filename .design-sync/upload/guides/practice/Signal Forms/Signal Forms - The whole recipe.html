Signal Forms - the whole recipe

DS controls bind to Angular Signal Forms with no wrapper and no adapter: put [formField] on the control and the form owns the value, the validation and the disabled state. Nothing needs to be imported from the DS to make it work.

Describe the shape and the rules in the component, then point each control at a field. The DS side is one attribute — [formField] — and it comes from @angular/forms/signals , not from this library. That is the point: a DS control participates because it exposes value as a model() , which is the entire FormValueControl contract. 

import { form, required, email } from '@angular/forms/signals';

model = signal({ email: '', role: '' });

loginForm = form(this.model, (path) => {
  required(path.email, { message: 'We need an email' });
  email(path.email, { message: 'That is not an email address' });
});
<ds-input label="Email" [formField]="loginForm.email" />
<ds-select label="Role" [options]="roles" [formField]="loginForm.role" />
<ds-checkbox label="I agree" [formField]="loginForm.terms" />

Held read-only by a readonly() rule in the schema

Type an invalid address and leave the field: the message appears only after the field is touched, the border turns, aria-invalid flips, and the button stays disabled until the form is valid. None of that is wired in the template.
