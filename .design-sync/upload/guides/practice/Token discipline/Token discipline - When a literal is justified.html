Token discipline - when a literal is justified

  • The value has no design role — e.g. an SVG viewBox dimension or a fixed glyph size owned by the asset itself.
  • A token should exist but doesn't yet. Promote the literal to a new semantic token before merging.
  • Never: as a shortcut to skip thinking about what role the value plays. If you can't name the role, the value doesn't belong in the component.
