Token discipline - the rule

Every padding, colour, radius, border, font size and motion curve in component CSS reads a token. Literals are token gaps to promote, not shortcuts to take.

Every value that has a design role — colour, spacing, radius, border width, motion — consumes a var(--token). Literals (#ccc, 12px , 200ms ) inside component CSS are a token gap to fix, never a shortcut to take. Dark mode, density and rebrand all rely on this contract.
