Elevation - shadow scale · semantic aliases
Truncation
  • Primitive vs semantic Components consume semantic tokens (--shadow-popover, --shadow-modal). Never reach for --shadow-2 / --shadow-4 directly.
  • Theme tinting Shadows are channel-split through --shadow-tint-h/s/l. Dark themes override --shadow-tint-l to render the same alphas as soft light glows.
  • Stacking Elevation communicates depth visually. Use --layer-* tokens for actual z-index stacking — never compose your own.

--shadow-card
Card at rest
alias → --shadow-1
--shadow-popover
Popovers, dropdowns, autocomplete

--shadow-toast
Toasts, floating notifications
alias → --shadow-3
--shadow-modal
Modals, drawers
alias → --shadow-4
