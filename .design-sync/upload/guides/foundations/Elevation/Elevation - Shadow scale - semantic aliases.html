Elevation - shadow scale · semantic aliases

--shadow-card
Raised surfaces (slider thumb, colour-picker swatch); ds-card is flat by default, elevation="raised" uses --shadow-1
alias → --ds-elevation-raised
--shadow-popover
Shared dropdown panel, table columns panel, colour-picker panel
alias → --ds-elevation-overlay
--shadow-toast
Toasts, floating notifications
alias → --ds-elevation-floating
--shadow-modal
For app surfaces; ds-modal and ds-drawer read --ds-elevation-modal directly
alias → --ds-elevation-modal
