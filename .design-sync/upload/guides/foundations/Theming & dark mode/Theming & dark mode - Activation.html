Theming & dark mode - activation

Three colour layers (base palette, light / dark role maps, brand overlays) let a theme or brand re-skin every component.

One attribute on <html> switches the whole document, not a subtree.

  • nothing - light (default)
  • <html data-theme="dark"> - dark
  • <html data-theme="light"> - explicit light

<html data-neutrals="brand"> re-tints the neutral ramp from --primary-h; light theme only, dark keeps its own ramp.

No automatic prefers-color-scheme switch. To follow the OS, add provideDsTheme({ followSystem: true }) .

  • Sets data-theme at startup and on each OS change, not on the server
  • A data-theme already on <html> at startup wins 
// app.config.ts
import { provideDsTheme } from '@ids-group-ltd/ids-design-system';

providers: [provideDsTheme({ followSystem: true })]
