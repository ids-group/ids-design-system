Surface levels

Ten surface roles: composable lanes, not elevation tiers. A canvas card can hold a subtle hover lane and a muted code block.

Canvas
--surface-canvas
Outermost page backdrop. Frames every other surface.
Default
--surface-default
Cards, tables, sheets, toolbars - the standard content surface.
Secondary
--surface-secondary
Hover lanes, table heads, code blocks, addon backgrounds.
Muted
--surface-muted
Pressed lanes, tracks, skeleton, chip fills.
Overlay
--surface-overlay
Modals, drawers, popovers, dropdowns, toasts.
Inverted
--surface-inverted
Bulk-action bar, dark callouts.
Inverted hover
--surface-inverted-hover
Hover on an inverted surface (bulk-action bar buttons).
Tint
--surface-tint
Brand-tinted selection: active list/tree rows, empty-state badge; follows ds-color via --accent-surface-tint.
Disabled
--surface-disabled
Disabled control fill. Reads as inactive without losing shape.
Scrim
--surface-scrim
Modal/drawer backdrop. Alpha-tinted; never used as a standalone fill.
