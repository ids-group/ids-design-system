Surface levels

Eight surface roles. They're not strict elevation tiers — they're contextual lanes that compose. A card on the canvas can have a subtle hover lane and a muted code block inside it.

Canvas
--surface-canvas
Outermost page backdrop. Frames every other surface.
Default
--surface-default
Cards, tables, modals — the standard content surface.
Secondary
--surface-secondary
Hover lanes, table heads, code blocks, addon backgrounds.
Overlay
--surface-overlay
Popovers, dropdowns, toast region — anything CDK-portaled.
Inverted
--surface-inverted
Bulk-action bar, dark callout cards, tooltip background.
Tint
--surface-tint
Brand-tinted callouts (banners, page-footer save state).
Disabled
--surface-disabled
Disabled control fill. Reads as inactive without losing shape.
Scrim
--surface-scrim
Modal/drawer backdrop. Alpha-tinted; never used as a standalone fill.
