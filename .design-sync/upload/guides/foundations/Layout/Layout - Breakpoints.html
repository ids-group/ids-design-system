Layout - breakpoints
Truncation
  • Breakpoint label Single line, ellipsis. Token names are short — never wrap.
  • Grid tier description Wraps to two lines max. Never clipped — the card grows vertically.
  • Cap row use Wraps freely; the row grows vertically to fit.

Six min-width breakpoint tokens, one column-count per tier, content caps for prose and page width. Page gutters scale with the viewport; content caps at 1280 px on the widest tier, fluid below.

A custom property can't be read inside an @media condition, so for media queries use the compile-time Sass aliases instead: after @use 'breakpoints' as bp write @include bp.up(md) or bp.down(sm) , or read bp.$bp-md directly. The --bp-* custom properties below stay for regular rules and JS.
