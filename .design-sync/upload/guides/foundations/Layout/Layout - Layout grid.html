Layout - layout grid

One column-count per breakpoint. Page gutters and margins scale with the viewport. Use these tracks for the primary page grid — sub-regions inherit, never invent a local grid.

Apply it with .page-grid and .col-span-1 to .col-span-12; a span wider than the active tier wraps to its own row. .grid-2, .grid-3 and .grid-4 are helper grids that collapse at smaller breakpoints.
