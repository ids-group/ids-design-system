Z-index

One stacking contract; components use names, never raw numbers.

Token Value Use
--layer-base 0 Default flow. No stacking context.
--layer-raised 1 Table sticky cells, button focus, loading overlay.
--layer-sticky 100 Reserved for app use; no DS component reads it.
--layer-dropdown 1000 Reserved; DS dropdown panels sit at --layer-popover.
--layer-overlay 1100 Reserved for app use; no DS component reads it.
--layer-drawer 1200 <ds-app-layout> mobile rail.
--layer-modal 1300 <ds-modal>, <ds-drawer>, <ds-bottom-sheet> + scrim.
--layer-popover 1400 <ds-popover> and the shared dropdown panel (select, multi-select, autocomplete).
--layer-toast 1500 <ds-toast-region> portal.
--layer-tooltip 1600 [dsTooltip] panel — must sit above toasts.

Each component's layer:

Token Value Use
--table-sticky-header-z --layer-raised Sticky table header cells.
--table-sticky-col-z --layer-raised Sticky table column cells.
--table-sticky-corner-z 2 Cell where a sticky header meets a sticky column.
--btn-focus-z --layer-raised A focused button above its neighbours.
--btn-group-focus-z 2 A focused segment in a button group or split button.
