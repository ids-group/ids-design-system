Z-index

One stacking contract. Components consume by name, never by raw number.

Token Value Use
--layer-base 0 Default flow. No stacking context.
--layer-raised 1 Subtle elevation — table sticky cells, hover lifts.
--layer-sticky 100 Sticky page headers, sticky filters.
--layer-dropdown 1000 <ds-select>, <ds-menu>, <ds-date-picker> panels.
--layer-overlay 1100 Generic CDK overlay panels.
--layer-drawer 1200 <ds-drawer> slide-in panel.
--layer-modal 1300 <ds-modal> + scrim layer.
--layer-popover 1400 <ds-popover> + <ds-autocomplete> dropdown.
--layer-toast 1500 <ds-toast-region> portal.
--layer-tooltip 1600 [dsTooltip] panel — must sit above toasts.
