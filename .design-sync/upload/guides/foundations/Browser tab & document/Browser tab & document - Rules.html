Browser tab & document - rules

Title format
{Record} · {Section} · Acme — leaf first, brand last so multi-tab triage works. Index pages: {Section} · Acme . Login: Acme only.
Title state
Prefix with ● for unsaved (● Project Alpha · Projects · Acme); prefix with (N) for unread alerts ((3) Logistics plan · Acme).
Favicon
Brand letter on brand surface; alert dot via .fav.alert nested under .tab-spec for unread count or attention state. Size matches --icon-md so it reads legibly at retina + sub-retina densities.
Theme-color
<meta name="theme-color"> matches --primary for branded chrome; reset to --surface-default on logout to avoid carry-over branding.
Tab grouping
Cap at 7 tabs per group; suggest the browser's native tab-grouping when the user opens more. Tabs in the same group share the favicon brand colour.
