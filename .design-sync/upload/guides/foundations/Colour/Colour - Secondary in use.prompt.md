# Colour - secondary in use

Live opt-in adoptions of --secondary — a distinct orange accent family (Tier-1), kept apart from --primary by default. Override --secondary-h/s/l (or a brand) to reskin it.

All adoptions are opt-in (use a class or variant input). --secondary maps to the orange palette family by default — distinct from --primary, so these examples already read apart from the blue accent. Under [data-brand="acme"] --secondary moves to the red family.
