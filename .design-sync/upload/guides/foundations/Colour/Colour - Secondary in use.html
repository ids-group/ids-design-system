ds-card — CSS override

No dedicated variant. If a consumer needs an accent stripe, style it inline — single-rule override, no new API surface:

All adoptions are opt-in (use a class or variant input). --secondary maps to the orange palette family by default — distinct from --primary , so these examples already read apart from the blue accent. Under [data-brand="manage-my"] --secondary becomes Coral (#FF6156).
