Motion - easings

Hover over each card to play the animation. Same duration, same distance — easing alone changes the feel.

--ease-standard cubic-bezier(.2, 0, 0, 1)
Default; decelerates into rest
--ease-emphasized cubic-bezier(.3, 0, .1, 1.4)
Pick-up-and-put-down for overlays
--ease-decelerate cubic-bezier(0, 0, 0, 1)
Incoming only — toast / popover open
--ease-accelerate cubic-bezier(.3, 0, 1, 1)
Outgoing only — dismiss / close
--ease-spring cubic-bezier(.5, 1.5, .5, 1)
Playful overshoot — celebratory feedback
