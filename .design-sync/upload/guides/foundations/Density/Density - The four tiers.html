Density - the four tiers

Four density tiers, applied via [data-density] on a route container. They rewrite hit-target and component-scoped tokens — components consume the same role tokens, so no component CSS changes.

Tier --hit-cozy Use case Touch / WCAG
Ultra-compact 24 px Financial dashboards, log viewers, dense data grids — keyboard/mouse only, never touch Below WCAG 2.5.8 — opt-in only
Compact 32 px Power-user desktop screens with high information density (Bulk inventory matrix, Logistics grid) Below WCAG 2.5.5 — desktop-only
Cozy (default) 40 px The default. All non-matrix screens. Meets WCAG 2.5.8 (24×24 minimum) with margin
Comfy 48 px Field-ops on tablets / touch devices, accessibility preference Meets WCAG 2.5.5 (44×44 enhanced)
