Density - the four tiers

Four density tiers, set by [data-density] ; they rewrite tokens, not component CSS.

Tier --hit-cozy Use case Touch / WCAG
Ultra-compact 24 px Financial dashboards, log viewers, dense data grids — keyboard/mouse only, never touch At the WCAG 2.5.8 minimum (24px), below 2.5.5 - opt-in only
Compact 32 px Power-user desktop screens with high information density (Bulk inventory matrix, Deliveries grid) Below WCAG 2.5.5 — desktop-only
Cozy (default) 40 px The default. All non-matrix screens. Meets WCAG 2.5.8 (24×24 minimum) with margin
Comfy 48 px Field-ops on tablets / touch devices, accessibility preference Meets WCAG 2.5.5 (44×44 enhanced)
