# Charts & dataviz - app-wide chart defaults

Six things are the same decision for every chart in an app rather than a choice per plot, so they resolve through DS_CONFIG: valueFormat (a number reads one way in a product, and a formatter passed per chart drifts as soon as there are two screens), dataTable (whether the numbers behind a plot have a non-visual route is an accessibility policy), frame (whether charts live inside cards), tooltipLingerMs (a property of what the app puts in its tooltips), pinOnClick (whether a click holds a mark) and hoverDelayMs (how long a resting pointer waits before a chart answers it, which has no per-chart input). Precedence is the input, then the config, then the built-in default — so binding one on a single chart still wins. The empty and error copy is wording, so it lives in DS_INTL.chart, and the number locale is DsConfig.locale, then Angular's LOCALE_ID.
