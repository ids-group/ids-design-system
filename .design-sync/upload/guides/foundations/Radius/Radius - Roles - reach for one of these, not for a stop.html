Radius - roles — reach for one of these, not for a stop

Components resolve only these four roles; retheme corners by moving them. A raw stop says "no role", almost never true.

  • Square every pill: --radius-pill-value, e.g. var(--radius-sm)
  • No field role; scope the control role: ds-input { --ds-radius-control: 4px; }
Role
Resolves to
What it is for
--ds-radius-inner

--ds-radius-control
--radius-md

--ds-radius-panel
--radius-lg
A surface that CONTAINS controls — card, menu, popover, modal, drawer, toast

--radius-pill
Round by meaning, not by size — avatar, badge, radio, progress track
