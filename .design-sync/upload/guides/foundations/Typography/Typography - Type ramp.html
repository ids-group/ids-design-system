Typography - type ramp

Mulish for UI and prose, JetBrains Mono for IDs, dates and data; weights 400 / 500 / 600 / 700 / 800.

Page title: usually .t-h2; default UI: .t-s (14).

Each class reads --ds-typography-<role>-font-weight , -font-size , -line-height , -font-family (and -letter-spacing or -color where set); retune one axis in a scope: .my-scope .t-h3 { --ds-typography-h3-font-weight: var(--font-weight-bold) } .
