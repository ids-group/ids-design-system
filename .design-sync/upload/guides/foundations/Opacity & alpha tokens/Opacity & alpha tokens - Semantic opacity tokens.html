Opacity & alpha tokens - semantic opacity tokens

Six purpose-named opacity tokens for component states. Composite alphas (shadows, focus rings) are channel-split; literal alphas stay inside a single token.

Token Value Use Sample
--opacity-disabled 0.5 Disabled where opacity is the only signal — never stacked on --text-disabled
--opacity-text-disabled 0.38 Disabled text where a colour token isn’t available
--opacity-scrim 0.55 Loading-overlay veil
--opacity-state-hover 0.08 Hover layer over surface (overlay vs surface swap)
--opacity-state-pressed 0.16 Active / pressed layer
--opacity-state-active 0.24 Selected / active layer
