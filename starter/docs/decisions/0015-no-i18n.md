# 0015 — No i18n in the starter (deferred → Transloco)

- **Status:** Accepted
- **Date:** 2026-06-19

## Context

The source app has no internationalization, and i18n is a sizeable, opinionated
concern (build-time `@angular/localize` vs runtime libraries).

## Decision

No i18n in the initial starter. When needed, the recommendation is **Transloco**
(runtime translations, lazy-loadable per feature — fits the lazy-route + feature
structure better than build-time `@angular/localize`).

## Consequences

- **+** Avoids premature i18n machinery and string-extraction overhead.
- **−** Retrofitting i18n later touches every template with user-facing copy.
