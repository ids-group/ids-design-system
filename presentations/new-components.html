Layout primitives — Stack · Inline · Container

High

Spacing components, not ad-hoc CSS. Apps repeatedly write flex + gap by hand. Three primitives encode the rules: Stack (vertical rhythm), Inline (horizontal cluster with wrap), Container (max-width + responsive padding).

Use for: every page and card body — consistent gaps that retune with density instead of magic-number margins.
