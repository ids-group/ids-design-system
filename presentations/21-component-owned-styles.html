Решение 1: поля зависят от box-sizing из reset

Рекомендую

Компонент ставит сам

Каждый компонент задаёт box-sizing: border-box себе и своим элементам. Вид с reset не меняется, без reset совпадает.

Описать reset как обязательный

Строка в themes/README и CHANGELOG. Кода нет, приложения без reset остаются со сдвигом.

Ничего

mm-ecm грузит свой reset; другим приложениям сдвиг на 1 px рамки и больше.

Замер

ds-docs, страница Input: у правила *, ::before, ::after { box-sizing } снято свойство через CSSOM. Из 142 хостов форм 112 меняют размер: ds-input 53, ds-select 33, ds-search 14, ds-textarea 11, ds-button 1; например ds-input 192.7 x 38.8 -> 192.7 x 40.0. Свойство задают сами только 3 из 126 папок компонентов. Снимок без reset задевает и карточки доков, поэтому высота хоста 63 -> 96 включает не только поле.

Решение 2: .icon из icon-base сжимает иконку баннера

Рекомендую

Иконка 20, класс свой

Внутренний класс переименовать (например banner-icon), чтобы icon-base его не касался. Иконка везде 20 px, как заказывает шаблон; в приложениях с icon-base она станет крупнее на 4 px.

Иконка 16, класс свой

Переименовать и задать 16 px в стилях компонента. Вид как сейчас в доках, и одинаковый без icon-base.

Ничего

16 px с icon-base, 20 px без него.

Замер

ds-docs, страница Banner: у глобального .icon сняты width и height через CSSOM; 13 иконок ds-banner > ds-icon.icon из 16.0 становятся 20.0 ([size]="20" в шаблоне). Класс icon ставят ещё ds-toast, ds-dropzone, ds-sidenav-item, ds-sidenav-footer; гард их пропускает, потому что их стили тоже определяют .icon.
