♿ A11y — по компонентам и findings

15a11y-ветка покрыла ~29 компонентов; ниже — непокрытое + открытые находки ревью.
P0
switch — role=switch

Сейчас `type=checkbox` → читается как чекбокс. Добавить `role="switch"` + `aria-checked` + `label`/`ariaLabel`.

P1
checkbox — label + ARIA

Голый ``: нет label-ассоциации/`aria-label`/`aria-invalid`/`required`. Зеркалить `input.component.ts` + `booleanAttribute`.

P1
radio + RadioGroup

Голый radio без label; нет группового координатора. Построить `ds-radio-group` (`role=radiogroup`, roving) + per-radio labelling.

P1
bottom-sheet — dialog-семантика

Поведение есть; нет `role=dialog` + `aria-modal` + `aria-labelledby` + `cdkTrapFocus`. Зеркалить `modal.component.html`.

P1
number-stepper — aria-label

Кнопки `−/+` без `aria-label` (Decrease/Increase); `` без label.

P0
table — клавиатурная сортировка

Сортируемые `` не с клавиатуры: нет button/`tabindex`+Enter/Space, нет `aria-sort`.

MED
a11y-мелочь (кластер)

spinner `role=status`; divider `role=separator`; skeleton `aria-busy`; badge count `aria-label`; avatar-group hidden-count; topbar `role=banner`.

P1
combobox trigger open-only

Клик по триггеру/шеврону не закрывает открытую панель (`togglePanel` есть, триггер только открывает).

P1
listbox не закрывается на Tab

combobox/select/dropdown: оверлей висит, фокус уходит за него. Escape обработан, Tab — нет.

P1
scroll-lock без ref-count

modal/drawer: при двух оверлеях закрытие первого возвращает скролл под вторым (оба сбрасывают `body.overflow`).

P2
accordion aria-controls висит

`role=region` внутри `@if(expanded())` → заголовок ссылается на несуществующий id когда свёрнут.

P2
listbox options в tab-order

select/dropdown: option-кнопкам нужен `tabindex="-1"` под roving/active-descendant.

P2
combobox «No matches» selectable

«Нет совпадений» — это `role=option`; должно быть `role=status`/презентационным.

P2
date-picker grid-семантика + focus-баг

Нет `role=grid` (используется `aria-pressed`); `setTimeout`-фокус может стрелять по уже снятому оверлею.

4Гэпы combobox/select/search (Kit Movement, 2026-06-17). focus-баг — корень в pinkmoon, починен там.
combobox — нет content/compact ширины

Multi-select всегда тянется на ширину хоста → один короткий чип оставляет пустой триггер справа. Нужен `fit-content`/`max-content`-режим (триггер обнимает чипы + min поле ввода). Сейчас консьюмер хардкодит ширину.

combobox single — читается как free-text

В single-режиме триггер сохраняет поле ввода + шеврон после выбора — выглядит как multi/typeahead и как `ds-select`. Нужен filled-select display-режим или гайд select vs combobox.

root-cause найден
focus-ring на инпутах — DS follow-up

«Двойной ринг» оказался НЕ багом DS: глобальный `.input:focus` из pinkmoon `_forms.scss` протекал в `.input` внутри `ds-search` (emulated encaps. не щитит inner-элемент от глобального селектора). Починено в pinkmoon. Токен-нестыковка combobox `--focus-ring`→`--focus-field` ✅ исправлена (06-18). Открыто в DS: `ds-search` именует inner-инпут слишком общим `.input` — переименовать в scoped-класс, чтобы либа была иммунна к консьюмерским `.input`-ресетам.
