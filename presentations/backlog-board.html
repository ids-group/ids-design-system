Цвет-движок: один источник

Схлопнуть `--primary` + `--primary-h/s/l` в ОДИН токен; оттенки/halo выводить через `color-mix()` + relative color (`hsl(from …)`), сохраняя ручную калибровку рампы. Убирает дубль (из-за него consumer-override `--primary-h/s/l` красит только halo, не заливку) и разблокирует `--accent` indirection.

Global `focus type` — тема-вайд переключатель

Сейчас 2 фикс-семейства: `--focus-field` (мягкое 3px halo — поля) и `--focus-ring` (чёткий 2px ring — действия/нав). Дать бренду/приложению выбрать СТИЛЬ фокуса в одном месте (токен / `[data-focus]` на `:root`) из 4: field · ring · B offset-outline (выживает в forced-colors) · C contiguous primary edge. Откр.: outline-режимы нельзя выразить как `box-shadow`-токен → нужен outline-путь / shared mixin.

combobox — нет content/compact ширины

Multi-select всегда тянется на ширину хоста → один короткий чип оставляет пустой триггер справа. Нужен `fit-content`/`max-content`-режим (триггер обнимает чипы + min поле ввода). Сейчас консьюмер хардкодит ширину.

combobox single — читается как free-text

В single-режиме триггер сохраняет поле ввода + шеврон после выбора — выглядит как multi/typeahead и как `ds-select`. Нужен filled-select display-режим или гайд select vs combobox.
