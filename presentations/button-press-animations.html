ds-button · press animation — текущая и альтернативы

Сейчас в либе (карточка «0»): нажатие = только затемнение фона (--primary-pressed, color-mix 76% black) + слабое halo-кольцо, переход 120ms --ease-standard. Движения нет — никакого тактильного «вдавливания». Ниже — 6 альтернатив на тех же токенах (transform/box-shadow — дёшево по перфу). Зажми и подержи кнопку, чтобы почувствовать. Все варианты гасят движение под prefers-reduced-motion и падают обратно к цвету+halo.

0 · Текущая в либе

Фон темнеет + faint halo-кольцо. Без движения — спокойно, но «плоско», нажатие почти не ощущается.

&:active {
  background: var(--primary-pressed);
  box-shadow: 0 0 0 3px
    color-mix(--primary-pressed 35%);
}

A · Scale-down

Кнопка сжимается до .96 — каноничный тактильный «клик». 80ms ease-out. Самый дешёвый способ дать ощущение нажатия.

&:active {
  transform: scale(0.96);
  background: var(--primary-pressed);
}

B · Push (3D key)

Скевоморфная клавиша: под кнопкой сплошная «грань», на нажатии кнопка опускается на неё (translateY(3px)). Очень «физично».

box-shadow: 0 3px 0 var(--primary-strong);
&:active {
  transform: translateY(3px);
  box-shadow: 0 0 0 var(--primary-strong);
}

C · Elevation sink

Material-логика: в покое приподнята (--shadow-2), на нажатии «оседает» — тень уплощается + 1px вниз.

box-shadow: var(--shadow-2);
&:active {
  box-shadow: var(--shadow-1);
  transform: translateY(1px);
}

D · Squish

Резиновое сжатие — шире и ниже (scale(1.05, .88)), пружинный возврат (--ease-spring). Игривый, для брендов с характером.

transition: transform 180ms
  var(--ease-spring);
&:active { transform: scale(1.05, 0.88); }

E · Spring

Глубокое сжатие до .9 и пружинный overshoot-возврат на отпускании. Заметнее scale, чуть «живее».

transition: transform 180ms
  var(--ease-spring);
&:active { transform: scale(0.9); }

F · Ripple +JS

Material ink-ripple из точки клика. Канон для тач-интерфейсов, но требует JS-спавна спана (не чистый CSS).

// mousedown → spawn .ripple span
// at click point, animate scale+fade

Гайдлайны (ui-ux-pro-max + web): press-фидбек — 80–120ms ease-out (быстрее hover); анимировать только transform/opacity (не размеры); prefers-reduced-motion обязателен; не перегружать (1 движение на нажатие).
Рекомендация: A (scale .96) или C (elevation sink) — дёшево, универсально, читается как «нажал». B/D/E — характернее, под игривый бренд. Ripple — если нужен тач-канон. Все можно положить на токены: --ds-button-press-* (новый слой) или включать через тему.
