Бренд, заданный один раз, в тёмной теме снова синий

Одно решение: как цвет бренда, заданный один раз, попадает в тёмную тему.

Ответ нести в чат: «Acc2 · Дека движения графиков»

Сегодня

  • Бренд пишет --primary один раз; тёмный блок DS :root[data-theme='dark'] объявляет его заново и побеждает по специфичности (0,2,0 против 0,1,0).
  • В тёмной теме кнопка, тинты, чип, рамка фокуса и ссылка снова синие; ошибки нет, видно только глазами.
  • Обход: повторить --primary и три канала под [data-theme='dark'][data-brand] - шаг чек-листа в themes/README.md.
  • Синий по умолчанию в обеих темах один и тот же: --primary = --blue-600 = #2e54ff, шаг от светлой к тёмной равен нулю.

Зелёный бренд #1F7A4D, заданный только в [data-brand], на настоящем ds.css.

Три варианта

как сейчас

Как сейчас: бренд повторяет цвет в тёмной теме

  • Бренд пишет цвет дважды: в [data-brand] и в [data-theme='dark'][data-brand].
  • Пропущенный повтор = синие кнопки в тёмной теме, как на картинке выше.
  • Миграции нет; синий по умолчанию не меняется.
[data-brand='green'],
[data-theme='dark'][data-brand='green'] {
  --primary: #1F7A4D;
  --primary-h: 150; --primary-s: 59%; --primary-l: 30%;
}
рекомендую

Тёмная тема берёт цвет бренда как есть

  • Тёмный блок перестаёт объявлять --primary и каналы: их значение там то же, что в светлой.
  • Тёмная тема берёт светлый цвет бренда без изменений; тинты, текст на них и ссылка уже считаются от тона.
  • Тёмный бренд остаётся тёмным: край кнопки тёмно-синего на карточке - (нужно 3:1).
  • Миграции нет: повтор из варианта «как сейчас» работает и становится лишним.
[data-brand='green'] {
  --primary: #1F7A4D;
  --primary-h: 150; --primary-s: 59%; --primary-l: 30%;
}
новый токен

Один вход бренда, тёмная тема выводит светлее

  • Новый вход --ds-brand: светлая --primary = он, тёмная = oklch(from var(--ds-brand) max(l, 0.54) c h).
  • Шаг синего по умолчанию нулевой, поэтому вывод - порог: бренд темнее синего (OKLCH L 0,54) поднимается до него. Зелёный +0,025, тёмно-синий +0,21.
  • Миграция: каждый бренд переходит с --primary на --ds-brand; оставшийся на --primary в тёмной снова синий.
[data-brand='green'] {
  --ds-brand: #1F7A4D;
  --primary-h: 150; --primary-s: 59%; --primary-l: 30%;
}

Каждая карточка: синий по умолчанию, зелёный #1F7A4D и тёмно-синий #1C3558 (CTA консьюмера из деки 9), светлая и тёмная тема. Каждый фрагмент - отдельный документ на настоящем ds.css; цифры посчитаны в нём из отрисованных цветов, красным - ниже порога. Тонал синего по умолчанию в тёмной (4,15) красный уже сегодня и одинаков во всех вариантах.

Рекомендую: «Тёмная тема берёт цвет бренда как есть»

  • Чинит баг без нового токена и без миграции: тот же CSS бренда работает в обеих темах.
  • Синий по умолчанию совпадает пиксель в пиксель: его тёмное значение уже равно светлому.
  • «Выводит светлее» меняет картину только у очень тёмных брендов; это вопрос «Как получать все оттенки цвета из одного цвета бренда» (деки 2-color-engine-derivation, 3-color-engine-relative), туда и переедет порог, если нужен.

Источники
  • Код, 2026-10-12: styles/_theme-activation.scss (светлая на :root, тёмная на :root[data-theme='dark']), themes/_semantic.scss (--primary: var(--blue-600) и каналы в @mixin roles, который включают обе темы), themes/dark/_theme.scss (тинты hsl(from var(--primary) h …), ссылка от --primary-h), themes/README.md (шаг чек-листа про тёмную тему).
  • Фрагменты: каждый - iframe с @import "ds.css" и <html data-theme data-brand>, как у консьюмера. Кнопка --accent / --accent-on, тонал --accent-muted / --accent-strong, строка --accent-surface-tint, чип как ds-tag, поле --accent + --focus-field, ссылка --text-link на --surface-default.
  • Как нарисованы варианты 2 и 3: ds.css импортирован в слой layer(ds), поэтому --primary и каналы бренда побеждают и в тёмной; для бренда, задающего только их, это те же пиксели, что удаление этих объявлений из тёмного блока. Вариант 3 добавляет слой с --primary от --ds-brand.
  • Почему не слой для всех токенов темы: тогда любой :root-оверрайд консьюмера (например, --surface-canvas) тоже протечёт в тёмную тему. Снять только вход бренда из тёмного блока уже, чем слой, и даёт тот же результат для бренда.
  • Шаг синего: --primary посчитан в обеих темах на этой странице (-); OKLCH L синего 0,540, зелёного 0,515, тёмно-синего 0,330 (sRGB → OKLab, формулы Оттосона).
