Интеракции по формуле: контракт ds-interactive

Слева — как цвета состояний заданы сейчас (ramp-пики и подмена токенов). Справа — формула: компонент задаёт только базу (--interactive-base), hover и pressed выводятся глобальным правилом. Наводи мышь и зажимай кнопку, чтобы увидеть pressed. Рядом с каждым элементом — статичные триады база / hover / pressed для сравнения «в покое».

Формула (живёт глобально, ровно один раз)

/* styles/_interaction.scss — единственное место с формулой */
.ds-interactive {
  --interactive-hover:  color-mix(in srgb, var(--interactive-base) calc(100% - var(--state-step-hover)),   var(--state-into));
  --interactive-active: color-mix(in srgb, var(--interactive-base) calc(100% - var(--state-step-pressed)), var(--state-into));
}
/* константы: --state-step-hover: 12%; --state-step-pressed: 24% (= 2 × hover);
   направление --state-into: black (тёмная база/тема → white);
   нейтральные поверхности: прозрачная база + чернильные шаги 5% / 10% */
Брендовый --primary: Меняется ТОЛЬКО --primary — формульная сторона пересчитывает все состояния сама.

1. Заливки

Primary и error уже формульные в теме — стороны совпадают (это подтверждение совместимости). У success/warning сегодня нет pressed (active повторяет hover) — формула даёт его бесплатно.

2. Тональные и контурные

Сейчас: hover — это другой токен рампы (muted → muted-strong, transparent → subtle → muted). Формула: secondary темнеет от своей базы; tertiary — «чернильный» слой, где чернила = бренд (--state-into: var(--primary)); outline — нейтральные чернила 5% / 10%.

3. Нейтральные поверхности (меню, строки)

Сейчас hover — подмена на непрозрачный --surface-secondary: на белом ок, но на тонированном фоне «дырявит» подложку. Формульный чернильный слой (прозрачная база + 5% / 10% чернил) работает поверх любого фона.

4. Тёмные базы — направление переключается токеном

Sidenav сегодня делает то же самое локальной формулой (mix 88% white) — справа она стала глобальной (--state-into: white), результат идентичен. Инвертированная панель сегодня — абсолютный пик --neutral-800; формула даёт почти тот же тон.

5. Ссылки — единственный нарушитель пропорции

Сейчас: −20% hover / −35% active (и pressed ≠ 2 × hover). Формула: стандартные −12% / −24%. Сравни, не слишком ли слабым станет hover.

Что остаётся в компоненте

/* button.component.scss — токен-блок наверху, только необходимое */
.button          { --interactive-base: var(--primary); }
.button.error    { --interactive-base: var(--error); }
.button.success  { --interactive-base: var(--success); }
.menu-item       { /* класс ds-interactive surface в шаблоне — и всё */ }

/* уходит из компонентов: --ds-*-bg-hover, --ds-*-bg-active на каждый вариант,
   локальные color-mix (sidenav), ramp-пики состояний (secondary/tertiary/outline) */

Не охвачено контрактом (остаётся семантикой): focus-кольца (уже единые через --focus-ring), смена бордеров default → strong и текста secondary → primary.
