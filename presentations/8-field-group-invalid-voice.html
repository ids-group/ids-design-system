Цвет — единственный канал, и это провал WCAG 1.4.1. Сегменты прячут свои .label и ds-field-message через display: none — иначе строка сообщения разорвала бы склеенный ряд, — а групповой строки не существует. aria-invalid не ставится нигде, так что скринридер на любом сегменте не скажет ничего. Проверено в коде сегодня: _field-group-segment.scss:10-13, и grep aria-invalid по компоненту пуст.

Визуальная половина дефекта уже починена (2026-09-10): красная рамка пропадала под курсором и под фокусом, потому что :hover и :focus-within весили больше .invalid. Сейчас держится, и гало берёт цвет ошибки. Эта дека — про то, что осталось.

Как это устроено у полей

Пятнадцать контролов уже несут пару входов, и у каждого своя работа. Группа — единственная, у кого половина пары, и её половина делает меньше, чем у поля.

ВходЧто делает15 полейds-field-group
error строка: включает состояние и несёт текст
invalid флаг: красит и ставит aria-invalid, текста нет только красит

И библиотека уже описала, зачем нужна вторая половина — этим самым случаем. Докблок DsFieldBase.invalid, дословно: «paints the error state and sets aria-invalid, WITHOUT a message of its own — for when the text lives elsewhere, such as a form-level error summary or one message covering a whole field group». То есть invalid у сегмента существует ровно для того, чтобы текст нёс кто-то снаружи. Снаружи — это группа. Группе текст нести нечем.

Второе: invalid у группы — это одноимённый вход, который делает меньше. У поля он даёт [attr.aria-invalid] и краску; у группы — [class.invalid] и всё.

Выбор сводится к одному: получает группа свою строку ошибки или нет. Первые три дают один и тот же экран и отличаются только тем, что слышно. Строка ошибки вход error, слот сообщения в шаблоне, id раздаётся сегментам группа перестаёт быть одной строкой по высоте; следом попросят hint — это уже небольшая фича, а не фикс

Рекомендую «строку ошибки». Это не новый API — это пара error + invalid, которая уже есть у пятнадцати контролов, и docblock DsFieldBase.invalid прямо называет группу тем местом, где должен жить текст. Только она закрывает то, из-за чего пункт вообще в P2: сегодня об ошибке группы нельзя узнать иначе как увидев цвет. error: string делает текст условием состояния — включить ошибку и не сказать, в чём она, становится невозможно, и это совпадает с полями, где error уже строка. invalid: boolean остаётся ровно для одного реального случая: текст живёт снаружи, а от группы нужна только рамка.
