<html> этой страницы - cozy. Справа контейнер с data-density="compact": иконка-кнопка сжалась до 32, поле, выбор и кнопка остались 40. Страница Density в ds-docs советует ставить атрибут на контейнер маршрута и обещает тулбар в 32px.

В каждой карточке одни и те же поля в четырёх контейнерах и один вложенный. Цифры под строкой - высоты, измеренные в этой странице. Выбор - клик по карточке.

Где работает data-densityПлотность только на <html> · Плотность на любом контейнереПлотность на любом контейнере

Источники, проверено 2026-10-09 на dev (5baa53e30). Код: src/lib/styles/_tokens.scss - :root объявляет --field-h-sm: var(--hit-min) (330), --field-h-md: var(--hit-cozy) (331), --sidenav-collapsed-item (352) и --calendar-cell-min (442) от --hit-cozy; блоки [data-density] (506-559) меняют 18 базовых токенов и ни одного из этих четырёх - список посчитан скриптом по всем :root и [data-density] в src/lib/styles. Читают их styles/_field-box.scss (input, select, multi-select, autocomplete, date, time и colour picker, number stepper, field-group, split-button, modal), button, search, pagination, icon-button .lg, sidenav-item; icon-button .md читает --hit-cozy напрямую и потому следует контейнеру. Docs: ds-docs/.../density/density.section.html:210 («on the route container») и :231 («levels a toolbar at 32px»); живое сравнение там на локальных .dens-btn/.dens-input, которые читают --hit-cozy напрямую. Поля в деке пересобраны из SCSS компонентов на токенах ds.css; карточка «на любом контейнере» добавляет ровно четыре строки из таблицы. В mm-ecm-platform*, mm-broker-platform и исходниках pinkmoon-platform data-density не встречается (grep по C:/Repositories, 2026-10-09). CSS: значение custom property подставляется в computed value до наследования - CSS Variables 1; @property этого не меняет, registered property тоже наследует computed value - Properties and Values API, MDN. Библиотеки: Carbon Layout, _layout.scss; React Spectrum Provider; Ant ConfigProvider; MUI theming; MDC density; FluentProvider types; Atlassian spacing (настройки плотности нет).
