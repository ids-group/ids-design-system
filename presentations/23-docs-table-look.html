Рекомендую: «Везде с рамкой»

Один вид на всех страницах, и для плотных справочных данных рамка с серой шапкой лучше держит строки вместе: таблица читается как один объект, шапка отделена заливкой, а не только цветом текста. Меняются две страницы, общее правило не трогается.
