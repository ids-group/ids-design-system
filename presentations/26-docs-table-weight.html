Рекомендую: «Витрина настроек»

Сразу видно, что в компоненте можно менять, одной строкой чипов; живые образцы уже стоят выше на странице. Чипы и полный список строятся из сгенерированного API, поэтому не расходятся с кодом и не требуют ручных таблиц. Полный список свёрнут в одну строку на каждой странице, а не развёрнут на двух.

Источники, проверено 2026-10-12 на dev (f8998fe2). Таблицы: разбор каждой table.tbl в ds-docs/src/app/sections/**/*.html по заголовкам колонок (скрипт в scratchpad), классы назначены вручную по шапке. API: shared/component-api.generated.ts прочитан целиком в node; число чипов - входы с union или boolean, кроме aria* и type. Рендер: docs-section.component.html выводит docs-component-meta для компонентов и docs-api-table только для serviceNames(). Высоты страниц и таблиц измерены в Chrome на localhost:4300 (/charts/chart, /components/button, /components/toast), окно 1807px. Строки таблицы dsColumnSeries - из charts/chart/chart.section.html; стиль таблицы перенесён из docs-section.component.scss. Высоты блока входов на фрагментах меряются в этой странице при открытии на ширине 640px.
