ds-date-picker получил потолок ширины

Ответ нести в чат: «Acc2 · pp-ревью и Dashboard Review»

Слева dev, справа ветка feat/date-picker-width. По умолчанию поле уже было шириной своего формата даты (маска в моноширинном шрифте), это не менялось. Новое: --ds-date-picker-max-width останавливает поле с fullWidth на заданной ширине, например в широком диалоге.

Ширина по формату уже была на dev: :host { width: fit-content } и size у input = длина маски + 1, шрифт значения JetBrains Mono. Поэтому ветка добавляет только потолок: max-width: var(--ds-date-picker-max-width, 100%) на хосте; min-width: min-content по-прежнему сильнее, маска не обрезается.

mm-ecm: обёртка app-date-field всегда ставит fullWidth, поэтому в диалоге разархивации поле растягивается и там стоит display: inline-block. С токеном это --ds-date-picker-max-width на месте вызова, либо убрать fullWidth из обёртки там, где поле не должно тянуться.

Снято с ds-docs на ветке (ng serve, порт 4431), раздел Date picker, блок «Size · full width», окно 1423 на 861, масштаб 1,6875. «Было» снято на той же сборке с файлами стилей и демо из dev, подложенными на время; в коммит это не вошло.
