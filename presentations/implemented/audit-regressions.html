Как сделано и как мерил

Колбэк общего ResizeObserver и MutationObserver теперь сначала спрашивает у всех хостов isNeeded() (там isClipped()), потом пишет все tabindex. Проба tooltip-tab-stop получила случай: три хоста в одной пачке, порядок «read read read write write write»; на dev она падает с «read write read write read write».

Замер: ng build ds-docs трёх деревьев с временным крючком window.__injectTruncate (откатан, в коммиты не попал), раздача статикой, вставка 500 строк в демо truncate (1000 обрезанных значений), PerformanceObserver longtask 3 с, время колбэка через обёртку ResizeObserver. В dev-режиме ng serve задача 3-9 с от рендера Angular, этим числам верить нельзя. Включённое дерево доступности (снимок до вставки) на dev: 228 мс, тоже не причина.
