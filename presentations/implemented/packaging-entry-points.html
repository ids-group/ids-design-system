Корневой фасад тоже ничего не стоит. 138,37 против 138,36 — собранный фасад это 5 272 байта из 74 строк export * from и больше ничего, бандлер видит его насквозь. Поэтому миграции нет: потребитель импортирует из корня, как раньше, и получает тот же бандл.

РЕШЕНО и построено — D

74 entry point, корень остаётся фасадом. Потребитель не переписывает ни одного импорта, а стартовый бандл падает на 42%. Влито в dev мержем a18d20c4.

Форма — короткие алиасы, дека «Форма точки входа». Глубокие специферы работают, но не рекомендуются: байтов они не дают, и корневой импорт остаётся поддерживаемым спеллингом.

Во что D обошёлся на самом деле

Entry point74
Импортов переписано на специфер пакета318 в 93 файлах
Циклов разорвано3 — radio → radio-group/radio, time-columns → time-picker/time-columns, а core ↔ icons переносом icons.data.ts → core/icon-names.ts
Первичный ng-package.jsonпереехал в src/lib — module id точки входа это её путь относительно первичного
Символов стало публичными37, все помечены @internal
Потеряно из публичного API0
Дублей классов в пакете0

Соседние папки «со-локировать» нельзя: entry point — это директория. И оба ребра core → icons были import type — они всё равно считаются: ng-packagr ищет цикл через resolveModuleNames, куда TypeScript заходит и за типами.

Единственное, ради чего глубокий специфер всё-таки нужен

Обычные ленивые роуты раскладываются и через корень — это замерено выше. Исключение одно: @defer. Этот код компилируется без предупреждений и ничего не откладывает: 

import { TableComponent } from '@ids-group-ltd/ids-design-system';   // ← через корень

@defer (on viewport) { <ds-table [columns]="cols" [data]="rows" /> }

Одна строка — и откладывается по-настоящему:

import { TableComponent } from '@ids-group-ltd/ids-design-system/table';
через корень 154 КБ · 1 файл
глубокий специфер 123 КБ · 4 файла

Обратная сторона F, и её надо знать

Приложению, которое рисует почти всё сразу, F делает хуже — откладывать нечего, а обёртки модулей стоят места. Собрал ds-docs обеими формами:

сплющено 239 КБ
F 248 КБ · +3,8%

То есть F — не бесплатное улучшение для всех, а сдвиг в пользу тех, у кого ленивые роуты. Для потребителя вроде mm-broker это ровно цель; для витрины — небольшой минус.
