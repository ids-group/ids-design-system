ds-button · press animation — текущая и альтернативы

Было (карточка «0»): нажатие = затемнение фона (--primary-pressed) + слабое halo-кольцо, без движения. Сейчас в либе — F: затемнение + микро-scale (.98), halo выключен по умолчанию (опц. через --ds-button-pressed-shadow). Ниже — варианты на тех же токенах (transform / filter / box-shadow / opacity — дёшево по перфу, без скевоморфизма и JS). Зажми и подержи кнопку, чтобы почувствовать. Под prefers-reduced-motion движение гаснет (цвет/яркость/прозрачность остаются — это не движение).

0 · Было (до F)

Фон темнеет + faint halo-кольцо. Без движения — спокойно, но «плоско», нажатие почти не ощущается. Так было в либе до перехода на F.

&:active {
  background: var(--primary-pressed);
  box-shadow: 0 0 0 3px
    color-mix(--primary-pressed 35%);
}

0b · Только затемнение

Минимум: только фон темнеет, без halo и без движения. Чисто и спокойно — частый дефолт DS. Отличие от «0» — убрано halo-кольцо.

&:active {
  background: var(--primary-pressed);
}

A · Scale-down

Кнопка сжимается до .96 — каноничный тактильный «клик». 80ms ease-out. Самый дешёвый способ дать ощущение нажатия.

&:active {
  transform: scale(0.96);
  background: var(--primary-pressed);
}

B · Brightness

Затемнение фильтром (brightness(.88)) — одна строка, темнит кнопку целиком (фон+текст+иконку), работает на любом варианте. Без движения.

&:active {
  filter: brightness(0.88);
}

C · Inset (вдавленная)

Две внутренние тени — тёмная сверху + светлый блик снизу — кнопка читается как утопленная «лунка», а не просто темнее. Без сдвига позиции (раскладка не прыгает).

&:active {
  background: var(--primary-pressed);
  box-shadow:
    inset 0 4px 6px -1px color-mix(black 60%),
    inset 0 -3px 5px -2px color-mix(white 35%);
}

D · Squish

Резиновое сжатие — шире и ниже (scale(1.05, .88)), пружинный возврат (--ease-spring). Игривый, для брендов с характером.

transition: transform 180ms
  var(--ease-spring);
&:active { transform: scale(1.05, 0.88); }

E · Spring

Глубокое сжатие до .9 и пружинный overshoot-возврат на отпускании. Заметнее scale, чуть «живее».

transition: transform 180ms
  var(--ease-spring);
&:active { transform: scale(0.9); }

F · Затемнение + микро-scale в либе

Минимальное затемнение + едва заметное сжатие до .98. «0b с щепоткой тактильности» — спокойно, но нажатие ощущается. Выбрано и в либе (icon-button — scale .96).

&:active {
  background: var(--primary-pressed);
  transform: scale(0.98);
}

G · Opacity dip

Самый быстрый и тихий — кратковременное приглушение прозрачностью (.72). Универсально, но «дешевит» — фидбек слабее цвета.

&:active {
  opacity: 0.72;
}

Гайдлайны (ui-ux-pro-max + web): press-фидбек — 80–120ms ease-out (быстрее hover); анимировать только transform/opacity (не размеры); prefers-reduced-motion обязателен; не перегружать (1 движение на нажатие).
Рекомендация: спокойно/минимально — 0b (только затемнение), B (brightness) или G (opacity). Тактильно, но сдержанно — F (затемнение + scale .98) или C (inset). Заметнее «нажал» — A (scale .96). Игриво, под характерный бренд — D / E. Всё можно положить на токены: --ds-button-press-* (новый слой) или включать через тему.
