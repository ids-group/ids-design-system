Две колонки с одной подписью: убрал первую - на её место едет не та

Одно решение: как график узнаёт колонку между обновлениями данных.

Ответ нести в чат: «Acc2 · Дека движения графиков»

Сцена

данные до

[{ label: 'Jan', value: 30 },  // 2025
 { label: 'Feb', value: 50 },
 { label: 'Jan', value: 90 },  // 2026
 { label: 'Mar', value: 70 }]

данные после

[{ label: 'Feb', value: 50 },
 { label: 'Jan', value: 90 },  // 2026
 { label: 'Mar', value: 70 }]
  • Убираем первую «Jan» (30); верно: она гаснет, остальные три сдвигаются влево.
  • Каждая колонка своего цвета (color у точки), чтобы было видно, чья колонка куда едет.
  • Тайминги из токенов: сдвиг --ds-motion-chart-mark-duration, угасание --ds-motion-chart-mark-exit-duration; подписи оси одинаковы во всех карточках.

Пять вариантов

сейчас в dev

По подписи с номером повтора

ECharts, DS сейчас

Jan 30 → место 2-й Jan, растёт до 90 · Jan 90 гаснет · Feb, Mar к своим

  • Колонка 2025 едет через Feb и становится 2026-й, настоящая 2026 гаснет.
  • Ключ «Jan», «Jan#1»: второй «Jan» узнаётся по номеру, а номер сдвинулся.

По месту в массиве

Chart.js, Recharts по умолчанию, D3 по умолчанию, Highcharts без id

1-я → Feb · 2-я → Jan 90 · 3-я → Mar · 4-я гаснет

  • Никто не пересекается, но каждая колонка меняет высоту и цвет.
  • Сортировка без id перестаёт ехать: столбцы перерисовываются на месте.

Только по подписи

Nivo

Jan 30 исчезает без анимации · Jan 90, Feb, Mar к своим

  • У обеих ключ value.Jan: выигрывает последняя с этим ключом.
  • Убери вторую «Jan» - на место первой едет 2026-я: верно только случайно.

Свой ключ у точки

Highcharts id, ECharts id, Recharts animationMatchBy, D3 функция ключа, Vega key

jan-2025 гаснет · jan-2026, feb, mar к своим

{ id: 'jan-2025',
  label: 'Jan', value: 30 },
{ id: 'jan-2026',
  label: 'Jan', value: 90 },
  • В DS это уже есть: поле id у точки, отдельный key не нужен.
  • Без id остаётся то, что выбрано по умолчанию.
рекомендую

По подписи и предупреждение в консоли

DS: «как сейчас» + проверка в dev

[ds-column-chart] label "Jan" repeats; pass id to keep each column

  • Без id движение как «По подписи с номером повтора» (нарисовано), плюс строка в консоли в dev.
  • С id движение как «Свой ключ у точки».

Рекомендую: «По подписи и предупреждение в консоли»

  • При разных подписях ничего не меняется: сортировка и фильтр едут как сейчас.
  • Единственный неверный случай, повтор подписи без id, называется в консоли вместе с лекарством.
  • Лекарство уже в API: поле id у точки, как id у Highcharts и ECharts.
