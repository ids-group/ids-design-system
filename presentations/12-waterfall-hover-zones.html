Источники, проверено 2026-09-29. Waterfall кладёт столбцы через dsColumnSeries (waterfall-chart.component.html:55), ширину зоны задаёт .hit-area в chart/column-series.component.scss, высоту - hitBox() в column-series.component.ts (у плавающего столбца зона равна его пролёту). Замер на docs dev-сервере, Chrome 1400px, первый waterfall страницы, getBoundingClientRect пяти .hit-area: на dev ширина 51.9-52.0px при шаге около 196.8px, между зонами около 145px пустоты; в ветке fix/chart-contiguous-hover 196.7-196.8px, правый край каждой зоны совпадает с левым краем следующей. Высоты в обоих случаях 239.9, 61.9, 40.0, 24.0, 160.0px, то есть по пролёту столбца. Графики в деке нарисованы заново на токенах ds.css; счётчик под каждым считается в странице из тех же прямоугольников.
