ds-column-chart не может заменить график-фильтр консьюмера: нет пустого значения, подписи под столбиком и выбора

Ответ нести в чат: «ME-491/493/465: фиксы Analyze и Prepare»

Одно решение: какой формой API ds-column-chart получает вторую строку подписи и постоянный выбор столбиков. Пустое значение решается однозначно и описано ниже.

Нужно решениеновое API column-chartактуально на 2026-10-06

Что консьюмер рисует сам, потому что column-chart не умеет

Распределение по децилям: процент над столбиком, под ним имя дециля, диапазон значений и число людей. Клик по столбику фильтрует таблицу под графиком, выбранная группа «Deciles 1-3» подсвечена, остальные бледнее. У дециля, где никто не был контактирован, процента нет - «—».

Так этот график выглядит в консьюмере сегодня - собран самописной разметкой. Число под столбиком - сколько людей в дециле, подсказка над ним говорит «N policyholders».

Пустое значение: value: number | null

Сегодня ColumnChartPoint.value - только число (column-chart.types.ts:9), поэтому «нет данных» консьюмер может передать только нулём, а ноль читается как «0%». Делаю так: null рисует пустую категорию без столбика, над ней «—», в data table и описании для скринридера - «no data». Вариантов с разной ценой тут нет. Скажи, если не согласен.

Подпись и выбор: три способа

Во всех трёх карточках одна и та же задача - график выше - записана так, как её писал бы консьюмер. Под кодом - что получится. Выбор - клик по карточке.

Рекомендация

Поля точки. Всё, что относится к столбику, лежит в его точке: значение, подпись, выбран ли он. Data table и описание для скринридера берут caption оттуда же, без дублирования, а выбранный столбик получает aria-pressed.

Цена: два новых необязательных поля в ColumnChartPoint и постоянное приглушение невыбранных, когда хоть один selected. Это minor. Без выбора график ведёт себя как сегодня.
