C · Toast по тапу на заблокированную кнопку

Bottom bar не растёт - причина показывается toast'ом, когда пользователь тапает по disabled-кнопке (нужна обёртка, ловящая тап, т.к. disabled не эмитит клики). Минус: скрытая аффордансность - пользователь должен догадаться тапнуть по неактивной кнопке; спека же требует показывать текст в disabled-состоянии, а не по действию.
