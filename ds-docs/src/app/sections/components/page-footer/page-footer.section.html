Layout helper for page-bottom rows. Three variants: default (border-top + spread), compact (subtle card), save (brand-tinted unsaved-changes bar). Project into brand, nav and actions (in that order, then the default slot); the row spreads them with space-between and wraps.

The host has no role: wrap it in <footer> for a landmark, and announce an unsaved-changes bar yourself. Tokens: --ds-page-footer-bg-color, -border-color, -save-bg-color, -save-border-color, -radius.
