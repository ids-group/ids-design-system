Empty state

The base component for any "nothing-to-show" state. One icon, a title that names what is missing, one sentence of body, and at most two actions. For richer scenarios (loading overlay, error retry, permission denied) see Patterns › Empty-state variants.

Truncation
  • Title Wraps to a second line if needed. Never clip — the user needs the full sentence to understand the state.
  • Body Wraps, no clip. Capped at ~360 px via max-width so a long sentence doesn't span the full card width.
  • CTA label Short verb phrases only (Retry, Allocate resources). If the action needs a sentence, the empty state copy is wrong.
  • Icon Fixed 28 px inside a 64 px rounded tile. Doesn't scale with title length — always centred above the title.
