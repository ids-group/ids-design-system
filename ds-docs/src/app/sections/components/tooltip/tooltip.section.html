An unbreakable value, such as a file name or ID, breaks inside --ds-tooltip-max-width (240px) instead of overflowing.

The light theme has a light, bordered panel. For the dark inverted one, set three hooks on :root: 

:root {{ '{' }}
  --ds-tooltip-bg-color: var(--surface-inverted);
  --ds-tooltip-text-color: var(--text-inverted);
  --ds-tooltip-border-color: transparent;
{{ '}' }}

Only while clipped

dsTooltipWhenClipped shows the tip only while the host is clipped, re-tested on every open. Without dsTooltip it shows the host's own text. dsTooltipTextSelector aims the clip test and text at a descendant; no match, no tip.

A clipped host that cannot take focus (a label in a button, a cell of a clickable row) opens when keyboard focus lands on its nearest focusable ancestor, and closes on its blur, a click or any key. That ancestor must be a Tab-reachable control: native, or a widget role (button, link, tab, option, row, combobox). A focusable container (tab panel, scroll region), a negative tabindex or a click opens nothing. Only the first clipped value per control opens.
