Pin on click

dsTooltipPinOnClick opens at once on hover and focus, and a click keeps the tip open after the pointer leaves. A click outside, Escape or blur closes it; a second click on the trigger too. Opt in only where the click does nothing else: without it a click closes the tip.

Info hint

<ds-info-hint> is an icon button with an ariaLabel ; its text shows on hover and focus and pins on click. The icon is a question mark; icon="info" draws an "i" instead.

Definition term

dsDefinitionTerm="…" on any element marks a term with a dotted underline and shows its definition on hover and focus; a click pins it. On a <span> it adds tabindex="0" , role="button" and Enter / Space; a <button> has those already. [pinOnClick]="false" where the click already acts, as on a sortable ds-table header.

Trigger states

Hover makes the underline solid and darker; a press tints the term; a pinned tip paints its trigger in the accent until it closes. The pinned trigger carries data-ds-tooltip-pinned , which any dsTooltipPinOnClick host can style. No state changes the size of the term, so the line around it never moves.

Only while clipped

dsTooltipWhenClipped shows the tip only while the host is clipped, re-tested on every open. Without dsTooltip it shows the host's own text. Give it a selector, dsTooltipWhenClipped=".label", to aim the clip test and text at a descendant; no match, no tip.

A clipped host that no keyboard path reaches - not focusable, inside no control, holding no control - takes tabindex="0" while it is clipped, so Tab stops on it and opens the tip. Text that fits is skipped, and the stop goes once a resize or a text change lets it fit. A tabindex you set is never touched; set tabindex="-1" to keep a clipped value out of the Tab order.

A clipped host that cannot take focus (label in a button, cell of a clickable row) opens when keyboard focus lands on its nearest focusable ancestor; blur, a click or any key closes it. That ancestor must be a Tab-reachable control: native, or a widget role (button, link, tab, option, row, combobox). Focus on a container (tab panel, scroll region) opens nothing, so a clipped value inside one takes its own tab stop; a click opens nothing. Only the first clipped value per control opens.
