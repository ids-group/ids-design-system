Long value · breaks inside the max width
Anchor

A value with no place to break, a file name or an ID, breaks inside --ds-tooltip-max-width (240px) rather than running past the panel.

On the light theme the panel is light, with a border. To keep the dark, inverted panel, set the three hooks on :root: 

:root {{ '{' }}
  --ds-tooltip-bg-color: var(--surface-inverted);
  --ds-tooltip-text-color: var(--text-inverted);
  --ds-tooltip-border-color: transparent;
{{ '}' }}

Live demo

Hover or tab into a button. The tip opens after dsTooltipDelay (120 ms) and hides at once; Escape closes it. With no room on the dsTooltipPlacement side it opens on the opposite side, 8px clear of the viewport edge, with its arrow turned to match.

Only while clipped

dsTooltipWhenClipped shows the tip only while the host is cut off (re-tested on every open, so it follows a resize). Without dsTooltip it discloses the host's own text. dsTooltipTextSelector points the clip test and the disclosed text at a descendant; while nothing matches, no tip opens.

A clipped host that cannot take focus (a label in a button, a cell of a clickable row) opens when keyboard focus lands on its nearest focusable ancestor, and closes on that ancestor's blur, a click or any key. The ancestor must be a control (native, or a widget role such as button, link, tab, option, row, combobox) reachable by Tab. A focusable container (tab panel, scroll region), a negative tabindex or a click opens nothing. Only the first clipped value in one control opens.
