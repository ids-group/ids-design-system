Only while clipped

dsTooltipWhenClipped shows the tip only while its host is cut off, re-tested on every open, so it follows a resize. On its own, with no dsTooltip, it discloses the host's own text. The pickers use it for their labels.

A clipped host that cannot take focus itself, like a label inside a button or a cell of a clickable row, opens when keyboard focus lands on the nearest focusable ancestor, and closes on its blur, a click or any key. That ancestor has to be a control: a native one, or an element with a widget role such as button, link, tab, option, row or combobox. A container that takes focus, like a tab panel or a scroll region, opens nothing, and neither does an ancestor focusable only through a negative tabindex. A click alone opens nothing either. Of several clipped values in one control only the first opens.
