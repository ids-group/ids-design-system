Menu

Inline list of actions. Used inside modals, popovers, or any container that already provides its own surface. Each item is a full-width button with an optional leading icon. danger turns the item red for destructive actions (Sign out, Delete); disabled dims it and blocks clicks. A floating-overlay variant triggered from a button is a follow-up.
