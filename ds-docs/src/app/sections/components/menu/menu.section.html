Inline list of actions. Used inside modals, popovers, or any container that already provides its own surface. Each item is a full-width button with an optional leading icon. error turns the item red for destructive actions (Sign out, Delete); disabled dims it and blocks clicks. To float it from a trigger, host it in a ds-popover — see the first demo.

Trigger-opened (overlay)

The real usage — a button opens the menu in a ds-popover. Selecting an item closes the overlay automatically (the item finds it via DI, no wiring needed). Click outside or press Esc to dismiss.

Standing description

description puts a second line under the label for a limitation the action carries. Unlike a [dsTooltip] , it is visible without hover or focus — which is the whole point of a caveat like "will not be saved".
It reaches assistive tech as aria-describedby , not as part of the item's name: the label names the action, the description describes it. So a screen reader announces "Export as CSV" and then the caveat, rather than one run-on name.
