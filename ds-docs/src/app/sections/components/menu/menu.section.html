Components

Menu

Inline list of actions. Used inside modals, popovers, or any container that already provides its own surface. Each item is a full-width button with an optional leading icon. danger turns the item red for destructive actions (Sign out, Delete); disabled dims it and blocks clicks. To float it from a trigger, host it in a ds-popover — see the first demo.

Trigger-opened (overlay)

The real usage — a button opens the menu in a ds-popover. Selecting an item closes the overlay automatically (the item finds it via DI, no wiring needed). Click outside or press Esc to dismiss.
