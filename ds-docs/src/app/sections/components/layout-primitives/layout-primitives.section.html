Stack, Inline and Container: token-aware wrappers in place of one-off flexbox utilities.

Stack

Vertical column. gap: none · xs · sm · md · lg · xl ; align : start · center · end · stretch. Unset gap reads --ds-stack-gap .

Inline

A horizontal row: tags, button groups, filter chips.

  • gap , align - Stack's values; items centre vertically by default. Unset gap reads --ds-inline-gap .
  • justify - start · center · end · between .
  • Wraps by default; [wrap]="false" keeps one line and overflows.
