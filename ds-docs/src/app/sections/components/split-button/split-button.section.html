Combines a primary action button with a dropdown of secondary actions in a single cohesive control.

Primary variant

The main action fires immediately; the chevron reveals alternative actions. Last triggered action is shown below.

Outline variant

Use the outline variant when the split button sits alongside a primary action.

Without menu items

An empty [menuItems] disables the chevron: one that opens an empty panel reads as a broken control. A dev-mode warning says so, and a single action belongs in ds-button instead.
