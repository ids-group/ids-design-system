Hover surface

separator="slash" with --ds-breadcrumbs-bg-color-hover , --ds-breadcrumbs-padding and --ds-breadcrumbs-radius makes each crumb a pill on hover.

Type, gap and clip width

--ds-breadcrumbs-font-size , --ds-breadcrumbs-font-weight , --ds-breadcrumbs-current-label-font-weight , --ds-breadcrumbs-gap , --ds-breadcrumbs-label-max-width and --ds-breadcrumbs-current-label-max-width resize the trail; here larger font, wider gap, labels capped at 8ch.

Clipped label

Labels past 16ch (current page 32ch ) get an ellipsis and a full-label tooltip on hover or keyboard focus. Labels that fit get none.

Non-clickable

Service-driven (route-aware apps)

  • No [items] - reads BreadcrumbsService.items, fed from route data or an effect.
  • providedIn: 'root' : a trail persists across routes; each page calls set (or clear).
  • push , pop, replaceLast - edit the end of the trail.
