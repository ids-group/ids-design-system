Trail to root. The last item is the current page (no href). With [maxItems], middle segments collapse to … N more; without it a long trail clips from the end.

Default

Four levels — leaf is the current page, bold and non-interactive.

Long trail · ellipsis collapse

[maxItems]="4" keeps the first and last crumbs and collapses the middle into one crumb that says how many it hides. Set it on any trail that can get deep: the row is nowrap + overflow: hidden, so an uncapped trail clips from the end - the current page.

Single level

Root + leaf - the shortest meaningful trail.

Icon crumb

A BreadcrumbItem may carry an icon. An icon-only crumb needs an ariaLabel; dev mode warns without one.

Custom separator

Default separator is chevronRight. Override via the [separator] input or globally via provideDsConfig({{ '{' }} breadcrumbs: {{ '{' }} separator: 'arrowRight' {{ '}' }} {{ '}' }}) .

Hover surface

separator="slash" with --ds-breadcrumbs-bg-color-hover, --ds-breadcrumbs-padding and --ds-breadcrumbs-radius set turns each crumb into a pill on hover.

Type, gap and clip width

--ds-breadcrumbs-font-size, --ds-breadcrumbs-font-weight, --ds-breadcrumbs-current-label-font-weight, --ds-breadcrumbs-gap, --ds-breadcrumbs-label-max-width and --ds-breadcrumbs-current-label-max-width resize the trail; here the font is larger, the gap wider and the label width capped at 8ch.

Clipped label

A label past 16ch (the current page past 32ch) ends in an ellipsis, and hovering it or focusing its link from the keyboard opens a tooltip with the whole label; a label that fits opens none.

Modified clicks

A plain primary click on a crumb link prevents the default and emits (navigate); a Ctrl, Cmd, Shift or Alt click, or any non-primary button such as the middle one, leaves href to the browser (a new tab or window) and emits nothing. Bind (navigate) and route with Router.navigateByUrl(item.href); unbound, a plain click does nothing.

Non-clickable

[clickable]="false" disables item activation - useful for read-only trails (audit logs, archived snapshots) where you want the path visible but not navigable. Unset follows DS_CONFIG.breadcrumbs.clickable, then true.

Service-driven (route-aware apps)

Omit [items] and the component reads from BreadcrumbsService.items - apps push crumbs from route data or an effect when the page model resolves. The service is providedIn: 'root', so a trail persists across routes until replaced: each page calls set (or clear). push, pop and replaceLast edit the end of the trail.

import {{ '{' }} BreadcrumbsService {{ '}' }} from '@ids-group-ltd/ids-design-system/components/breadcrumbs';

this.crumbs.set([

  {{ '{' }} label: 'Records', href: '/records' {{ '}' }},
