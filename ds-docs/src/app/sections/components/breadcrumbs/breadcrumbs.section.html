Breadcrumbs

Trail to root. The last item is the current page (no href). Middle segments collapse to … before the leaf clips.

Default

Four levels — leaf is the current page, bold and non-interactive.

Long trail · ellipsis collapse

Six original levels collapsed to root · … · parent · leaf. The middle "…" is a static glyph; the live affordance would be a menu trigger that re-expands.

Full path: Workspace · Clients · Acme Co. · Policies · 2026 Cycle · P-12894

Single level

Root + leaf — the shortest meaningful trail. Anything shorter renders no breadcrumb at all.

Custom separator

Default separator is chevronRight. Override via the [separator] input or globally via provideDsConfig({{ '{' }} breadcrumbs: {{ '{' }} separator: 'arrowRight' {{ '}' }} {{ '}' }}).

Non-clickable

[clickable]="false" disables item activation — useful for read-only trails (audit logs, archived snapshots) where you want the path visible but not navigable.

Service-driven (route-aware apps)

Omit [items] and the component reads from BreadcrumbsService.items — apps push crumbs from route data or an effect when the page model resolves. 

{{ '// in a page component or route effect' }}
import {{ '{' }} BreadcrumbsService {{ '}' }} from 'ds';
private readonly crumbs = inject(BreadcrumbsService);
this.crumbs.set([
  {{ '{' }} label: 'Workspace', href: '/' {{ '}' }},
  {{ '{' }} label: 'Records', href: '/records' {{ '}' }},
  {{ '{' }} label: 'P-12894' {{ '}' }},
]);

{{ '// template — items input omitted, reads from service' }}
<ds-breadcrumbs />

Truncation

Truncation
  • Item label Single line, ellipsis at long labels. Tooltip on hover when clipped.
  • Separator Single glyph (slash or chevron) — no clip.
  • Current item Bold; truncates last if overflows total width.
