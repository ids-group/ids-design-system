Long labels

A label too long for its space is cut with an ellipsis, and hovering it shows the whole text in a tooltip; a label that fits shows none. That covers the trigger value and every option, so a [title] that repeats the label is not needed; keep one only where it says more than the label.

Option groups

options also takes SelectOptionGroup entries (label, options, optional disabled), mixed with flat options; isSelectOptionGroup() tells them apart. loading shows a spinner in the panel and sets aria-busy; dsEmptyTemplate replaces the "no options" row. The projected dsOptionTemplate, dsGroupLabelTemplate, dsPanelHeaderTemplate and dsPickerTrigger are demoed in Multi-select.

Helper / error text

Clearable

Add clearable to show an ✕ button inside the trigger when a value is set. Clicking it resets the value without opening the panel.

Per-option icons

Add an icon property to each SelectOption . The icon appears in both the option list and the trigger when that option is selected.

Type-ahead, and the cursor staying in view

Typing a letter on the closed trigger selects the first option starting with it, like a native <select>; repeating it cycles. With the panel open the same keys move the cursor and the active row scrolls into view; scrollActiveIntoView="false" hands scrolling back to you.

PageDown/PageUp move ten rows; Home/End go to the first/last enabled option. Hover sets the active row but never scrolls.

A panel footer, and a reason an option is off

dsPanelFooterTemplate puts a strip under the options, outside the listbox so it is not counted as one. An option's disabledReason is announced through aria-describedby — the row already looks disabled, the sentence is for whoever cannot see it.

Clearing from outside

clear() empties the value from a template reference (a reset-filters button) and closes an open panel, without moving focus. Follow it with blur() where the host moves on; it drops focus from the control and leaves an open panel alone.
