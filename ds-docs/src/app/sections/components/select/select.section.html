Alternative trigger that opens a fully styled popover via CDK Overlay. Use when the showcase or product needs branded options, leading icons, or a consistent panel across browsers. <ds-select> is the form-field variant of the same CDK Overlay engine — use it inside Angular forms where you need a label, required/optional markers, and grouped options.
