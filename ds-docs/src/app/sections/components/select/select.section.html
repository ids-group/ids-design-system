Long labels

A label too long for its space is cut with an ellipsis, and hovering it shows the whole text in a tooltip; a label that fits shows none. That covers the trigger value and every option, so a [title] that repeats the label is not needed; keep one only where it says more than the label.

Use when the showcase or product needs branded options, leading icons, or a consistent panel across browsers. <ds-select> is the form-field variant of the same CDK Overlay engine — use it inside Angular forms where you need a label, required/optional markers, and grouped options.

Per-option icons

Add an icon property to each SelectOption . The icon appears in both the option list and the trigger when that option is selected.

Type-ahead, and the cursor staying in view

Typing a letter on the closed trigger jumps to the first option starting with it and commits, the way a native <select> does; repeating the letter cycles. With the panel open the same keys move the cursor, and the active row scrolls itself into view — try ArrowDown through this list, which is longer than the panel. scrollActiveIntoView="false" hands the scroll position back to you.

PageDown and PageUp move ten rows — the native <select> step, a fixed number rather than a measured screenful so the jump does not change with the panel's height. Home and End go to the first and last option a reader can actually pick, skipping a disabled one.

The scroll follows the KEYBOARD only. The rows set the active row on hover too, and scrolling for that would pull a half-visible row up under the pointer while you were reading with the mouse — try hovering the bottom row here: nothing jumps.

A panel footer, and a reason an option is off

dsPanelFooterTemplate puts a strip under the options, outside the listbox so it is not counted as one. An option's disabledReason is announced through aria-describedby — the row already looks disabled, the sentence is for whoever cannot see it.

Clearing from outside

clear() empties the value from a template reference — a "reset filters" button, a form the app clears itself. All three pickers have it now; ds-autocomplete was the only one before, so an app with its own reset had to write the empty value by hand and guess what empty means for each control. It deliberately does not move focus; where the host moves on after clearing, follow it with blur() , the counterpart of focus() that every field control has. It drops focus from whichever part of the control holds it and leaves an open panel alone.
