Keeping the tab in the URL

urlParam="tab" keeps the active tab in ?tab=<name> , surviving reload, sharing and Back. Inert outside a routed context. 

<ds-tabs urlParam="tab">
  <ds-tab label="Profile"  value="profile" />
  <ds-tab label="Activity" value="activity" />
</ds-tabs>

<!-- second tab active -->  ?tab=activity
  • Name - the tab's value, else a slug of its label ("License Verification Status" gives license-verification-status ).
  • Set value so a rename keeps links; without it, tabClosed emits the raw label, not the slug.
  • The first tab writes no parameter; writes replace history; an unknown name opens the first tab.
  • Query-only writes skip ds-app-layout's pathChanged scroll reset.
  • One strip per parameter name (tab, subtab ); dev mode warns on a clash.

Reopening the last tab

rememberLastTab (needs urlParam ) reopens the last tab per path from sessionStorage . A link wins; storage failures are ignored.
