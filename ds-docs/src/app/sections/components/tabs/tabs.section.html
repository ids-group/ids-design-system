Switch among peer panels. Two visual variants — line for primary navigation, pills for compact filters. Optional icon and count chip per tab.

Variants

Line — primary navigation. Pills — compact filter row. Pills look like a ds-segmented control but are real tabs (they own content panels, with tablist semantics); for a value/view toggle with no panels, use ds-segmented instead.

When scrollable is set the tab strip clips to its bounds and scrolls horizontally. The active tab is always scrolled into view. Works for both variants.

Closable

When closable is set each tab shows a close button. Clicking it emits tabClosed with the tab's value (or label as fallback). The host is responsible for removing the tab. Closing a tab does not change the active index.

Vertical

Setting orientation="vertical" places the tab list in a column beside the panel. The active indicator runs along the right edge. Arrow-key navigation follows the axis (Up / Down moves between tabs).

Lazy

When lazy is set, each tab's content is instantiated only the first time that tab is activated, then kept alive (not destroyed on switch). Without lazy only the active panel renders (default).
