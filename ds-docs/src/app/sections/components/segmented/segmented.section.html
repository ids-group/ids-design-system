Segmented control switches exclusive views; button group fuses related actions.

Segmented control

Options take optional icon and disabled . One tab stop; arrow keys and Home/End move the selection, skipping disabled segments.

Selected: {{ view() }}

A choice inside a track: the track and its segments draw no border, and the selected segment is a solid --segmented-selected fill, at least 3:1 against the track (--accent in light, --accent-strong-overlay on dark), its label in --segmented-selected-on. A standalone control such as ds-toggle-button draws a --border-field boundary instead.

A form control: binds [formControl] and ngModel ; label , hint and error render like any field.

  • joined - no padded track: segments share one hairline edge, only the outer ends round; a row of filter chips.
  • Needs --ds-segmented-segment-border to draw the shared edge. With no track behind it, a joined row keeps these borders; the selected segment takes the same fill.

Button group

A role="group" wrapper named by ariaLabel , fusing projected ds-button s into one row. Stateless; for an on/off action use ds-toggle-button ([(pressed)], announced via aria-pressed ).
