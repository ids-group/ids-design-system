Top of every page: title, optional subtitle, actions, optional bottom tabs. It renders a <header> with the title as the page's <h1>, so do not add another h1. The Page header pattern documents the page composition around this block.

Title, subtitle and breadcrumb segments are single-line with ellipsis. One status badge per header; beyond two ghost actions and one primary, collapse the rest into an overflow menu. The host class eyebrow-secondary colours the eyebrow --secondary-strong; colours, divider, title/subtitle font size and title gap retune through --ds-page-header-*.
