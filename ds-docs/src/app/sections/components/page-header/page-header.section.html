Top of every page: title, optional subtitle, actions, optional bottom tabs. Renders a <header> with the title as the page's <h1>; do not add another h1. For the surrounding composition see the Page header pattern.

Title, subtitle and breadcrumb segments truncate to one line. One status badge per header; past two ghost actions and one primary, use an overflow menu. Host class eyebrow-secondary colours the eyebrow --secondary-strong ; --ds-page-header-* retunes colours, divider, title/subtitle font size and title gap.
