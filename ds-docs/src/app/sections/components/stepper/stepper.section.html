Multi-step progress from steps (labels) and a zero-based current. Earlier nodes show a check, the current node fills with the accent, later nodes stay outlined numerals. labelPosition="inline" puts captions beside nodes, orientation="vertical" stacks them, and [clickable]="true" makes nodes buttons that emit (stepClicked). [errorSteps] marks steps in error; error wins over every other state.
