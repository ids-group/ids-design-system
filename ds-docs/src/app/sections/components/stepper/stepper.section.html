Multi-step progress: steps (labels) and a zero-based current.
  • Earlier nodes - checked. Current - filled with the accent. Later - outlined numerals.
  • labelPosition="inline" - captions beside nodes.
  • orientation="vertical" - stacks them.
  • [clickable]="true" - nodes are buttons emitting (stepClicked).
  • [errorSteps] - marks errors, which override every other state.
