Visual indicator of multi-step progress. Pass an array of step labels and a zero-indexed current. Nodes before current render as done (with check icon); the current node fills with brand; later nodes stay as outlined numerals. Each label shows beneath its node, with the current step emphasised.

Default

States showcase

current = 0 (just started)
current = 2 (mid-flow)
current = 5 (all done)
