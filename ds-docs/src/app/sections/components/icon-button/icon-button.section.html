Icon-only action with its own variant taxonomy — distinct from <ds-button> . Use for toolbars, table-row actions, close / back / overflow affordances. [ariaLabel] is required (an icon has no text label). This replaces the former ds-button iconOnly flag.

Color × variant

variant = fill taxonomy (standard chromeless · filled · tonal · outlined); color = the shared brand/status hue family (same axis as ds-button ). All combinations are valid.
