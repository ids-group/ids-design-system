Icon-only action with its own variant taxonomy — distinct from <ds-button> . Use for toolbars, table-row actions, close / back / overflow affordances. [ariaLabel] is required (an icon has no text label). This replaces the former ds-button iconOnly flag.

Color × variant

variant = fill taxonomy (standard chromeless · filled · tonal · outlined); color = the shared brand/status hue family (same axis as ds-button ). All combinations are valid. secondary/tertiary default to --primary; shown recoloured (orange / violet) below so the brand rows read as independent roles.

Sizes

sm 32 · md 40 (default) · lg 48 — aligned with the field / button scale.

Toggle

[selected] renders the pressed state and sets aria-pressed. Click to flip.

Disabled

Disabled is a muted tint of the variant's own colour (derived via oklch() ), not a flat grey. Chromeless standard stays boxless — muted icon only.
