Icon-only action for toolbars, row actions and close/back/overflow.

Color × variant

ariaLabel is required. Variants are its own, not ds-button's.

  • filled and tonal take the color tint; standard and outlined stay neutral at rest and tint only when selected.
  • secondary / tertiary default to orange / violet, independent of --primary.

States

Primary colour. Hover, focus and active are pinned via the component's own resolvers.

Toggle

[selected] renders the pressed state and sets aria-pressed, "false" when off; an icon button with no [selected] is no toggle and has none. As a menu trigger, bind [ariaExpanded] and [ariaControls] ; host attributes land on a non-focusable wrapper.

selected = {{ bookmarked() }}

A muted mix of the variant's colour, not flat grey. Only filled (and selected) derives its fill with oklch() ; standard stays boxless, icon muted.
