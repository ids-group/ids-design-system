Headline metric with an optional delta arrow for movement against a baseline.

Stat tiles

Arrow and colour alone show direction; put it in words in deltaLabel or the [delta] slot (e.g. "down 5 vs last week"). deltaTone replaces the up/down colour where direction is not good or bad.

Sizes

[size] scales the value for dense dashboards (sm) or hero KPIs (lg), default md.

A value that is not a number

Project a badge, status dot or other non-text headline into [dsStatValue] ; the tile keeps its geometry and value is the fallback. As with the [delta] slot, projection replaces the input's text - but [delta] still needs a numeric [delta] input to show the row. unit applies only to the input value; put a suffix in the projected content.

Active

A value that is a phrase

The value clips to one line, with the rest in a tooltip on hover, and on focus inside a focusable element. Three hooks compose: --ds-stat-value-white-space: normal wraps, --ds-stat-value-lines: N then ellipsises on line N (only when wrapping), and --ds-stat-value-wrap: anywhere breaks a word wider than the tile.

default

white-space: normal

+ lines: 2

+ wrap: anywhere

Dashed outline: the 240px column.

A formatted number, through Angular's own pipe

value takes string | number | null , so number , percent , currency and date pipes bind directly under strictTemplates . Prefer them to toLocaleString('en-US') , which ignores LOCALE_ID and re-runs every change-detection pass.
