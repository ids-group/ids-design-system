Headline metric, with an optional delta against a baseline.

Stat tiles

  • Arrow and colour alone show direction; put it in words in deltaLabel or the [delta] slot ("down 5 vs last week").
  • deltaTone - replaces the up/down colour where direction is not good or bad.

Sizes

[size] scales the value for dense dashboards (sm) or hero KPIs (lg), default md.

A value that is not a number

  • [dsStatValue] - a badge, status dot or other non-text headline; the tile keeps its geometry, value is the fallback.
  • Projection replaces the input's text, as in the [delta] slot, which still needs a numeric [delta] to show the row.
  • unit applies only to the input value; put a suffix in the projection.
Active

A value that is a phrase

Clips to one line; the rest shows in a tooltip on hover, or on focus inside a focusable element.

Hook Effect
--ds-stat-value-white-space: normal Wraps.
--ds-stat-value-lines: N While wrapping, ellipsises on line N; at line-height: normal , no glyph cut.
--ds-stat-value-wrap: anywhere Breaks a word wider than the tile.

+ lines: 2

+ wrap: anywhere

Dashed outline: the 240px column.

A formatted number, through Angular's own pipe

value takes string | number | null , so number , percent , currency and date pipes bind directly under strictTemplates . Prefer them to toLocaleString('en-US') , which ignores LOCALE_ID and re-runs every change-detection pass.
