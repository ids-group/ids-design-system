Stat tiles

Label · value · optional delta with directional arrow.

Sizes

[size] scales the value typography for dense dashboards (sm) or hero KPIs (lg). Default is md.

A value that is not a number

Project into [dsStatValue] when the headline is a badge, a status dot or anything else a number slot cannot hold — the tile keeps its geometry, so it sits level with the numeric tiles beside it instead of being hand-built. Same shape as the [delta] slot: the input is the fallback. unit applies to the INPUT value only, so put any suffix inside the projected content.
