A value that is not a number

Project into [dsStatValue] when the headline is a badge, a status dot or anything else a number slot cannot hold — the tile keeps its geometry, so it sits level with the numeric tiles beside it instead of being hand-built. Same shape as the [delta] slot: the input is the fallback. unit applies to the INPUT value only, so put any suffix inside the projected content.

A value that is a phrase

The value line is white-space: nowrap, which is right for the number this tile was built around and wrong for a date range or a status phrase — that used to be a reason to reach for the slot above and undo it. Two hooks instead: --ds-stat-value-white-space and --ds-stat-value-font-size, the second working at every size rather than only the default.

Left: both hooks set. Right: the same value untouched — with nowrap and no overflow on the card, the phrase spills straight past the tile's edge. That is the behaviour every existing tile keeps, since the defaults did not move.

A formatted number, through Angular's own pipe

value takes string | number | null, so the number, percent and date pipes bind directly — they are typed string | null, and before the null they failed strictTemplates with TS2322. Prefer this to toLocaleString('en-US') in the template, which pins a locale instead of reading LOCALE_ID and re-runs on every change-detection pass where a pure pipe is cached. These four tiles are the proof: the section compiles under strictTemplates.
