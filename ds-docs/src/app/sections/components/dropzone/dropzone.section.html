Drag-and-drop or click-to-browse file picker with a file list whose upload state and progress the consumer sets.

Live demo

The dropzone holds no files. A pick or drop emits raw files through (filesAdded) ; your handler adds DropzoneFile rows to [files] and updates their state , progress and message . The remove X emits (fileRemoved) for the handler to drop the entry.
