Drag-and-drop or click-to-browse file picker with a file list.

Live demo

It holds no files; your handlers own the list.

  • Pick or drop - (filesAdded) emits raw files; add DropzoneFile rows to [files] , update their state , progress , message .
  • Remove X - (fileRemoved); drop the entry.

Single-file mode

  • multiple off (default) - one file per (filesAdded) ; replace the existing entry.
  • accept - filters the file picker, not drops.
  • hint - under the default text while the list is empty.
  • --ds-dropzone-max-width - caps the width.
