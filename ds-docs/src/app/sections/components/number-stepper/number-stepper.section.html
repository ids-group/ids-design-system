Spinbox for small bounded quantities — increment / decrement buttons around a numeric value. Respects min / max / step . Render via <ds-number-stepper [(value)]="qty"> .

Sizes

Three sizes aligned with input / select field heights.

size="sm"
size="md" · default
size="lg"

Bounds & step

[min] / [max] clamp the value; the buttons disable at the bounds. [step] sets the increment.

min=0 max=10 · value {{ bounded() }}
step=5 · value {{ stepped() }}
