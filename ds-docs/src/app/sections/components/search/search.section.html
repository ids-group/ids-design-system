Debounce, and the two things it must not delay

[debounce]="200" holds each keystroke back before value updates, so a list screen stops firing a request per character. Default 0 writes every keystroke through.

Three things skip the timer: clearing the field, Enter (flushes the pending keystroke, then emits submitted), and the public clear(). For a Clear button outside the control, clear() empties the field, drops the armed keystroke, publishes '' at once and keeps focus in the field.

Writing '' into value is not equivalent: the timer is cancelled only when the incoming text differs from the last pushed value. The displayed text is never delayed. blur() drops focus, the counterpart of focus().

In a form, and disabled

[formControl], formControlName, [(ngModel)] and signal forms all bind, alongside [(value)]. disabled combines with the form's disabled state and paints the disabled surface.

Deliberately no label and no message row. A toolbar filter is not a validated field, and giving it the field chrome would restyle every toolbar it sits in. Where a search needs a label or an error line, that is what ds-input is for.
