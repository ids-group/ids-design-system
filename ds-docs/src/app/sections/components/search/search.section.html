Debounce, and the two things it must not delay

[debounce]="200" delays value updates; default 0 writes every keystroke. The displayed text never lags.

Action Effect
Clearing the field Skips the timer.
Enter Flushes the pending keystroke, then emits submitted.
clear() Empties the field, drops the pending keystroke, publishes '' at once, keeps focus. For an external Clear button.
Writing '' into value Cancels the timer only if it differs from the last pushed value.
blur() / focus() Drops / sets focus.
