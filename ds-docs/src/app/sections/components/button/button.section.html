Two axes: color (brand/status hue family) × variant (solid · tonal · ghost · outline). Loudness is the variant (solid > tonal > ghost/outline); colour is orthogonal. Plus sizes, states, leading icon, subtext, full-width and toggle. For icon-only actions see the Icon button component; for a link-styled action use the global .link class on a button.

Color × variant

Every color × variant combination — all of them render. Defaults are color="primary" variant="solid" . Cells marked ⚠ are UX-discouraged (grey solid reads as disabled; quiet success/warning is too low-contrast) — they work but emit a dev-mode warning; prefer solid/tonal there. variant="text" is a no-chrome, link-styled button — it coexists with the global .link class (last column).

secondary and tertiary are brand hue roles , not fixed colours — their channels default to --primary , so in the default (single-hue) theme all three brand rows are blue. Below they're shown recoloured (orange / violet) to illustrate that a multi-hue brand drives them apart by overriding --secondary-h/s/l / --tertiary-h/s/l .

With subtext

Project a short helper line into the [dsButtonSubtext] slot — e.g. why an action is locked. Purely structural: the button stacks into a column only when the slot has content, and the subtext inherits the button's colour (including the muted disabled tone).
