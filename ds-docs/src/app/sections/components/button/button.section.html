Two axes: color (brand/status hue family) × variant (solid · tonal · ghost · outline). Loudness is the variant (solid > tonal > ghost/outline); colour is orthogonal. Plus sizes, states, leading icon, subtext, full-width and toggle. For icon-only actions see the Icon button component; for a link-styled action use the global .link class on a button.

Color × variant

With subtext

Project a short helper line into the [dsButtonSubtext] slot — e.g. why an action is locked. Purely structural: the button stacks into a column only when the slot has content, and the subtext inherits the button's colour (including the muted disabled tone).
