Loading — all variants

loading keeps the variant fill (not the disabled grey) and tints the spinner with the variant's own label colour, so a loading button stays distinct from a disabled one. Note the auto-contrast: the spinner is dark on warning and neutral-dark on outline, white on the solid fills.

With subtext

Project a short helper line into the [dsButtonSubtext] slot — e.g. why an action is locked. Purely structural: the button stacks into a column only when the slot has content, and the subtext inherits the button's colour (including the disabled grey).
