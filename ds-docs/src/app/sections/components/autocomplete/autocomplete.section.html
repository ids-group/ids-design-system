Typing filters a list to pick one record or a set. Not <ds-select> (fixed-list dropdown) or Command palette (global search).

Use autocomplete for lists too big to scan; ds-multi-select when options fit a checkbox list (it shows the unselected too). The same rule decides against ds-select : both read as pickers, but only autocomplete lets you type.

Capping the chips

maxVisibleChips keeps the trigger one line: "fit" (default) shows what fits plus "+N more", re-split on resize; a number is a ceiling, lowered if narrow; "all" grows the trigger. Same on ds-multi-select . Backspace removes the last selected chip, not the last visible.

Drag the handle to resize.

Width

width="fill" (default) stretches; width="content" hugs chips/value plus a typing area, for toolbars. --ds-autocomplete-input-min-width (default 40px) sizes the typing area; --ds-autocomplete-max-width caps both modes. Long values ellipsise; valueOverflow="wrap" wraps to a second line. Long option labels, create row included, ellipsise with a hover tooltip.

Validation states

hint adds a helper line. error , warning and success show a message; [invalid]="true" is error without one. [disabled]="true" is inert; readOnly is focusable, panel closed.

clearable adds a clear button once set. size sets height (unset: DS_CONFIG.control.size , then 'md' ). [showChevron]="false" suits a search field.

Option groups

Groups mix with flat options, in order. Groups without matches hide.

Create new

allowCreate shows a Create «text» row for text with no exact match, emitting create ; you add the item.

Icons in the options

DsOption (as in ds-select and ds-multi-select ) takes icon (16px, before the label) and disabled (greyed, aria-disabled , unclickable, skipped by arrows). The trigger shows no option icon; its leading slot is [dsAutocompletePrefix] .

dsAutocompletePrefix : trigger start; dsAutocompleteSuffix : after the input, before clear and chevron.

Object values keep their selection

compareWith matches values. The default === drops a selection when a re-fetch returns new objects; compare by identity key. Try Refetch.

Server-side search

filterWith narrows (default: case-insensitive substring of label); 'none' shows options as given: fetch them on (filterChange), which emits each query.
