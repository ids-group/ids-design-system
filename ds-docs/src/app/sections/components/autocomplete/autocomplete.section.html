Text input that filters a token-tagged list. Single-select for picking a record (a Member, a venue); multi-select for picking a set (allowed products, audience tags). Distinct from <ds-select> (fixed-list dropdown) and Command palette (global search).

Autocomplete or ds-multi-select: choose by the list, not the count. Use autocomplete when the set is too big to scan and typing narrows it (a member, a venue, one product of thousands); use ds-multi-select when the options are few enough to read as a checkbox list, which also shows what is not selected.

The same rule decides against ds-select: once a value is chosen, autocomplete collapses its filter input and reads like a picker; opened, it lets you type and ds-select does not.

Capping the chips

maxVisibleChips keeps the trigger one line. "fit" (default) shows as many chips as fit, the rest behind "+N more", re-split on resize; a number is a ceiling, reduced further when the trigger is too narrow; "all" shows every chip and lets the trigger grow. Same input and default on ds-multi-select. Backspace removes the last selected chip, not the last visible one.

Drag the handle to watch the default split move with the width.

Width

Default width="fill" stretches to the container. width="content" hugs the chips/value plus a minimum typing area — for filter toolbars where a full-width trigger looks broken next to one short chip. --ds-autocomplete-input-min-width tunes the typing area (default 40px), --ds-autocomplete-max-width caps the trigger in either mode. A settled single value wider than the trigger ellipsises; valueOverflow="wrap" wraps it onto a second line. An option label too long for the panel, the create row's included, is cut with an ellipsis and shows in full in a tooltip on hover; one that fits shows none.

Validation states

hint renders a helper line below the field. error, warning and success show a message in that state; [invalid]="true" paints the error state without one. [disabled]="true" makes the control inert; readOnly keeps it focusable but stops the panel opening.

clearable adds a clear affordance once there is a value. size sets the trigger height (unset follows DS_CONFIG.control.size, then 'md'). [showChevron]="false" drops the trailing chevron, for a search field.

Option groups

Put groups in the same options input — flat options and groups may be mixed, and render in the order given. Filtering hides a group whose options produce no matches.

Create new

Add allowCreate to show a Create «text» row when the typed text has no exact match. Selecting it emits a create output — the consumer decides how to add the item. In this demo the new tag is appended to the list and auto-selected.

Icons in the options

An option may carry icon (16px, before the label) and disabled (greyed, aria-disabled, unclickable, skipped by the arrow keys) - the same DsOption shape as ds-select and ds-multi-select. Only ds-select repeats the icon in its trigger; here the leading slot belongs to [dsAutocompletePrefix].

Project an element with dsAutocompletePrefix to place it at the start of the trigger, or with dsAutocompleteSuffix to place it after the input, before the clear and chevron.

Object values keep their selection

compareWith decides when two values are the same one. The default is ===, which for an object is reference identity — so a re-fetch returning equal data as new objects would drop the selection. Key the comparator on whatever identifies the value. Press Refetch: the selection survives.

A search placeholder of its own

searchPlaceholder replaces placeholder while typing over a settled value; empty keeps placeholder. Pick a city, then focus the field again.

Server-side search

filterWith decides how the query narrows the list (default: case-insensitive substring of label); 'none' renders every option as given. (filterChange) emits the typed query on every change, so pair it with 'none' and fetch the options yourself. [loading]="true" shows a spinner instead of the empty row and sets aria-busy on the listbox.

Templates

Template directives come from @ids-group-ltd/ids-design-system/components . dsOptionTemplate fills an option row's label area (context: the option); the row's role, selection and check stay library-owned. dsEmptyTemplate replaces the "no matches" row (context: query); the row keeps role="status". dsCreateTemplate fills the create row (context: query); picking it still emits create. dsChipTemplate, dsGroupLabelTemplate, dsPanelHeaderTemplate and dsPanelFooterTemplate fill the chip, the group label and the panel's header and footer.
