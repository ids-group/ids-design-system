Capping the chips

maxVisibleChips keeps the trigger one line. Same on ds-multi-select.

  • "fit" (default) - what fits plus "+N more", re-split on resize.
  • A number - a ceiling, lowered if narrow.
  • "all" - grows the trigger.
  • Backspace removes the last selected chip, not the last visible.

Drag the handle to resize.

Validation states

hint adds a helper line. error , warning and success show a message; [invalid]="true" is error without one. [disabled]="true" is inert; readOnly is focusable, panel closed.

clearable adds a clear button once set. size sets height (unset: DS_CONFIG.control.size , then 'md' ). [showChevron]="false" suits a search field.

Option groups

Groups mix with flat options, in order. Groups without matches hide.

Create new

allowCreate shows a Create «text» row for text with no exact match, emitting create ; you add the item.

Icons in the options

  • DsOption.icon - 16px, before the label (as in ds-select and ds-multi-select).
  • DsOption.disabled - greyed, aria-disabled, unclickable, skipped by arrows.
  • The trigger shows no option icon; its leading slot is [dsAutocompletePrefix].

dsAutocompletePrefix : trigger start; dsAutocompleteSuffix : after the input, before clear and chevron.

Object values keep their selection

compareWith matches values. The default === drops a selection when a re-fetch returns new objects; compare by identity key. Try Refetch.

Server-side search

filterWith narrows (default: case-insensitive substring of label); 'none' shows options as given: fetch them on (filterChange), which emits each query.

  • [loading]="true" - aria-busy on the listbox.
  • No options - three placeholder rows.
  • With options - under a ds-loading-overlay , inert until loading clears.
