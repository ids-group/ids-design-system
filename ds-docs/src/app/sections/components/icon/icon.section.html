Icon

Inline SVG icons rendered through <ds-icon>. 2-px stroke, rounded caps, currentColor fills. Driven by the name input and a fixed size scale.

Sizes

Five canonical sizes. Every glyph renders inside a 24-unit viewBox at stroke-width: 1.75.
