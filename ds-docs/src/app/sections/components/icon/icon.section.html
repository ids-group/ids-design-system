Custom icons

provideDsIcons(icons) registers extra names: each value is the SVG body inside the 24x24 stroke <svg>, without a stroke attribute. Built-in names win on a clash; an unknown name renders nothing and warns in dev mode. Calls add up, including a lazy route's, and a later call wins a shared name.
