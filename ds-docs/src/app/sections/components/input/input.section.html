Sizes

size takes sm , md or lg; unset, it reads DS_CONFIG.control.size , then md .

Clearable

[clearable] shows × on a non-empty field: true for type="search" , false otherwise.

Password toggle

On type="password", [passwordToggle]="true" adds an unmask button; [(passwordVisible)] binds its state two-way.

Character counter

[maxLength] caps length natively and shows current/max at the hint line's right.

Required vs optional

[required]="true" adds a red asterisk; [optional]="true" adds a muted "(optional)". Use one, not both.

Messages: error, warning, hint

One message at a time, so the height is fixed. Highest first: 

error > validation errors > warning > warning-kind errors > success > hint
  • Error - red border and tinted fill.
  • Warning, success - the border only.
  • All nine bordered fields set data-field-state on the host; style against it, not a class.

The glyph on the message line

error , warning and success carry a glyph, not hue alone (WCAG 1.4.1: light-theme warning #8A7400 vs success #156822). hint has none. 

messageIcon > DS_CONFIG.field.stateIcons.<state> > default
  • An icon name replaces the glyph; false removes it.
  • stateIcons: false removes all four; stateIcons.hint adds a glyph to the hint line.

Reserved message row

reserveMessage (default off) holds the message line's height, so validation causes no reflow.

  • The row sits ~23px under the control - stack reserved fields with <ds-stack gap="none"> , or the gap reads as a hole.
  • Whole form - <form dsReserveMessages> provides a merged DS_CONFIG to its subtree; a field's own [reserveMessage] wins.
  • Only fields declared inside the host count; projected content keeps its own template's injector.
