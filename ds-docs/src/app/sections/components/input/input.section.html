With icon · prefix · suffix · floating

Clicking anywhere in the frame — a leading icon, a prefix/suffix add-on, or the padding — focuses the input; only nested controls (a projected button, the clear ✕, the password toggle) keep their own click. Same behaviour on ds-search and ds-textarea .

Clearable

[clearable] shows an inline × button when the field has a non-empty value. Defaults to true for type="search" and false otherwise — pass an explicit boolean to override.

Password toggle

On type="password", [passwordToggle]="true" adds an eye button that flips the field between masked and plain text. Two-way [(passwordVisible)] exposes the state.

Character counter

[maxLength] caps input length natively and shows a live current/max counter below the field — right-aligned, aligned with the hint.

Required vs optional

[required]="true" appends a red asterisk to the label; [optional]="true" appends the muted "(optional)" suffix. They are mutually exclusive — pick one.

Reserved message row

reserveMessage (default on) holds a message line's height even when there's no hint or error, so a form doesn't reflow the moment validation appears. Set [reserveMessage]="false" to collapse it where a shift is fine. The reserved row sits ~23px under the control, so stack reserved fields tighter (≈4px) than bare ones or the gap reads as a hole.
