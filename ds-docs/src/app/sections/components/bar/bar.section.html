One horizontal track with one fill: a task's completion, or a measurement on a known scale.

What the bar is

semantics For Role
'progress' (default) Task completion progressbar
'meter' A measurement: rate, score, count against a ceiling meter
'none' A cell that prints its figure beside it Hidden from assistive technology

Progress and meter bars need an ariaLabel (the role has no name); with a target , name the comparison in it.

In a table cell

  • No chart chrome (caption, legend, annex table), to fit a 60px cell.
  • max - the column's largest value, so the longest bar fills its track.
  • The figure prints beside it, so bars are semantics="none".
{{ asRow(row).rate }}%

Give the cell a width

  • The bar fills its box. In a content-sized box (width: 'content' on ds-table, a shrink-to-fit flex/grid item) it falls back to --ds-bar-min-width (3rem).
  • Set a fixed width; the table above uses 4rem.

Colour

Prefer variant; color overrides one bar's fill. Set the fill tokens in a stylesheet to colour a whole column.

Token Sets
--ds-bar-fill-color Default fill
--ds-bar-fill-color-success / -warning / -error Variant fills
--ds-bar-height , --ds-bar-track-color Track
--ds-bar-target-color , --ds-bar-target-width Target mark
--ds-bar-radius Track and fill together; pill by default, square at var(--radius-0)

Edge cases

  • Past max - fills the track, no overflow.
  • Negative - draws nothing.
  • max of zero or less - falls back to 100.
  • indeterminate - ignored unless semantics is 'progress'.
