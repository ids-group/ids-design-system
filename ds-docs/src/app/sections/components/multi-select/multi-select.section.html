Labels in the trigger, and per-group select-all

triggerDisplay="labels" names the selection in the compact footprint, cut to width with the rest behind «+N». selectAll takes 'group' or 'both' for a row per group.

Hiding the filter row

  • searchable - true (default, always), false (never), or a number : the threshold at which the row appears.
  • DS_CONFIG.picker.searchable - app-wide; inputs override it.
  • searchPlaceholder - defaults to DS_INTL.picker.filterPlaceholder .

Arrows, Enter, Escape and aria-activedescendant belong to the filter input; without the row they move to the trigger.

Custom option and chip content

dsOptionTemplate fills an option row's label, dsChipTemplate the chip, so a visual survives selection. Both work in ds-select (rows only), ds-multi-select and ds-autocomplete .

Not projected, library-owned: role="option" , aria-selected , the checkbox, the check glyph and the chip's close button.

Option groups

Groups and flat options mix in one options input, in the order given. A group's disabled disables all its options. Filtering hides a group with no matches.

Width

  • width="fill" (default) - fills the container; the panel matches the trigger.
  • width="content" - hugs the trigger's content, which floors the panel width; --ds-dropdown-panel-min-width and --ds-dropdown-panel-max-width bound it.
  • Overlong labels - ellipsis and hover tooltip.

The panel is portaled: style one instance via panelClass . It reads --ds-multi-select-panel-bg-color , --ds-multi-select-check-bg-color , the --ds-dropdown-panel-* tokens and the shared --ds-option-* selected and check colours.

Helper / error text

  • hint - a helper line below.
  • error - replaces it, announced via role="alert" .
  • warning / success - their states.
  • [invalid] - the error border, no text.
  • size - sm · md · lg , falls back to DS_CONFIG.control.size .
  • required , optional - mark the label.

Icons in the options

  • An option's optional icon renders before its label at 16px - the same DsOption field as ds-select and ds-autocomplete .
  • For glyph-recognised sets like priority. Chips stay text-only.
