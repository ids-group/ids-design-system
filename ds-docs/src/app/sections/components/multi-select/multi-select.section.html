Chip-based multi-value selector with search filtering, keyboard navigation, and optional overflow collapse.

Basic usage

Chips expand horizontally; all selected values are always visible. [selectAll] adds a row that toggles every filter-matching option at once (shows an indeterminate state on a partial selection).

Overflow collapse

Set [maxVisibleChips] to a positive number to collapse extra chips into a "+N more" pill.
