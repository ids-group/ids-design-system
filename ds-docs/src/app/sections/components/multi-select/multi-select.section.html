Overflow collapse

maxVisibleChips defaults to "fit": chips that fit, the rest behind "+N more", re-split on resize. A number is a ceiling, lowered when the trigger is narrow. "all" shows every chip and grows the trigger. Same on ds-autocomplete .

Labels in the trigger, and per-group select-all

triggerDisplay="labels" names the selection in the compact footprint, cut to width with the rest behind «+N». selectAll takes 'group' or 'both' for a row per group.

Hiding the filter row

searchable takes true (always, the default), false (never), or a number - the threshold at which the row appears. DS_CONFIG.picker.searchable sets it app-wide; inputs override it. searchPlaceholder defaults to DS_INTL.picker.filterPlaceholder .

Arrows, Enter, Escape and aria-activedescendant belong to the filter input; without the row they move to the trigger.

Compact trigger

triggerDisplay="count" shows a caption and count badge at intrinsic width, fixed for filter toolbars. A projected dsPickerTrigger WINS: triggerDisplay is then ignored.

Custom option and chip content

dsOptionTemplate fills an option row's label, dsChipTemplate the chip, so a visual survives selection. Both work in ds-select (rows only), ds-multi-select and ds-autocomplete .

Not projected, library-owned: role="option" , aria-selected , the checkbox, the check glyph and the chip's close button.

Option groups

Groups and flat options mix in one options input, in the order given. A group's disabled disables all its options. Filtering hides a group with no matches.

Width

Default width="fill" fills the container, panel matching the trigger. width="content" hugs the trigger's content, which floors the panel width; --ds-dropdown-panel-min-width and --ds-dropdown-panel-max-width bound it. Overlong labels get an ellipsis and hover tooltip.

The panel is portaled: style one instance via panelClass . It reads --ds-multi-select-panel-bg-color , --ds-multi-select-check-bg-color , the --ds-dropdown-panel-* tokens and the shared --ds-option-* selected and check colours.

Helper / error text

hint adds a helper line below; error replaces it with text announced via role="alert"; warning / success show their states. [invalid] paints the error border without text. size takes sm · md · lg and falls back to DS_CONFIG.control.size ; required and optional mark the label.

Icons in the options

An option's optional icon renders before its label at 16px - the same DsOption field as ds-select and ds-autocomplete . Use it for glyph-recognised sets like priority. Chips stay text-only to save room.

Server-side search

filterChange reports the query; filterWith="none" renders your options unfiltered. loading with no options shows three placeholder rows; with options they stay under a ds-loading-overlay , inert until loading clears, while the filter input and select all stay live. dsEmptyTemplate replaces the No-matches row. Panel header and footer

dsPanelHeaderTemplate and dsPanelFooterTemplate fill a strip above and below the options, with count, total and query in context. Both sit outside the listbox: not counted as options, not scrolled with the list.

Group headings, and why an option is off

dsGroupLabelTemplate fills a group's heading; the element and its naming id stay library-owned. An option's disabledReason reaches the row as aria-describedby for screen readers - try the "On leave" rows.
