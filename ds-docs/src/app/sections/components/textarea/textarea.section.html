Read-only

[readOnly]="true" renders the field on a muted --surface-secondary background — value is visible but not editable.

Character counter

[maxLength] caps input length natively and shows a live current/max counter below the field — right-aligned, aligned with the hint.

maxLengthMode="soft" lets the text run past the limit: the counter turns red, the characters past it are highlighted, and the field reports aria-invalid with the counter as its description. The form still decides whether to block a save.

Autosize

[autosize]="true" grows the textarea with its content (forces resize="none"). Bound by [minRows] / [maxRows] .

Selection API

selectionStart / selectionEnd , setSelectionRange(start, end, direction?) and select() forward to the native textarea, so an editor toolbar never reaches into the component's DOM.
