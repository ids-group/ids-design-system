Read-only

[readOnly]="true" shows the value on a muted --surface-secondary background, not editable.

Character counter

[maxLength] caps input length natively and shows a live current/max counter, right-aligned on the hint row.

maxLengthMode="soft" lets the text run past the limit: the counter turns red, the characters past it are highlighted, and the field reports aria-invalid with the counter as its description. The form still decides whether to block a save.

[countTrimmed]="true" leaves whitespace at either end out of the count, the over-limit state and the highlight, for a note the server stores trimmed. Whitespace between words still counts.

Autosize

[autosize]="true" grows the textarea with its content between [minRows] and [maxRows]. resize sets the native handle (default vertical); ignored under autosize.

Selection API

selectionStart / selectionEnd , setSelectionRange(start, end, direction?) and select() forward to the native textarea, so an editor toolbar never reaches into the component's DOM.
