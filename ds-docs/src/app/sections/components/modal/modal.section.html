Status

status takes DsStatus and sets the icon-badge tint, title colour, default icon and ARIA role; the icon is there so severity is not signalled by colour alone. error and warning become alertdialog, the rest dialog - the same split as ds-alert's alert / status.

icon (overrides the glyph), dialogRole (overrides the role) and showClose are inputs of ds-modal-card only; ds-modal always picks icon and role from status and always shows the close button.

Without dividers

[dividers]="false" drops the rules and the body's vertical padding together; --ds-modal-divider: transparent alone leaves the gap. The header and actions keep their padding, because the body scrolls and a gap in it would scroll away.

Set it app-wide with provideDsConfig({ modal: { dividers: false } }) , which also reaches ModalService confirms; an explicit [dividers] still wins.

Actions that outgrow the card

Persistent

[persistent]="true" disables backdrop click and Esc ; only a close button or open.set(false) dismisses, for wizards and save-required flows. [closeOnBackdrop]="false" disables only the backdrop click.

A backdrop dismissal needs both press and release on the backdrop, so a text selection or slider drag that ends outside does not close it (same in ds-bottom-sheet ). ds-modal emits closed after its leave animation ends; ds-modal-card emits closed when its header close button is clicked.

Confirmation

For a destructive or irreversible action, call inject(ModalService).confirm(options). It returns a Promise<boolean>: true on confirm, false on cancel, backdrop click or Esc. The dialog is always an alertdialog without a close button.

ModalConfirmOptions: title (required), message, confirmLabel and cancelLabel (defaults from DS_INTL.dialog), tone ('default' | 'error'), icon, and typeToConfirm, which keeps the confirm button disabled until the user types that phrase. 

private readonly modal = inject(ModalService);

const ok = await this.modal.confirm({
  title: 'Delete database?',
  message: 'Type the database name to confirm.',
  confirmLabel: 'Delete',
  tone: 'error',
  icon: 'trash',
  typeToConfirm: 'production-db',
});
