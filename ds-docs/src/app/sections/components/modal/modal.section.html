Persistent

[persistent]="true" disables backdrop and Esc ; only a close button or open.set(false) dismisses. [closeOnBackdrop]="false" disables only the backdrop.

  • Backdrop dismissal needs press and release on it; a drag ending outside never closes (as in ds-bottom-sheet).
  • ds-modal emits closed after its leave animation; ds-modal-card, on its header close click.

Confirmation

For destructive or irreversible actions, inject(ModalService).confirm(options) returns Promise<boolean> : true on confirm, false on cancel, backdrop or Esc. An alertdialog , no close button.

ModalConfirmOptions : title (required), message , confirmLabel and cancelLabel (defaults from DS_INTL.dialog), tone ('default' | 'error'), icon , typeToConfirm (phrase required to enable confirm). 

private readonly modal = inject(ModalService);

const ok = await this.modal.confirm({
  title: 'Delete database?',
  message: 'Type the database name to confirm.',
  confirmLabel: 'Delete',
  tone: 'error',
  icon: 'trash',
  typeToConfirm: 'production-db',
});

Tokens --ds-modal-*:

  • Surface - bg-color, radius, shadow, backdrop, divider.
  • Spacing - padding-x; header, body and actions padding.
  • Text - title font, title-text-color (+ -error / -warning / -success / -info), subtitle font and colour, impact-text-color, eyebrow.
  • Icons - close-icon and icon-badge colours.
  • Motion - enter / leave.
