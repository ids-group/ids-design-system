Date range

Two clicks set start and end.

Label · hint · required

[label] / [hint] work as on input and select. [required]="true" adds the asterisk, [optional]="true" the muted suffix.

Size · full width

size takes sm , md or lg. The field is as wide as its date format; [fullWidth]="true" fills the container, up to --ds-date-picker-max-width when set.

Validation states

error replaces the hint with a message; [invalid] paints the state only; [disabled]="true" makes the picker inert.

Min / max date bounds

[minDate] and [maxDate] (inclusive) disable days outside; here, today to today + 30 days.

Disabled-date predicate

[disabledDate] accepts a (date: Date) => boolean predicate; here, weekends.

Presets

[presets] adds a quick-pick column to the panel. Each preset has a label and a value (Date or DateRangeValue), disabled when outside minDate / maxDate / disabledDate .

Masked manual entry

[allowInput]="true" (default): the trigger is a text field masked to the locale format.

  • Non-digits are rejected; an impossible or out-of-range date errors on blur.
  • Range mode - one field for both ends.
  • A click on field or icon opens the panel.

Date of birth

[maxDate]="today" rejects future dates; [defaultDate] opens the panel focused on that day without selecting it.

Localization

[locale] drives month names, weekday headers and value format via Intl, never mixed with the OS locale. With no locale set it is en-GB: Monday first, DD/MM/YYYY. The week starts on the locale's first day (en-US Sunday, en-GB Monday; Monday where the browser has no week data); [firstDayOfWeek] (0-6) overrides it. App-wide: provideDsConfig({{ '{' }} datePicker: {{ '{' }} locale, dateFormat, firstDayOfWeek {{ '}' }} {{ '}' }}) .

Custom format

[dateFormat] pins the token order (DD / MM / YYYY ), overriding the locale's.

Calendar-only

[allowInput]="false" makes the trigger a button; dates come from the calendar only.
