Calendar popover anchored to a date field. Single-day or range selection. Range is the canonical use for Build / Access / Strike scheduling.

Single date

Trigger shows the selected date or placeholder; click opens a one-month panel.

Date range

Two clicks set start + end; cells between them are tinted in-range.

Label · hint · required

New [label] / [hint] inputs render the field-label above and a hint line below the trigger, matching the input/select field shape. [required]="true" appends the asterisk; [optional]="true" appends the muted suffix.

Validation states

[invalid]="true" switches the hint to an error message; [disabled]="true" makes the picker inert.

Min / max date bounds

[minDate] and [maxDate] disable days outside the allowed window. Days before minDate or after maxDate are rendered as disabled and cannot be selected. The example below restricts to today ± 30 days.

Disabled-date predicate

[disabledDate] accepts a (date: Date) => boolean predicate. The example disables weekends — useful for booking working days only.

Presets

[presets] renders a quick-pick button column inside the calendar panel. Each preset carries a label and a value (Date or RangeValue). Disabled when its dates fall outside minDate / maxDate / disabledDate .

Day states

Every individual cell state side-by-side. Static specimens mirroring the internal ds-calendar-day cell (which the picker grid renders) — scoped .day-specimen markup with .is-forced-* hooks pin each transient state for screenshot.
