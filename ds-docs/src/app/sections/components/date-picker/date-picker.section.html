Calendar popover anchored to a date field. Single-day or range selection. Range is the canonical use for Build / Access / Strike scheduling.

Single date

The field accepts masked typing (the locale mask, e.g. MM/DD/YYYY ); the calendar icon or ↓ opens a one-month panel. In the grid, arrows move by day or week, Home/End jump to the week start or end, PageUp/PageDown move by month, Enter or Space selects and Esc closes.

Open calendar

The range calendar as it looks open, with a five-day span selected.

Date range

Two clicks set start + end; cells between them are tinted in-range.

Label · hint · required

[label] / [hint] inputs render the field-label above and a hint line below the trigger, matching the input/select field shape. [required]="true" appends the asterisk; [optional]="true" appends the muted suffix.

Size · full width

size takes sm, md or lg. The trigger has a fixed width; [fullWidth]="true" fills the container.

Validation states

error replaces the hint with an error message; [invalid] paints the state only; [disabled]="true" makes the picker inert.

Min / max date bounds

[minDate] and [maxDate] (inclusive) disable days outside the window; the example allows today to today + 30 days.

Disabled-date predicate

[disabledDate] accepts a (date: Date) => boolean predicate. The example disables weekends — useful for booking working days only.

Presets

[presets] renders a quick-pick button column inside the calendar panel. Each preset carries a label and a value (Date or DateRangeValue). Disabled when its dates fall outside minDate / maxDate / disabledDate .

Masked manual entry

The trigger is a text field by default ([allowInput]="true"). Typing is masked to the active locale format — non-numeric characters are rejected as typed, and an impossible or out-of-range date flags an error on blur. Range mode uses one combined field (start and end in a single input). Clicking the field or the calendar icon opens the panel.

Date of birth

[maxDate]="today" rejects future dates, and [defaultDate] opens the panel on that date instead of the current month — the calendar focuses its exact day without selecting it.

Localization

[locale] drives month names, weekday headers and the value format together via Intl — no OS-locale mixing. [firstDayOfWeek] (0–6, default Monday) shifts the week. Set app-wide via provideDsConfig({{ '{' }} datePicker: {{ '{' }} locale, dateFormat, firstDayOfWeek {{ '}' }} {{ '}' }}) .

Custom format

[dateFormat] pins an explicit token order (DD / MM / YYYY ), overriding the locale-derived one.

Calendar-only

[allowInput]="false" makes the trigger a button: the date is picked from the calendar only.
