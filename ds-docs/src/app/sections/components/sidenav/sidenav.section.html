App-level vertical navigation. Items carry an icon, a label, an optional count badge or alert dot. Collapsed mode keeps the icon and pushes the label into a tooltip.

Default

Three groups, brand mark at the top, one item active. Each item exposes an (activate) output (the click MouseEvent ) — preventDefault() intercepts navigation on an href item (a routerLink navigates regardless), e.g. to drive scroll-spy.

Projection slots: an item takes [icon] (custom icon, when the icon input is unset) and [trailing] (content before the badge); a group takes [ds-group-icon].

Custom brand logo

Project a logo image or inline SVG into the [brand] slot instead of the string brand input — the auto letter-mark is skipped. When the rail collapses, the consumer hides its own wordmark and keeps the mark.

Letter-mark & accent wordmark

logoLetter sets the tile glyph when it differs from the brand's first letter, and markup marked dsBrandName projects a custom wordmark in place of the plain brand text - here a two-tone "AppAdmin" whose accent slice matches the tile. Keep the string input alongside as the fallback semantics.

brandRoute makes the brand row a router link (usually home); unset, the row is a plain block. It announces "<brand>, home" - override with brandLinkLabel. RouterLink is created only once the input is set, so an app with no router still renders. Not demoed live: a navigating specimen would leave this page.

<ds-sidenav brand="Atlas" brandRoute="/">

Expandable groups

<ds-sidenav-group expandable> renders the header as a toggle button with a caret. Group body collapses when expanded=false. Combine with the icon input to set a group-level icon.

A group that is also a page

Without routerLink the whole group header only toggles the group. With it, the header navigates and the caret becomes its own toggle button.

<ds-sidenav-group expandable [routerLink]="reportsRoute">

Collapsed
