App-level vertical navigation. Items carry an icon, a label, an optional count badge or alert dot. Collapsed mode keeps the icon and pushes the label into a tooltip.

Default

Three groups, brand mark at the top, one item active.

Expandable groups

<ds-sidenav-group expandable> renders the header as a toggle button with a caret. Group body collapses when expanded=false. Combine with the new [icon] input to set a group-level icon.

Collapsed

Labels and group headings hide; icons survive. Full label moves to a tooltip on hover (omitted here — static specimen).
