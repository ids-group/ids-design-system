App-level vertical navigation.

Default

Each item emits (activate) with the click MouseEvent ; preventDefault() stops navigation on an href item, e.g. for scroll-spy; a routerLink navigates regardless.

Slots: an item takes [icon] (when the icon input is unset) and [trailing] (before the badge); a group takes [ds-group-icon].

Custom brand logo

  • An image or SVG in the [brand] slot replaces the brand input; the letter-mark is skipped.
  • On collapse, hide your own wordmark and keep the mark.

Letter-mark & accent wordmark

logoLetter overrides the tile glyph (default: the brand's first letter); dsBrandName markup replaces the plain brand text with a custom wordmark. Keep the string input for semantics.

  • brandRoute - the brand row becomes a router link (usually home), announced "<brand>, home" ; override with brandLinkLabel .
  • RouterLink exists only when it is set, so an app without a router still renders.

<ds-sidenav brand="Atlas" brandRoute="/">

App Admin

Expandable groups

<ds-sidenav-group expandable> makes the header a toggle with a caret; the body collapses when expanded=false ; icon sets a group icon.

A group that is also a page

With routerLink the header navigates and the caret becomes a separate toggle; without it, the header toggles.

<ds-sidenav-group expandable [routerLink]="reportsRoute">

Collapsed

Labels and group headings hide; hover or focus shows the label in a tooltip.
