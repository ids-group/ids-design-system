Custom brand logo

Project a logo image or inline SVG into the [brand] slot instead of the string brand input — the auto letter-mark is skipped. When the rail collapses, the consumer hides its own wordmark and keeps the mark.

Letter-mark & accent wordmark

logoLetter sets the tile glyph when it differs from the brand's first letter, and markup marked dsBrandName projects a custom wordmark in place of the plain brand text — here a two-tone "AppAdmin" whose accent slice matches the tile. Keep the string input alongside as the fallback semantics.

brandRoute makes the brand row a link — normally the app's home. Unset it stays a plain block, because a logo that goes nowhere should not be a link and every app decides for itself whether its mark is a way home. The row announces itself as "<brand>, home" ; override that with brandLinkLabel . Router targets only, and RouterLink is instantiated only once the input is set, so an app with no router still renders the sidenav. Not demonstrated live here on purpose: a specimen that navigates takes the page with it.

Expandable groups

<ds-sidenav-group expandable> renders the header as a toggle button with a caret. Group body collapses when expanded=false. Combine with the new [icon] input to set a group-level icon.

A group that is also a page

Without routerLink the whole header only opens the group — a heading that navigates closes the page being read the moment someone reaches for the section beneath it. Set it and the group becomes a destination as well as a container: the header navigates, and the caret splits off into its own control, because one control cannot both go somewhere and stay to open something.

<ds-sidenav-group expandable [routerLink]="reportsRoute">
