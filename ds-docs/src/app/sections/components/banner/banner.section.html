Layout

layout="stacked" (default) wraps actions onto a new line; use for multi-line messages or several CTAs. layout="row" keeps actions on the right edge, vertically centred with the body; use for one-line messages with a single trailing CTA.

Announcing

announce is off unless bound or set app-wide with provideDsConfig({ banner: { announce: true } }) , because a live region fires on insertion and page furniture would interrupt on every route. When on, error, warning and severe banners get role="alert" (assertive), the rest role="status" (polite).

In dev mode only, with announce unbound: an error, warning or severe banner warns while the key is unset; an info, success or neutral banner warns when it announces only because the key is true.
