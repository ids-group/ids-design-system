Covers a content region with a spinner and optional label while an async operation is in progress.

Interactive demo

The overlay is positioned relative to its host; toggle it without unmounting the content. [blur]="false" drops the backdrop blur; spinnerSize takes sm · md (default) · lg. Tokens: --ds-loading-overlay-scrim-color, -label-color and -enter-keyframes/-duration/-easing/-scale.

Toggle loading

The scrim stops the keyboard too

The scrim blocks the pointer; while loading the covered content also goes inert (not tabbable, out of the accessibility tree), so a keyboard user cannot reach controls under it. aria-busy stays on the host.

For a scrim over only part of the content, offset its top edge with insetTop, set [inertContent]="false" and mark the covered subtree inert yourself. ds-table does this: its scrim starts below the header, so only <tbody> goes inert and sorting stays operable.
