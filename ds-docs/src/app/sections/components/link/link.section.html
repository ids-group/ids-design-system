Anchor styling via the .link CSS class. No Angular wrapper — apply directly to any <a> or <button> . Five modifiers cover quiet, inline, standalone (bold), small and large sizes.

States

Default Hover (forced) Active (forced) Focus (forced) Disabled

Variants

Default link Quiet link Standalone (bold) Small link Large link

Inline usage

Use .link.inline when the anchor sits inside body text — it inherits font-weight/size from the surrounding paragraph. For example, read the contributing guide for more detail.
