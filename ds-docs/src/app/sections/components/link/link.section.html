Anchor styling via the .link CSS class. No Angular wrapper: apply it to any <a> or <button> . Modifiers: quiet, inline, standalone (bold), plain (underlined only on hover and focus) and the sizes xs · sm · lg. Recolour with --ds-link-color; hover and active derive from it unless --ds-link-color-hover / --ds-link-color-active are set.

States

Default Hover (forced) Active (forced) Focus (forced) Disabled

Disable with aria-disabled="true"; a native disabled gets no disabled styling.

Variants

Default link Quiet link Standalone (bold) Plain (underline on hover) Extra-small link Small link Large link

Inline usage

Use .link.inline when the anchor sits inside body text: it inherits font weight and size from the paragraph. For example, read the contributing guide for more detail.

On a button, for an action that is not navigation

ds-button warns variant="text" off in favour of this class, and an action that does not navigate must be a <button> , so .link resets the browser's button chrome (padding, border, background, font). A <button class="link"> matches the anchor except display , which stays inline-block .
