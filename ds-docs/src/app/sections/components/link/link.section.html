The .link CSS class, for any <a> or <button> .

States

Default Hover (forced) Active (forced) Focus (forced) Disabled

Disable with aria-disabled="true"; a native disabled gets no disabled styling.

Variants

Modifiers: quiet, inline, standalone (bold), plain (underlined only on hover and focus), sizes xs · sm · lg . Recolour with --ds-link-color ; hover and active derive from it unless --ds-link-color-hover / --ds-link-color-active are set.

Inline usage

.link.inline inherits font weight and size inside body text. For example, read the contributing guide for more detail.

On a button, for an action that is not navigation

ds-button warns against variant="text" in favour of this class. A non-navigating action must be a <button> ; .link resets its chrome (padding, border, background, font) and matches the anchor except display , which stays inline-block .
