Page navigation for tabular data.
  • DS_INTL.pagination.label names the <nav>; the current page button carries aria-current="page".
  • DS_INTL.pagination.* - localises previous, next, page and rows-per-page labels.
  • Tokens --ds-pagination-*: button bg/label/border and hover, active bg/label and hover, radius, label font.

Default

States showcase

  • loading - page buttons take aria-disabled and ignore presses but keep focus, the size select disables; masks the range label with a skeleton, sets aria-busy on the nav.
  • total 0 - "Showing 0 of 0" via DS_INTL.pagination.range(0, 0, 0) (a custom range must handle it); every button disabled, none current.

Rows per page

On by default; [showPageSize]="false" hides it when the host fixes the size. Choices: pageSizeOptions (default [10, 25, 50, 100] ), plus any other pageSize. Changing the size resets currentPage to 1.

Layout and size

  • layout="grouped" (default) - label and buttons together, natural width.
  • layout="spread" - full width, label at one end, for under a table.
  • Both also apply to the pager inside ds-table.
