Pagination

Page navigation for tabular data — ellipsis when ranges exceed 7 visible items.

Default

12 pages, current page near the start — two ellipses bracket the centred range: one after 1, one before 12.

States showcase

Page-button states side-by-side. Live ds-pagination — pin classes target non-active buttons via ::ng-deep (see styles below).

Default
Hover
Active · current page
Prev · disabled (page 1)

Ranges

Ellipsis kicks in once the total exceeds 7 items. With more pages, the centred window stays 3 items wide; ellipses fill the gap on either side as needed.

3 pages · no ellipsis
8 pages · one ellipsis
24 pages · two ellipses
100 pages · two ellipses

With page-size select

Pager with the built-in items-per-page selector. The <ds-pagination> component renders its own size control — no external dropdown needed.

Truncation

Truncation
  • Page number Single digit / short numeral — no clip ever.
  • Ellipsis Three dots only — no clip.
