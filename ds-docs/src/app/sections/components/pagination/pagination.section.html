Page navigation for tabular data, with an ellipsis once there are more than 7 pages.

DS_INTL.pagination.label names the <nav>; the current page button carries aria-current="page". Override DS_INTL.pagination.* to localise the previous, next, page and rows-per-page labels. Tokens: --ds-pagination-* (button bg/label/border and hover, active bg/label and hover, radius, label font).

Default

12 pages, page 4: ellipses after 1 and before 12 bracket the centred range.

States showcase

loading disables every control, masks the range label with a skeleton and sets aria-busy on the nav. At total 0 the label reads "Showing 0 of 0" (DS_INTL.pagination.range(0, 0, 0), so a custom range must handle that call), and every button is disabled, none current.

Past 7 pages the centred window stays 3 wide, with ellipses on either side as needed.

Rows per page

On by default; [showPageSize]="false" hides it when the host fixes the size. Choices: pageSizeOptions (default [10, 25, 50, 100] ), plus any other pageSize. Changing the size resets currentPage to 1.

Layout and size

layout : 'grouped' (default) keeps label and buttons together at natural width; 'spread' goes full width, label at one end, for a pager under a table. Fallbacks: size → DS_CONFIG.pagination.size → DS_CONFIG.control.size → 'sm' ; layout → DS_CONFIG.pagination.layout → 'grouped' . Both also apply to the pager inside ds-table.
