Picks a number or interval on a bounded scale.

Single slider

A bound number signal, updated as the thumb moves.

  • Arrows - one step; PageUp / PageDown - ten; Home / End - the ends.
  • Range mode - bounded by the other thumb.

No visible label input: ariaLabel names the thumb(s), suffixed "minimum"/"maximum" in range mode.
