Lightweight inline status message. Five variants - info, success, warning, error, neutral - each with a default icon (icon overrides it), optional title, optional dismiss control, and an [actions] slot for follow-up CTAs.

Variants

All five severity variants as permanent specimens.

Sync is running in the background — changes will appear shortly.
Info
Allocation saved — 3 delivery schedules updated successfully.
Success
Lane 04 is at 92% capacity — review before scheduling new pickups.
Warning
Resource conflict detected — resolve before saving.
Error
Maintenance window scheduled — read-only Sunday 02:00–04:00 UTC.
Neutral

With title

An optional title input adds a bold heading above the message body.

Lane 04 is at 92% of the 95% volume cap. Re-balance before scheduling new pickups.

3 fields require attention before the form can be submitted.

Dismissible

[dismissible]="true" adds a close button; (closed) fires on click. The alert does not hide itself - remove it in the handler.

@if (dismissed()) { Show the alert again } @else { Changes go live in 5 minutes. }
Info · dismissible

Announcing

announce (unset follows DS_CONFIG.alert.announce, then false) gives an error or warning alert role="alert" + aria-live="assertive" and the others role="status" + polite.

In dev mode, with announce unbound, [ds-alert] warns when an error or warning alert is silent because the key is unset, and when an info, success or neutral alert announces only because the key is true.
