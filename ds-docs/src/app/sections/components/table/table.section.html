Bordered

[bordered]="true" wraps the table in an outer border + radius. Off by default so tables nested inside <ds-card padding="none"> don't double-border.

Loading · skeleton

First-load placeholder — rows are replaced with shimmer skeletons that lock-step with every other <ds-skeleton> on the page. Use [loading]="'skeleton'" when you have no rows to show yet.

Loading · overlay

Re-fetch indicator — existing rows stay visible behind a translucent overlay with a centred spinner. Use [loading]="'overlay'" for refresh / re-sort / filter-change.
