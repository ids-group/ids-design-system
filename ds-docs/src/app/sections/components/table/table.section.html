A cell that is a link

A clickable row is no link to screen readers, Ctrl/Cmd-click, keyboard or touch. A real <a> is:

  • Column link returning a route target - renders an <a>; null keeps that cell plain text.
  • External URL - a [cell] template.
  • With rowInteractive - a click on the link skips the row handler; the rest of the row fires it.
  • That is two tab stops per row; on long lists drop rowInteractive.

Truncation · full-text popover

  • truncate: true - ellipsis-clips a text column at its width. Without one the column grows to its text while the table has room and takes what the other columns leave when it does not; in a table that scrolls anyway it clips at 240px.
  • Tooltip - the full value. Click - a clipped cell opens a popover, an unclipped one clicks the row.
  • Detection runs only in truncate columns, dsCellTemplate descendants included.

Sticky horizontal scrollbar

[stickyScrollbar]="true" swaps the native bar for a proxy pinned to the viewport bottom. App-wide: DS_CONFIG.table.stickyScrollbar .

Server-side filtering, and a filter of your own

filterMode Effect
server (default) The table tracks columnFilters; your request filters. Pass all values via columnFilterOptions, or the checklist shows only this page.
client The table holds every row and filters them.
none Removes the affordance.
  • A filter: 'set' column with no total and no mode - dev warning.
  • Non-list criteria (date range, threshold) - project a panel with dsHeaderFilter; the table keeps button, popover and styling. active marks it set.
