How to

01

Add a new client theme

Create _brand-<client>.scss in the app's styles folder. Inside [data-brand="<client>"] , override palette ramp (--blue-50…900), brand HSL channels (--primary-h/s/l), --primary* roles, other semantic tokens (surfaces, text, --secondary* ) and the font stack. Activate with <html data-brand="<client>"> .

Reference: ds-docs/src/styles/_preview-brand-acme.scss
02

Extend with a new component

Tokens, never raw values; plain class names with &.modifier nesting; each background with its matching foreground. Add a docs section.

See Practice › Do / Don't
