Welcome

Start here

A white-label boilerplate design system. Re-skin per consumer app via a _brand-<client>.scss partial that overrides DS palette + font tokens under a [data-brand="<client>"] attribute selector. Default contents are generic admin-tool components — tables, forms, banners, sidenav, page headers. Re-theme without touching components by overriding tokens.

How to

01

Add a new client theme

Create _brand-<client>.scss in the consumer app's styles folder. Inside [data-brand="<client>"] , override the brand tokens — palette ramp (--blue-50…900), brand HSL channels (--primary-h/s/l), the --primary* roles and other semantic tokens (surfaces, text, --secondary* ), and the font stack. Activate with <html data-brand="<client>"> . Components stay untouched.

Reference: src/app/styles/_brand-acme.scss
02

Extend with a new component

Author against tokens — never raw values. Use idiomatic class names with &.modifier nesting. Pair tokens correctly (background + matching foreground). Add a per-component section to this docs site.
