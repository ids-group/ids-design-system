A running total, bar by bar: where a figure started, what moved it, where it ended.

Default

Each bar's value adds to the running total. A delta (default) hangs from the previous bar's end; a total stands on zero at the sum. A closing total usually carries value: 0 : it prints the sum, not a change.

Colour never carries it alone

Deltas print a signed change and accessible names say "increase", "decrease" or "total", surviving forced colours and monochrome. Rise and fall use the palette's lead hues, not --success / --error : a change is a direction, not a verdict. Recolour with --ds-chart-positive-color and --ds-chart-negative-color ; totals use --ds-chart-series-default-color .

Subtotals

A subtotal draws exactly like a total , and the chain continues past either; they differ only in meaning.

Crossing the baseline

Below zero the axis extends instead of clipping. tickCount (default 5) targets a tick count, snapped to a round step.

Values and connectors

showValues prints changes and sums above bars; showConnectors draws dashed rules between them. Both default on; turn off beside a table, or when bars are cramped.

default
showValues = false
showConnectors = false

Drilling in

interactive adds the affordance and keyboard route; barClicked emits the datum. Any point, axis labels included, hits its nearest step.

Holding a step

A click holds a bar and tooltip (pin disc, Unpin control at the top end); a second click, Esc or a press elsewhere releases; barClicked fires either way. Set pinOnClick="false" to disable holding, or DS_CONFIG.chart.pinOnClick: false for every chart.

Dimming and the tooltip

dimOthers (default off) fades all steps but the hovered, focused or pinned one. tooltip="none" removes the panel; 'item' (default) opens it per step. There is no 'axis': each bar is its own category.

Stagger

staggerMs delays each bar's growth (40 by default), capped so the spread fits 260ms. 0 brings every step in at once.
