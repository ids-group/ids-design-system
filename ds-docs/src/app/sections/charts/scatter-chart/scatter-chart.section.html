Several series

Each series takes its own palette slot, or its own color . Overlapping clouds are the reading, not a defect.

Thinning, and saying so

  • One SVG node per point, not one <path> per line: Lighthouse warns near 800, errors near 1400.
  • Past four times the plot width in marks, a series is decimated; the chart prints how many readings it dropped.
  • dataTable still lists every reading.
  • decimator : the default 'minMax' keeps each bucket's highest and lowest reading, so spikes are never dropped; 'lttb' keeps a truer silhouette without that promise; 'none' leaves the node budget to the caller.

Nearest point

Anywhere over the plot answers with the nearest point, ringed and tethered to the pointer. [showNearestPoint]="false" answers only within 16px of a point, without the ring.
