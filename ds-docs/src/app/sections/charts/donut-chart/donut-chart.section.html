A ring that splits one total into its parts, each slice carrying its share as a whole percentage.

Default

Slices run clockwise from twelve o'clock in the order you pass them. Shares are settled by largest remainder so they total exactly 100, which is why a slice can print a percentage one off the value you would get by rounding it yourself.

Legend placement

end is the default; bottom is for a narrow column, where the ring would otherwise shrink to make room beside it; none is only safe where the parts are named elsewhere.

Legend length

maxSlices caps the legend and sums the smallest slices into one, named by otherLabel . Off by default, the tail is summed rather than dropped, and the slices you keep stay in the order you gave them.

Palette slots

Slices take the categorical palette by position, so dropping one recolours everything after it; slot pins a slice to a fixed palette position instead. Slots count from one and wrap past the eighth.

Data table

toggle , the default, leaves the disclosure closed; visible renders it open; none leaves it out.
