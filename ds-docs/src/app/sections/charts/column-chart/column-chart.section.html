Vertical columns for a short series read left to right — months, stages, teams. Every column is measured against one value axis whose ticks snap to round numbers, each column prints its own value above itself, and a skeleton holds the space while the numbers are still arriving.

Default

Columns keep the order you pass them and share one axis, niced up from the largest value to a round step. That is why the tallest column usually stops short of the top gridline: the gap is the axis staying readable, not a margin you can tune away.

Tick count

The same data under two tick counts. The count is a hint: ticks snap to a round step, so an axis asked for three ends up with five and one asked for ten stops at eight.

Column values

A figure above each column is what lets a reader take a number off the chart without tracking back to the axis. Turn showValues off where the columns are too narrow to hold one, or where an open annex table already prints the same numbers a few pixels below.

Column colour

Columns take the palette in list order and wrap past the eighth, so a column's colour records its position and says nothing about its value — dropping a point recolours everything after it. A point that sets color pins its own, which is what keeps a category the same colour across two charts that do not hold the same points.

Data table

The plot is one image with a generated description, so the annex table is not what makes the chart readable — it is what makes the figures selectable. toggle , the default, leaves the disclosure closed; visible renders it open; none leaves it out.

Edge cases

The axis starts at zero and never goes below it, so a negative point keeps its label and its value and draws no column at all. Where one value dwarfs the rest the axis is honest and the short columns vanish — that is the signal to split the series, not to rescale it.
