One or more series plotted over a shared set of categories, with an optional second y axis for a series in different units.

Default

Series share one set of categories and take categorical palette colours in the order you pass them.

Missing readings

A null reading is a hole, not a zero, and gaps decides what it draws: break , the default, stops the line and picks it up after; zero draws through the baseline. Any non-finite value takes the same route, so an upstream NaN lands here too.

break (default)
zero

Second axis · rounded (default)

A series in other units sets axis: 'secondary' and is measured against the right-hand scale; yAxisMode reconciles the two. Rounded keeps one set of gridlines and rounds the secondary step up, so that line stops short of the top.

Second axis · exact

The secondary step is taken straight from the peak, so that series uses the full height and its labels are no longer round numbers.

Second axis · independent

Each axis is niced on its own and both series use the full height, at the price of two sets of gridlines — the secondary's are dashed so the right-hand labels can be told apart.

Second axis · stacked

Two plots over a shared category axis, labelled under the lower one only: nothing overlaps, but the two shapes can no longer be read against each other.

Markers

Turn showMarkers off once the readings are dense enough that the markers merge into a band.

Area fill

area: true fills the series down to its axis baseline, which asserts that zero means something for it — wrong for a rate or an index. Fill one series at most: two translucent fills overlap into a third quantity that is not there.

Long series

At most twelve category labels are drawn whatever the length — the chart keeps every nth and drops the rest — while the line still carries every reading.

Data table

toggle , the default, leaves the disclosure closed; visible renders it open; none leaves it out.

Edge cases

Loading holds the plot's height with a skeleton; empty has no series to derive axes from, so the chart falls back to its emptyText line.
