One or more series plotted over a shared set of categories. A series can be measured against a second y axis when it is in different units, a missing reading can break the line or sit at zero, and the category labels thin out rather than crowd once the series gets long.

yAxisMode · rounded (default)

One set of gridlines for both axes. The secondary step is rounded up, so against a peak of 75 the right-hand axis labels 0·20·40·60·80·100 and the conversion line stops short of the top.

yAxisMode · exact

The same gridlines and the same data, with the secondary step taken straight from the peak: 0·15·30·45·60·75. The conversion line now uses the full height, and the labels are no longer round numbers.
