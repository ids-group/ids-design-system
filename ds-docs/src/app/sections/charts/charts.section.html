Horizontal bars: each row draws its value as a share of the longest row.

Default

Rows keep the order you pass them — the chart never sorts. Track length is a share of the largest value in the set, not of a total, so the longest row always fills its track.

Row colour

Every row takes the same single-series colour; a row that sets color opts out.

Data table

toggle , the default, leaves the disclosure closed; visible renders it open; none leaves it out.

Edge cases

A value at or below zero draws an empty track rather than dropping the row, so its label survives; one value far above the rest flattens every other track.
