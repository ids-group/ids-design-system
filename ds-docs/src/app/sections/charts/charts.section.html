Horizontal bar chart. Each row draws its value as a share of the longest row, with an optional data table underneath and a loading skeleton for data still arriving.

Default

Rows stay in the order you pass them — the chart never sorts, because the order is usually the point. Track length is a share of the largest value in the set, not of a total, so the longest row always fills its track and the chart says nothing about what is missing from the list.

Row colour

Every row takes the same series colour. Hue carries no meaning in a bar chart, and giving each row its own only invites the reader to hunt for one. A row that sets color opts out — that is how you mark the single row the surrounding copy is about.

Data table

The plot is already one image with a generated description, so the annex table is not what makes the chart readable — it is what makes the figures selectable. toggle, the default, leaves the disclosure closed; visible renders the same disclosure open; none leaves it out, which is right only where the numbers are already elsewhere on the page.

Edge cases

What the chart does when the data is awkward. A value at or below zero draws an empty track rather than dropping the row, so its label survives; one value far above the rest flattens every other track, which is the honest reading and the reason to split the series instead.
