The stages of a journey, drawn top to bottom in the order you give them — never sorted, because the order is the meaning.

Default

The default taper shape gives every stage the same depth whatever its value, so everything quantitative comes from the table under it. Editing the data moves the table, not the shape, because taper encodes nothing in width.

Shape · taper (default)

Switch to width or area when the geometry itself has to carry the value.

Shape · width

Every boundary is read off the values as a fraction of the largest stage, so a stage that has lost nearly everything collapses to a sliver with no room for its label.

Shape · area

The fixed silhouette of taper with the boundaries moved so each band's area is proportional to its value — a small stage buys its area back in depth rather than shrinking to nothing sideways.

Stage table

On by default, and under taper it is the only place the values exist — turn showTable off only with a shape that carries them.

Data table

The disclosure appears only where the stage table is off; with both on, the same numbers would print twice.

Edge cases

Every share is measured against the first stage, so a first stage of zero leaves the percentage column with nothing to divide by.
