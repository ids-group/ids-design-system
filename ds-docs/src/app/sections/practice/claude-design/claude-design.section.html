Loads this library into a Claude Design project, so its agent builds screens from the real components.

What the design tool actually loads

The agent renders React.createElement(window.IdsDs.<Component>) . Contract: React components on window.IdsDs ; React loads separately as a global (_vendor/react*.js). The rest of _ds_bundle.js is never inspected, so it can carry an Angular runtime.

A card holds no React: one HTML page per data-claude-design block, rendering its chapter's section tag on the bundle: 

<script>window.__dsSectionsOnly = true</script>
<script src="_ds_bundle.js"></script>
<div class="ds-page"><ds-docs-components-button></ds-docs-components-button></div>

build-cards.mjs writes the cards into .design-sync/upload/ , and measure-cards.mjs records their heights in viewports.json . snapshot-cards.mjs runs last, freezing every card outside live-cards.txt into static HTML linking _ds_cards.css . What to mark: .design-sync/CARDS.md .

Why the components are generated, not ported

Each component is a custom element with a React wrapper generated from the AST by gen.mjs : no second implementation to drift. Cost: a fixed-size Angular runtime in the bundle.

Publishing is a separate gated flow: read the project, lock a plan, show it to a human, then write. Paths outside the plan are rejected.

Authored, generated, or remote

The repo commits the sync inputs and the built tree at .design-sync/upload/ . Only _ds_sync.json lives in the project alone; its absence here is not drift.

Two rules that will bite otherwise

  • An agent composition sets its state as INITIAL props, never toggles it after mount. A conditional slot works (nested DS components too) if its gate is true at connect; toggled later, the custom elements inside are destroyed. An overlay passes staticPreview or open at creation; a table with bulk actions passes its selection.
  • A component used inside another component's template registers under an alias. Nested, a custom element loses its content and inputs, so the generator gives it a ds-x- tag no template mentions. The React wrapper emits the alias; callers and designs never see it.

Attribute directives have no tag, so the generated surface lacks them; manual-surface.json lists them. Only dsTooltip would be missed, and a static card cannot hover.
