Why the components are generated, not ported

  • Each component is a custom element with a React wrapper, generated from the AST by gen.mjs
  • No second implementation to drift
  • Cost: a fixed-size Angular runtime in the bundle

Two rules that will bite otherwise

  • An agent composition sets its state as initial props, never toggles it after mount. An overlay passes staticPreview or open at creation; a table with bulk actions passes its selection.
  • A component used inside another component's template registers under a ds-x- alias. The React wrapper emits it; callers and designs never see it.
Why Show
  • A conditional slot (nested DS components too) works if its gate is true at connect; toggled later, the custom elements inside are destroyed
  • Nested, a custom element loses its content and inputs, so the generator gives it a tag no template mentions

Attribute directives have no tag, so the generated surface lacks them; manual-surface.json lists them.
