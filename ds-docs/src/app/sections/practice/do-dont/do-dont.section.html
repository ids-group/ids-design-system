Button hierarchy

Do

One primary action per view. Everything else is secondary or ghost — Cancel never competes with Save.

Cancel Save draft Publish
Don't

Three solid primaries fight each other — the user has to read every label to find the canonical path.

Publish Save draft Notify team

Modal vs Drawer

Do

Modal for blocking confirms (destructive, terminal). Drawer for in-context detail that lets the user keep the page underneath visible.

Delete project? Modal — blocking confirm
Event details Drawer — in-context
Don't

Stack modals on top of modals. Each new layer drops the user further from the page and the back button stops meaning anything.

Edit project
Delete project?
Confirm permanently delete?

Badge proliferation

Do

One status per record at the title-row level. Badges signal real state, not metadata.

Project Alpha Active
Project Beta Planning
Don't

Every column wrapped in a coloured pill. Signal-to-noise collapses and the real status badge stops being noticed.

Alpha Q3 London Active Owner

Status without colour

Do

Dot + label. Readable when copied, read aloud, or seen by a colour-blind user.

Active Planning
Don't

Dot alone — colour-blind users have no signal, and the label is invisible to a screen reader.
