The rule

Every value with a design role (colour, spacing, radius, border width, motion) reads a var(--token).

  • A literal (#ccc, 12px , 200ms ) in component CSS is a token gap to fix; dark mode, density and rebrand depend on it

When a literal is justified

  • No design role, e.g. an SVG viewBox or an asset's fixed glyph size.
  • A token should exist but doesn't: promote the literal to a new semantic token before merging.
  • Never as a shortcut: a value whose role you cannot name does not belong in the component.
