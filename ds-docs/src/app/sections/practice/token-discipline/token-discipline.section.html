The rule

Every value with a design role (colour, spacing, radius, border width, motion) reads a var(--token). A literal (#ccc, 12px , 200ms ) in component CSS is a token gap to fix; dark mode, density and rebrand depend on it.

When a literal is justified

  • No design role, e.g. an SVG viewBox or an asset's fixed glyph size.
  • A token should exist but doesn't: promote the literal to a new semantic token before merging.
  • Never as a shortcut: a value whose role you cannot name does not belong in the component.

Lint removed names after an upgrade

The package ships two plugins that flag what the library has removed or renamed. @ids-group-ltd/ids-design-system/stylelint adds ids-design-system/no-removed-tokens for --* properties in stylesheets; --fix applies a rename. 

{{ stylelintSnippet }}

@ids-group-ltd/ids-design-system/eslint is a flat-config plugin with seven rules for **/*.ts and **/*.html : removed inputs, outputs and values, renamed selectors and imports, members that override nothing, and tokens set from code or templates. configs.recommended turns all seven on as errors; configs.recommendedFrom(from, to) reports only what changed after from, up to and including to.
