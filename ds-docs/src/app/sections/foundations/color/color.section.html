Switching the focus style brand-wide

Fields take a halo (--ds-field-focus-shadow); the rest a --focus-ring-width outline in --focus-ring-color .

  • focus.emit-rules rings any unstyled focusable via :where(:focus-visible), zero specificity, so any CSS wins
  • Without it a projected link or your own <button> gets the browser's outline: auto ; DS components ring their own elements through component-base
  • styles/ds includes it; an a-la-carte @use consumer adds @use 'styles/focus' as focus; and @include focus.emit-rules; to one global stylesheet

Building a ringed shell: silence the one control inside

A composite ringed on :focus-within (field box, segmented row, toolbar cell) silences the base outline of its one inner control, or two rings show.

  • Do: focus.ring-for($control) or focus.owns-the-focus-ring($control) , naming one control
  • Don't: reset the whole box; inner tab stops (clear button, password toggle, stepper) lose their ring (WCAG 2.4.7)
  • Under forced-colors every focused element keeps a CanvasText outline; silencing is off

A clipping ancestor eats the ring: data-focus="inset"

An overflow: hidden ancestor clips rings, which draw outside the border box (e.g. ds-card padding="none" with a full-bleed child).

  • inset draws the outline inside and makes the field halo an inset double ring
  • Set it on the clipping element, not <html> ; descendants inherit it
