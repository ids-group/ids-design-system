Rules every component keeps, so a screen built from them keeps them with no opt-in.

Pointer target: 24px

Every icon-only control takes the pointer over at least --hit-xs (24px, WCAG 2.5.8), however small its icon.

Design Conversion rate
Token / mixin / param Effect
--hit-xs 24px; raise it (44px for touch) and every icon-only target follows
target.min-size Your own control: include last in its rule, after its own focus style; a box of 24px or more grows by nothing. The ring follows --focus-ring-offset
$ring-on-target: false Keeps the ring on the icon, for a control a few pixels from a label (ds-info-hint); the target still grows
$position: null For a control that is already positioned 
@use 'styles/target';

.my-icon-button {
  &:focus-visible { /* own ring */ }
  @include target.min-size;
}
How the target grows Show

The box keeps its size, so nothing around it moves and its fills stay as drawn. A transparent ::before takes the pointer over at least 24px around it, centred, and the focus ring is drawn on it.
