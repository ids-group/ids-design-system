Composition rules

  • One grid per page. Sub-regions use the inherited tracks, never a local grid.
  • Snap to columns, not to pixels. Desktop splits are 8 + 4 or 6 + 6, never 7 + 5.
  • Sidenav lives outside the grid. Reserve a fixed rail (collapsed 64 px / open 240 px); the grid fills the rest.
  • Content cap. Body text stays within 720 px: --col-cap-text .
  • Asymmetric layouts. 8 + 4 for record-detail pages (main + meta sidebar); 9 + 3 for kit / track-plan picker rails.
