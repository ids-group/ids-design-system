Foundations

Layout

Five min-width breakpoint tokens, one column-count per tier, content caps for prose and page width. Page gutters scale with the viewport; content caps at 1280 px on the widest tier, fluid below.

Breakpoints

Use them in @media queries via custom-property reference (PostCSS) or copy the values into hand-written queries.

Composition rules

  • One grid per page. Sub-regions align to the same column track they inherit — never invent a local grid.
  • Snap to columns, not to pixels. Two-column splits at desktop are 8 + 4 or 6 + 6 — never 7 + 5.
  • Sidenav lives outside the grid. Reserve a fixed rail (collapsed 64 px / open 240 px), then start the grid in the remaining width.
  • Content cap. Body text never exceeds 720 px width regardless of grid — use --col-cap-text.
  • Asymmetric layouts. 8 + 4 is canonical for record-detail pages (main + meta sidebar). 9 + 3 reserved for kit / track-plan picker rails.

Truncation

Truncation
  • Breakpoint label Single line, ellipsis. Token names are short — never wrap.
  • Grid tier description Wraps to two lines max. Never clipped — the card grows vertically.
  • Cap row use Wraps freely; the row grows vertically to fit.
