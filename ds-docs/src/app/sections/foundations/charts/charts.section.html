Chart palettes, axis tokens and the behaviour every chart shares.

Categorical palette (8)

Every hue clears 3:1 (WCAG 1.4.11); slot 8 is the neutral "other". A one-series chart takes --ds-chart-series-default-color , with --ds-chart-series-accent-color for the highlighted row.

@for (n of slots; track n) {
--ds-chart-series-{{ n }}-color
}

Ramp and heat

--ds-chart-ramp-N-color : one hue, mid lightness, for ordered stages (funnel). --ds-chart-heat-N-color : full lightness range, for cell-to-cell steps (heat map).

@for (n of slots; track n) {
--ds-chart-ramp-{{ n }}-color
}
@for (n of slots; track n) {
--ds-chart-heat-{{ n }}-color
}

Sequential ramp

Light → dark, for ordinal magnitudes (utilisation %). Sequential and divergent ramps are for hand-drawn visuals: no component reads them, no --ds-chart-* override.

@for (n of seqs; track n) {
--chart-sequential-{{ n }}
}

Divergent ramp

Red ← neutral → green for signed values around 0.

How a chart arrives

Token Marks Default
--ds-motion-chart-mark-grow-duration Columns, bars, waterfall steps grow from the baseline 600ms
--ds-motion-chart-mark-sweep-duration Rings and lines sweep in 600ms
--ds-motion-chart-mark-detail-duration Value labels and markers follow 180ms
--ds-motion-chart-mark-enter-duration Marks that fade or settle in place 400ms

A series' arrivals spread across 260ms. Reduced motion shows all marks at once.

Reference charts

Empty, loading and error states

Every chart draws these: empty data shows emptyText and [error] errorText . Unset copy comes from DS_INTL.chart .

  • [loading] , no data - skeleton in the chart's shape.
  • [loading] , data on screen - plot under the ds-loading-overlay scrim and spinner; caption uncovered.
  • Skeleton on every load - pass empty data while loading.
  • skeletonCount (default 5) - skeleton marks while the data's count is unknown: columns on ds-chart, ds-column-chart; slices on ds-pie-chart; stages on ds-funnel-chart; steps on ds-waterfall-chart.

Reading a value without keeping the pointer still

One tooltip and pin model for every chart. Chart pages list only what differs.

Gesture Result
Pointer rests on a mark Panel opens after DS_CONFIG.chart.hoverDelayMs (default 0), then answers at once until the pointer leaves the chart.
Focus, tap Panel opens at once.
Pointer moves on or leaves One panel glides mark to mark; it closes tooltipLingerMs after the pointer leaves (default 500, 0 at once).
Click a mark Pins it: tooltip, highlight and dimming stay, a pin disc marks it, Unpin shows on the caption line. The click output fires.
Second click, press elsewhere, Unpin Releases the pin.
Esc Releases a pin; closes an unpinned panel until the pointer reaches another mark (WCAG 1.4.13).
Touch tap Pins, whatever pinOnClick says.
Enter / Space on a focused mark Fires the click output; never pins.
Scroll Closes a following panel; a pinned one moves with its mark.
  • Pinned panel takes the pointer: its text is selectable and zoomable (WCAG 1.4.13). Unpinned, the pointer passes to the plot.
  • pinOnClick="false" turns click pinning off. Precedence: pinOnClick > DS_CONFIG.chart.pinOnClick > true .
  • ds-line-chart and a ds-chart category cursor pin the whole category.
  • Two to four readings: a series colour dot each. One, or five and more: labels only.
  • A dot below 1.5:1 against the panel gets a ring.
  • tooltipSwatches forces dots on or off; tooltip="none" removes the panel.

Keyboard

With interactive, the marks of a bar, column, pie, funnel or ds-chart are one tab stop.

Key Action
Tab Enters on one mark; again, leaves the chart.
← ↑ / → ↓ Previous / next mark, wrapping.
Home / End First / last mark.
Enter / Space Fires the click output; never pins.
Esc Closes the panel, releases a pin.

Category cursor (ds-line-chart, ds-chart cursor="category" ):

Key Action
Tab Rings a band and opens its panel of all readings; again, leaves.
← / → Previous / next band, wrapping.
Home / End First / last band.
Enter / Space on a band Pins the category until focus moves to another band, unless pinOnClick is off.
↑ / ↓ Focuses one reading; the panel names it alone.
Enter / Space on a reading Fires pointClicked; never pins.
Esc From a reading back to the band; on the band, closes the panel.

Dimming the other marks

  • dimOthers , off by default on every chart, fades all marks but the active one to --ds-chart-dim-opacity .
  • Active: rested hover, focus or pin. A pin keeps the dimming.
  • A legend entry, a stage-table row and a scale step follow the marks in every chart: they dim the rest only under dimOthers.
  • highlighted on dsColumnSeries and dsLineSeries brightens or thickens a series and dims the rest only under dimOthers; on ds-bar-chart it singles out a segment whatever dimOthers says.

The frame a chart draws around itself

Charts draw a bordered, padded box by default. Inside a card, use frame="none" per chart or DS_CONFIG.chart.frame per app.

frame = auto (default)
frame = none

--ds-chart-frame-* tokens size the frame; switch it off with the input, not them.

The annex table

dataTable renders the plot's numbers as a table: the non-visual route to them. Per chart or on DS_CONFIG.chart.dataTable .

'none' (default) only when the page already tabulates the numbers; 'toggle' puts the table behind a closed disclosure, 'visible' shows it open.

A heat map always has its table: colour is its only magnitude channel.

dataTable = none (default)
dataTable = toggle
dataTable = visible

What a chart says to a screen reader

  • Marks are hidden from assistive tech.
  • The plot's accessible name is one generated sentence: caption , each series with its readings, then a pointer to the annex table if rendered.
  • summary replaces the sentence on all nine charts. A hand-written one goes stale.
  • Set it only when the generated one is useless: forty categories, or a shape ("Conversion falls sharply after the third step").
  • ds-sparkline has no sentence; its name is label.

App-wide chart defaults

input > DS_CONFIG.chart.<key> > built-in default

  • DS_CONFIG.chart : valueFormat , dataTable , frame , tooltipLingerMs , tooltipSwatches , pinOnClick , hoverDelayMs (config only), rendering (below).
  • Empty and error copy: DS_INTL.chart.
  • Number locale: DsConfig.locale, then LOCALE_ID . 
providers: [
  provideDsConfig({
    locale: 'de-DE',
    chart: {
      dataTable: 'visible',
      frame: 'none',
      tooltipLingerMs: 140,
      pinOnClick: false,
      hoverDelayMs: 0,
    },
  }),
  provideDsIntl({ chart: { empty: 'Нет данных', error: 'Не удалось загрузить' } }),
]

A page with dozens of charts

  • rendering.deferUntilVisible - a still placeholder of the chart's shape until it comes within visibleMargin of the viewport.
  • buildAheadMargin - charts this close are built while the page is idle.
  • A built chart off screen costs no style, layout or paint.
  • An unbuilt chart exposes only its caption to screen readers: leave deferral off where every chart must be readable at once. 
providers: [
  provideDsConfig({
    chart: {
      rendering: {
        deferUntilVisible: true,
        visibleMargin: '10% 0px',
        buildAheadWhileIdle: true,
        buildAheadMargin: '100% 0px',
        frameBudgetMs: 8,
        skipWhileOffscreen: true,
      },
    },
  }),
]
