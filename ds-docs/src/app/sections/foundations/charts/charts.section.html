Chart palettes, axis tokens and the behaviour every chart shares.

Categorical palette (8)

Every hue clears 3:1 (WCAG 1.4.11); slot 8 is the neutral "other". A one-series chart takes --ds-chart-series-default-color , with --ds-chart-series-accent-color for the highlighted row.

@for (n of slots; track n) {
--ds-chart-series-{{ n }}-color
}

Ramp and heat

--ds-chart-ramp-N-color : one hue, mid lightness, for ordered stages (funnel). --ds-chart-heat-N-color : full lightness range, for cell-to-cell steps (heat map).

@for (n of slots; track n) {
--ds-chart-ramp-{{ n }}-color
}
@for (n of slots; track n) {
--ds-chart-heat-{{ n }}-color
}

Sequential ramp

Light → dark, for ordinal magnitudes (utilisation %). Sequential and divergent ramps are for hand-drawn visuals: no component reads them, no --ds-chart-* override.

@for (n of seqs; track n) {
--chart-sequential-{{ n }}
}

Divergent ramp

Red ← neutral → green for signed values around 0.

{{ n > 0 ? '+' + n : n }}

How a chart arrives

Columns, bars and waterfall steps grow from the baseline over --ds-motion-chart-mark-grow-duration (600ms); rings and lines sweep in over --ds-motion-chart-mark-sweep-duration (600ms); value labels and markers follow over --ds-motion-chart-mark-detail-duration (180ms). Marks that fade or settle in place take --ds-motion-chart-mark-enter-duration (400ms). A series' arrivals spread across 260ms. Reduced motion shows all marks at once.

Reference charts

Empty, loading and error states

Every chart draws these: empty data shows emptyText , [loading] a skeleton, and [error] errorText . Unset copy comes from DS_INTL.chart .

Reading a value without keeping the pointer still

The panel takes the pointer, so its number can be zoomed and selected (WCAG 1.4.13). Esc closes it until the pointer reaches another mark.

Hover feedback is instant. DS_CONFIG.chart.hoverDelayMs waits for a resting pointer, then answers instantly until the pointer leaves. Focus, tap and pinning clicks stay instant.

One panel glides from mark to mark and closes tooltipLingerMs after the pointer leaves (default 500 , enough to cross gaps; 0 closes at once). Scroll closes a following panel; a pinned one moves with its mark.

Two to four readings get series colour dots; one or five-plus, labels only. A dot below 1.5:1 against the panel gets a ring. tooltipSwatches forces dots on or off; tooltip="none" removes the panel.

tooltipSwatches unset (default)
tooltipSwatches = false
tooltip = none

Panel colours: --ds-chart-tooltip-bg-color , -text-color , -border-color . Set them on the theme or one chart; the portaled panel copies the chart's values on open.

A click pins a mark: it keeps tooltip, highlight and, with dimOthers , the dimming. A pin disc marks it, and every chart (composed ds-chart included) shows Unpin at its top end. A second click, Esc or a press elsewhere releases it; the click output fires either way. Enter and Space on a focused mark fire the click output and never pin. pinOnClick="false" on any chart or DS_CONFIG.chart.pinOnClick: false turns pinning off, except for touch taps. ds-line-chart pins the whole category.

Custom tooltip content

ds-bar-chart , ds-column-chart , ds-funnel-chart , ds-line-chart and ds-pie-chart render a projected <ng-template #dsChartTooltip> as the panel body, with a ChartTooltipContext : category (empty where the marks are the categories) and entries, each with label , value , formatted , color and an optional detail .

{{ context.category }} @for (entry of context.entries; track entry.label) { {{ entry.label }}: {{ entry.formatted }} } 
<ds-line-chart [categories]="months" [series]="series">
  <ng-template #dsChartTooltip let-context>
    <strong>{{ context.category }}</strong>
    @for (entry of context.entries; track entry.label) {
      <span>{{ entry.label }}: {{ entry.formatted }}</span>
    }
  </ng-template>
</ds-line-chart>

The frame a chart draws around itself

Charts draw a bordered, padded box by default. Inside a card, use frame="none" per chart or DS_CONFIG.chart.frame per app.

frame = auto (default)
frame = none

--ds-chart-frame-* tokens size the frame; switch it off with the input, not them.

Background

--ds-chart-bg-color paints the frame and every cut between marks: the band under a line, segment seams, hatching, label and focus halos. On a tinted card with frame="none" , set it to the card's colour so the cuts blend in. --ds-chart-plot-bg-color paints only the area inside the axes; transparent when unset.

grey card, background unset
--ds-chart-bg-color = the card
--ds-chart-plot-bg-color set

The annex table

dataTable renders the plot's numbers as a table. none (default) draws none; toggle puts it behind a closed disclosure; visible renders it open. Set it per chart or app-wide on DS_CONFIG.chart.dataTable . A heat map always has its table, since colour is its only magnitude channel.

dataTable = none (default)
dataTable = toggle
dataTable = visible

What a chart says to a screen reader

Marks are hidden from assistive tech; the plot's accessible name is one generated sentence: caption, each series with its readings, then a pointer to the annex table if rendered. caption is the visible title and opens that sentence.

summary replaces the sentence on all nine charts; ds-sparkline has none and takes its name from label. Use it only when the generated one is useless: forty categories, or a shape ("Conversion falls sharply after the third step"). Otherwise leave it unset: the generated sentence follows the data, a hand-written one goes stale.

App-wide chart defaults

Eight settings on DS_CONFIG.chart : valueFormat , dataTable , frame , tooltipLingerMs , tooltipSwatches , pinOnClick , hoverDelayMs (config only) and rendering (below). Precedence: input, config, built-in default. Empty and error copy lives in DS_INTL.chart ; the number locale is DsConfig.locale , then LOCALE_ID . 

providers: [
  provideDsConfig({
    locale: 'de-DE',
    chart: {
      dataTable: 'visible',
      frame: 'none',
      tooltipLingerMs: 140,
      pinOnClick: false,
      hoverDelayMs: 0,
    },
  }),
  provideDsIntl({ chart: { empty: 'Нет данных', error: 'Не удалось загрузить' } }),
]

A page with dozens of charts

For a page with dozens of charts, turn on rendering.deferUntilVisible : each chart shows a still placeholder of its shape until it comes within visibleMargin of the viewport. Charts within buildAheadMargin are built while the page is idle; a built chart off screen costs no style, layout or paint. Unbuilt charts expose only their caption to screen readers, so leave deferral off where every chart must be readable at once. 

providers: [
  provideDsConfig({
    chart: {
      rendering: {
        deferUntilVisible: true,
        visibleMargin: '10% 0px',
        buildAheadWhileIdle: true,
        buildAheadMargin: '100% 0px',
        frameBudgetMs: 8,
        skipWhileOffscreen: true,
      },
    },
  }),
]
