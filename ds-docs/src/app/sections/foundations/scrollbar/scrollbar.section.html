Specification

The stylesheet declares two sets of rules; which one a browser applies is the browser's choice. Overlay or inline scrollbars are an OS setting the DS does not change.

Standard
scrollbar-width: thin and scrollbar-color: var(--scrollbar-thumb) transparent on html
WebKit width
10 px (--scrollbar-w) on ::-webkit-scrollbar
WebKit track
Transparent
WebKit thumb
--scrollbar-thumb; hover --scrollbar-thumb-hover; active --scrollbar-thumb-active; --radius-pill with a 2px transparent border
Dark mode
Same tokens; the neutral ramp flips, so the thumb reads --neutral-300 = #3A4252 and the track stays transparent
