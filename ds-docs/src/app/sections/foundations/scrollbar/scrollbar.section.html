Specification

Two rule sets; the browser picks one. Overlay vs inline scrollbars is an OS setting, left alone.

Standard
scrollbar-width: thin and scrollbar-color: var(--scrollbar-thumb) transparent on html
WebKit width
10 px (--scrollbar-w) on ::-webkit-scrollbar
WebKit track
Transparent
WebKit thumb
--scrollbar-thumb ; hover --scrollbar-thumb-hover ; active --scrollbar-thumb-active ; --radius-pill with a 2px transparent border
Dark mode
Same tokens on the flipped neutral ramp: thumb --neutral-300 = #3A4252, track transparent
