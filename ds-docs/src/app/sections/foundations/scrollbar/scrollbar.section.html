Scrollbar

System chrome the user touches every minute — has to feel like part of the product, not the OS. The global scrollbar styling is auto-applied (forwarded into ds.scss); no per-component opt-in is needed.

Specification

Width
10 px (--scrollbar-w)
Track
Transparent at rest; a faint neutral fill on hover
Thumb
--neutral-300; hover --neutral-400; active --neutral-500
Radius
--radius-pill on the thumb
Reveal
Overlay where supported (macOS); fallback to inline 10 px gutter on Windows / Linux
Dark mode
Track --neutral-800; thumb --neutral-600

Truncation

Truncation
  • Scroll-pane content Never clipped horizontally — the pane scrolls instead. Rows wrap inside the pane.
  • Row label Single line, ellipsis. Long labels truncate before causing horizontal scroll inside a vertical pane.
  • Horizontal column Fixed width; pane scrolls horizontally to reveal more columns.
