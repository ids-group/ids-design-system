Each surface takes --ds-<surface>-enter-keyframes , -enter-duration and -enter-easing .

Surface Default keyframes Leave tokens
Overlay panels (--ds-overlay-*) ds-fade-in -leave-duration , -leave-easing
Modal ds-fade-in Duration, easing, -leave-keyframes (ds-fade-out)
Drawer, bottom sheet ds-slide-edge-in Duration, easing, -leave-keyframes (ds-slide-edge-out)
Toast ds-fade-in Duration, easing
Banner, alert, loading overlay ds-fade-in None
  • -enter-offset / -enter-scale apply only with ds-slide-in / ds-scale-in
  • Leave keyframes: ds-fade-out, ds-scale-out , ds-slide-out , ds-slide-edge-out
  • Set them globally, per theme or per instance; portaled panels forward them to their overlay pane
  • Custom @keyframes must be global: emulated encapsulation renames scoped ones
