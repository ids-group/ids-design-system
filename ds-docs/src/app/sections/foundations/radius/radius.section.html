Five-stop scale (0 / sm / md / lg / 2xl) plus pill. The xl stop (16px) is reserved for large containers — viewport and scanner frames. Cards, modals, drawers, toasts and empty-state icons all use --radius-lg. --radius-pill is themable via --radius-pill-value.

Scale

One tile per stop. Top-left corner is the truthful one — tiles share the same dimensions so adjacent steps stay comparable.
