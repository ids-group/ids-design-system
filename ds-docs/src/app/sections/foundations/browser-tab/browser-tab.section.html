Rules

Title format
{{ '{Record} · {Section} · Acme' }} - leaf first, brand last. Index pages: {{ '{Section} · Acme' }} . Login: Acme.
Title state
Prefix ● when unsaved (● Project Alpha · Projects · Acme), (N) for unread alerts ((3) Delivery schedule · Acme).
Favicon
Brand letter on brand surface; alert dot for unread or attention. Size matches --icon-md .
Theme-color
<meta name="theme-color"> matches --primary for branded chrome; reset to --surface-default on logout.
Tab grouping
Cap at 7 tabs per group; beyond that, suggest native tab grouping. A group shares the favicon brand colour.
Long URLs and paths
Clip with ellipsis; expose the full path via a title attribute or a copy action.
