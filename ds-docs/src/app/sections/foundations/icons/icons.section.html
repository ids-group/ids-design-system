Foundations

Iconography

2-px stroke, rounded caps, currentColor fills. Sizes derive from a fixed scale. Rendered via the <ds-icon> component which inlines SVG paths from ICONS.

Size scale

Five canonical sizes. Every glyph renders inside a 24-unit viewBox at stroke-width: 1.75.

@for (s of sizes; track s.name) {
{{ s.token }}
{{ s.px }}px · {{ s.use }}
}

Library ({{ names.length }})

Every name in the ICONS registry. Pass as a string to <ds-icon name="…">.

@for (name of names; track name) {
{{ name }}
}

Colour roles

Icons inherit currentColor. The role tokens below set the parent color.

--icon-strong
--icon-default
--icon-muted
--icon-on-primary

Truncation

Truncation
  • Glyph Never clipped — the SVG sits in a square frame at one of the fixed sizes.
  • Name label Single line, ellipsis. Names are short identifiers — never wrap.
  • Icon + text pair Glyph fixed; text label takes the remaining width and clips with ellipsis.
