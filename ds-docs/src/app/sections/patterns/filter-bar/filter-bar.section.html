Wired to a table

Usage

  • Place it above the list it filters, never below.
  • Keep facets out of the search input; make them siblings.
  • Each applied tag is removable; the link clears all.
  • On narrow widths, fold facets that do not fit into an overflow panel (as ds-filter-bar does), never wrap one facet onto a second line.
