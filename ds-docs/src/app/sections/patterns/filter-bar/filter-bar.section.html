Wired to a table

The same bar driving a live ds-table — the search box feeds the table's built-in client filter ( [filterQuery] , case-insensitive substring over every column), the status facet narrows the data app-side, applied tags mirror the active filters and clear individually. When nothing matches, the table's empty slot shows the filtered variant. Against a real backend, skip [filterQuery] and flip [loading]="'overlay'" while the query runs instead.

Usage

  • Sits above the list it filters, never below — search is read top-down.
  • Don't mix free-text search with non-text facets inside the same input. Expose facets as siblings.
  • Each applied tag is individually removable; the right-side link is the escape hatch for everything at once.
  • On narrow widths, collapse the facets that do not fit into an overflow panel — that is what ds-filter-bar does — rather than wrapping a single facet onto a second line.
