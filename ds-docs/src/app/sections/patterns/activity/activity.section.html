Usage

  • Reverse chronological — newest at the top. Don't reverse by status or actor.
  • One sentence per row. Multi-line detail belongs in an expandable child or a separate timeline view.
  • Inline badge only when the event produced an outcome (Conflict, Impact pending, Confirmed). Skip otherwise.
  • Empty state offers the next concrete step, not an apology.
