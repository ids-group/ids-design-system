Back to dashboard Request access

Usage

  • One primary action per empty state — never more. Pair with a ghost secondary only when retry needs an escape hatch.
  • Concrete subject ("asset"), concrete next step ("pick from the asset register"). Skip generic copy and cheer.
  • Loading overlay reuses the previous content silhouette behind a dim scrim — don't drop to a full skeleton when data was previously visible.
  • Permission denied never suggests "log in again" — the user is already authenticated; give them a real escape route.

Truncation

Truncation
  • Title Wraps to a second line if needed. Never clip — the user needs the full sentence to understand the state.
  • Body Wraps, no clip. Capped at ~360px via max-width so a long sentence doesn't span the full card width.
  • CTA label Short verb phrases only (Retry, Allocate resources). If the action needs a sentence, the empty state copy is wrong.
  • Icon Fixed 28px inside a 64px rounded tile. Doesn't scale with title length — always centred above the title.
