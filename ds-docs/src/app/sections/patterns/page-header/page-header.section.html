Usage

  • One status badge maximum in the title row. Promote any second status to a banner or stat tile.
  • Primary action sits on the right; secondary actions go in a ghost button or overflow menu.
  • Tabs sit immediately below the title row — never above the breadcrumb.
  • The Page header component is documented under Components > Page header. This pattern covers composition.
