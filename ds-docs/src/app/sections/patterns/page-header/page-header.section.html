Compact variant

No breadcrumb, no tabs — just title + sub-line + action row. For embedded views (drawers, secondary pages) where the chrome already establishes location. With no tab row to close the header, [divider]="true" draws the rule under it.

Usage

  • One status badge maximum in the title row. Promote any second status to a banner or stat tile.
  • Primary action sits on the right; secondary actions go in an outline button or overflow menu.
  • Tabs sit immediately below the title row — never above the breadcrumb.
  • The Page header component is documented under Components > Page header. This pattern covers composition.
