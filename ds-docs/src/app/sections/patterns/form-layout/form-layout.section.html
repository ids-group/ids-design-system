Multi-column form

Two-column section pattern: title and description on the left, fields on the right. Fields stack vertically; naturally-paired controls (Start / End, City / Country) sit side-by-side. A footer anchors every form with a secondary Discard and a primary Save.

The display name and ID used across the operations stack.

Inline edit

One-line label + control + save/cancel pill. Use when a single field is the entire unit of work — renames, status flips, single-cell table edits.

Usage

  • Section description fits on one line — if you need two, the section is doing too much.
  • Pair natural counterparts (Start/End, City/Country) horizontally; everything else stacks.
  • Footer stays visible without scroll on common viewports; sticky-footer is acceptable on tall forms.
  • Inline edit is for single-field changes. Promote to a full form once two or more fields move together.
